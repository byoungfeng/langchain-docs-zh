[智能体聊天 UI](https://github.com/langchain-ai/agent-chat-ui) 是一个 Next.js 应用程序，为与任何 LangChain 智能体交互提供对话式界面。它支持实时聊天、工具可视化以及时间旅行调试和状态分支等高级功能。智能体聊天 UI 与使用@[`create_agent`] 创建的智能体无缝兼容，无论本地运行还是部署在 [LangSmith](https://docs.langchain.com/langsmith/observability) 等环境中，都能为智能体提供交互式体验，且配置简单。

智能体聊天 UI 是开源的，可根据应用需求进行定制。

### 快速开始

最快捷的启动方式是使用托管版本：

1. **访问 [智能体聊天 UI](https://agentchat.vercel.app)**
2. **连接您的智能体**：输入部署 URL 或本地服务器地址
3. **开始聊天** - UI 会自动检测并渲染工具调用和中断

### 本地开发

如需定制或本地开发，可本地运行智能体聊天 UI：

<CodeGroup>
```bash Use npx
# Create a new Agent Chat UI project
npx create-agent-chat-app --project-name my-chat-ui
cd my-chat-ui

# Install dependencies and start
pnpm install
pnpm dev
```
```bash Clone repository
# Clone the repository
git clone https://github.com/langchain-ai/agent-chat-ui.git
cd agent-chat-ui

# Install dependencies and start
pnpm install
pnpm dev
```
</CodeGroup>
