## 选择性追踪

您可以使用 LangSmith 的 `tracing_context` 上下文管理器来追踪特定的调用或智能体的部分：

```python
import langsmith as ls

# This WILL be traced
with ls.tracing_context(enabled=True):
    agent.invoke({"messages": [{"role": "user", "content": "Send a test email to alice@example.com"}]})

# This will NOT be traced (if LANGSMITH_TRACING is not set)
agent.invoke({"messages": [{"role": "user", "content": "Send another email"}]})
```

## 选择智能体和环境

使用 `LANGSMITH_AGENT_ID` 和 `LANGSMITH_AGENT_ENVIRONMENT` 来选择已注册的智能体和环境。对于按请求路由，请在代码中传递智能体地址。参见 [将追踪记录到智能体](https://docs.langchain.com/langsmith/log-traces-to-agent)。

<Accordion title="Project-based workspaces and self-hosted LangSmith">
将 `LANGSMITH_PROJECT` 设置为追踪项目名称，而不是设置智能体变量。对于需要在基于智能体的工作区中要求 `project_name` 的集成，使用环境的 [`tracer_session_name`](https://docs.langchain.com/langsmith/create-an-agent#use-an-environment-project) 作为兼容性值。
</Accordion>

## 为追踪添加元数据

您可以用自定义元数据和标签来标注您的追踪：

```python
response = agent.invoke(
    {"messages": [{"role": "user", "content": "Send a welcome email"}]},
    config={
        "tags": ["production", "email-assistant", "v1.0"],
        "metadata": {
            "user_id": "user_123",
            "session_id": "session_456",
            "environment": "production"
        }
    }
)
```

`tracing_context` 也接受标签和元数据以实现细粒度控制：

```python
with ls.tracing_context(
    enabled=True,
    tags=["production", "email-assistant", "v1.0"],
    metadata={"user_id": "user_123", "session_id": "session_456", "environment": "production"}):
    response = agent.invoke(
        {"messages": [{"role": "user", "content": "Send a welcome email"}]}
    )
```

这些自定义元数据和标签将被附加到 LangSmith 中的追踪。

<Tip>
要了解更多关于如何使用追踪来调试、评估和监控您的智能体的信息，请参阅 [LangSmith 文档](https://docs.langchain.com/langsmith/observability)。
</Tip>
