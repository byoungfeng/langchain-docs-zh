LangSmith 部署支持部署一个 [LangGraph](https://docs.langchain.com/oss/python/langgraph/overview) _图_。然而，图中一个 _节点_ 的实现可以包含任意代码。这意味着任何框架都可以在一个节点中实现并在 LangSmith 部署上部署。这让你可以在不使用额外的 LangGraph OSS API 的情况下实现你的核心应用逻辑，同时仍然使用 LangSmith 进行 [部署](https://docs.langchain.com/langsmith/deployment)、扩展和 [可观测性](https://docs.langchain.com/langsmith/observability)。更多详情，请参考 [使用任何框架与 LangSmith 部署](https://docs.langchain.com/langsmith/application-structure#use-any-framework-with-langsmith-deployment)。
