该插件在您机器上上传任何内容之前会清除密钥，因此它们永远不会到达 LangSmith 或副本。默认情况下，已启用屏蔽。

它捕获提供者 API 密钥、JSON Web 令牌和 PEM 私有密钥，以及常见模式，如 `API_KEY=<value>` 或 URL 中的密码。每个匹配项都会被替换为 `[SECRET_DETECTED]`。有关完整规则列表，请参阅 [从跟踪中屏蔽密钥](https://docs.langchain.com/langsmith/redact-secrets#rules-in-the-preset)。

屏蔽仅匹配已知的凭证形状，因此将其视为安全网而不是保证。运行名称、标签和附件会跳过此操作，并且屏蔽的跟踪仍然包含您的提示词和文件内容。限制可以读取跟踪项目的人员。
