#### 速率限制

基于 SmithDB 的方法具有比它所替换的方法更高的专用、更快的速率限制。限制适用于云端，每个 API 密钥。

    | | 之前 (`client.list_runs()`) | 之后 (`client.runs.query()`) |

  </Tab>

    |--------|--------|-------|
    | 限制 | 每秒 10 个请求 | 每秒 300 个请求 |
  </Tab>
  <Tab title="Go">
    | | 之前 (`client.Runs.Query()`) | 之后 (`client.Runs.QueryV2()`) |

超出限制的请求返回 `429 Too Many Requests`。有关一般速率限制信息，请参阅 [使用和计费](https://docs.langchain.com/langsmith/usage-and-billing#rate-limits)。
