在 [LangSmith UI](https://smith.langchain.com) 中，请将你的 API key 设置为 [workspace secret](https://docs.langchain.com/langsmith/set-up-hierarchy#configure-workspace-settings)。

添加工作区密钥需要管理工作区密钥的权限。若您没有该权限，请请求工作区管理员为您添加密钥或授予您访问权限。

添加工作区密钥的步骤如下：

1. 在 <Icon icon="settings" /> **Settings** > **Integrations** > **Provider secrets** 中导航。
1. 选择 **+ Secret**。
1. 在 **Provider** 下拉框中选择您的模型提供方。LangSmith 会根据提供方期望的环境变量名称命名密钥，例如 `OPENAI_API_KEY`。在此字段中输入您的密钥。

   若您的提供方未列出，请将 **Provider** 保持为 **Custom**。将提供方期望的环境变量名称填入 **Key**，将 API key 填入 **Value**。
1. 选择 **Save**。

<Note>如果您的提供方使用 OAuth2 `client_credentials` 进行认证，请直接在工作模型配置中配置凭据。此场景下无需工作区密钥。详见 [OAuth 客户端凭据](https://docs.langchain.com/langsmith/model-configurations#oauth-client-credentials).</Note>
