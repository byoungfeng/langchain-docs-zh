Python 中的 Anthropic 包装方法（@[`wrap_anthropic`][wrap_anthropic]）和 TypeScript（@[`wrapAnthropic`）将您的 Anthropic 客户端包装起来以自动记录跟踪。使用包装器，LangSmith 以可读格式渲染消息，包括工具调用和多模态内容块。包装器与 `@traceable` 装饰器（Python）或 `traceable` 函数（TypeScript）协同工作，因此您可以使用包装器跟踪 Anthropic 调用，并使用装饰器或函数跟踪智能体的其他部分。

<Note>
    将 `LANGSMITH_TRACING` 环境变量设置为 `'true'`，以便将跟踪记录到 LangSmith，即使您使用 `wrap_anthropic` 或 `wrapAnthropic`。这使您可以在不更改代码的情况下切换跟踪的开启和关闭。

    还将 `LANGSMITH_API_KEY` 环境变量设置为您的 API 密钥。要创建密钥，请参阅 [创建账户和 API 密钥](https://docs.langchain.com/langsmith/create-account-api-key)。

    如果您的 LangSmith API 密钥关联到多个工作区，请设置 `LANGSMITH_WORKSPACE_ID` 环境变量以指定要使用的工作区。

    将 `LANGSMITH_AGENT_ID` 和 `LANGSMITH_AGENT_ENVIRONMENT` 设置为注册的智能体和环境。请参阅 [为智能体配置跟踪](https://docs.langchain.com/langsmith/create-an-agent#configure-tracing-for-the-agent)。
</Note>

```python Python
import anthropic
from langsmith import traceable
from langsmith.wrappers import wrap_anthropic

client = wrap_anthropic(anthropic.Anthropic())

@traceable(run_type="tool", name="Retrieve Context")
def my_tool(question: str) -> str:
  return "During this morning's meeting, we solved all world conflict."

@traceable(name="Chat Pipeline")
def chat_pipeline(question: str):
  context = my_tool(question)
  messages = [
      { "role": "user", "content": f"Question: {question}\nContext: {context}"}
  ]
  message = client.messages.create(
      model="claude-sonnet-5-5",
      messages=messages,
      max_tokens=1024,
      system="You are a helpful assistant. Please respond to the user's request only based on the given context."
  )
  return message

chat_pipeline("Can you summarize this morning's meetings?")
```

```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";
import { traceable } from "langsmith/traceable";
import { wrapAnthropic } from "langsmith/wrappers/anthropic";

const client = wrapAnthropic(new Anthropic());

const myTool = traceable(async (question: string) => {
  return "During this morning's meeting, we solved all world conflict.";
}, { name: "Retrieve Context", run_type: "tool" });

const chatPipeline = traceable(async (question: string) => {
  const context = await myTool(question);
  const messages = [
      { role: "user", content: `Question: ${question}\nContext: ${context}` }
  ];
  const message = await client.messages.create({
      model: "claude-sonnet-5-5",
      messages: messages,
      max_tokens: 1024,
      system: "You are a helpful assistant. Please respond to the user's request only based on the given context."
  });
  return message;
}, { name: "Chat Pipeline" });

await chatPipeline("Can you summarize this morning's meetings?");
```
