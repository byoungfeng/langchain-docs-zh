LangGraph 受到塑造智能体未来公司的信赖——包括 Klarna、Uber、J.P. Morgan 等——它是一个低级编排框架和运行时，用于构建、管理和部署长时间运行、有状态智能体。LangGraph 为您提供细粒度控制，可以在同一图中混合确定性、手写的步骤与 LLM 驱动的智能体步骤，因此您可以根据应用程序的要求构建完全定制化的智能体。

LangGraph 非常低级，并且完全专注于智能体 **编排**。在使用 LangGraph 之前，我们建议您熟悉用于构建智能体的组件，从 [模型](/langchain/oss/langchain/models) 和 [工具](/langchain/oss/langchain/tools) 开始。

在文档中，我们将常用 [LangChain](/langchain/oss/langchain/overview) 组件来集成模型和工具，但您不需要使用 LangChain 才能使用 LangGraph。如果您刚开始接触智能体或想要更高级别的抽象，我们建议您使用 LangChain 的 [智能体](/langchain/oss/langchain/agents)，它们为常见的 LLM 和工具调用循环提供了预构建的架构。

LangGraph 关注于智能体编排的重要基础功能：持久执行、流式输出、人机交互等。

LangGraph 的一个核心优势是能够在单个图中混合确定性步骤与 LLM 驱动的智能体步骤。这使您能够构建定制的流程，其中部分逻辑是完全可预测和可审计的，而其他部分是灵活和模型驱动的，从而让您对 AI 应用的位置和方式有精确的控制。

**LangChain vs. LangGraph vs. Deep Agents**

如果您想要运行生产智能体而不需要管理基础设施，请从 [Managed Deep Agents](https://docs.langchain.com/langsmith/managed-deep-agents-overview) 开始，它提供了（上下文压缩、虚拟文件系统、子智能体）的完整套件。或者，如果您想要在使用 Deep Agents 套件的同时获得最大灵活性，可以使用 [Deep Agents SDK](/langchain/oss/deepagents/overview#使用-sdk-自托管) 自己托管智能体，或运行自定义的 [LangSmith Deployment](https://docs.langchain.com/langsmith/deployment)。Deep Agents 基于 LangChain [智能体](/langchain/oss/langchain/agents/) 构建，这些智能体在 LangGraph 上运行。

使用 [LangChain](/langchain/oss/langchain/agents) (`create_agent`) 用于高度可定制的智能体框架，具有模型、工具和智能体循环的抽象和集成。

使用 [LangGraph](/langchain/oss/langgraph/overview)，低级编排框架，用于结合确定性和智能体工作流的先进需求。
LangGraph 是编排运行时：持久执行、流式输出、人机交互和持久化。

使用 [LangSmith](https://docs.langchain.com/langsmith/observability) 来跟踪、调试和评估使用这些框架构建的智能体。请遵循 [tracing quickstart](https://docs.langchain.com/langsmith/trace-with-langchain) 来设置。我们建议您还设置 [LangSmith Engine](https://docs.langchain.com/langsmith/engine)，它监控您的跟踪、检测问题并提出修复建议。您可以直接从引擎选项卡中打开一个 pull 请求来应用建议的修复。

使用 [LangSmith Fleet](https://docs.langchain.com/langsmith/fleet/index) 用于无代码智能体构建，具有模板、集成和例行自动化。

然后，创建一个简单的 hello world 示例：

:::python
```python
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})
```
:::

:::js
```typescript
import { StateSchema, MessagesValue, type GraphNode, StateGraph, START, END } from "@langchain/langgraph";

const State = new StateSchema({
  messages: MessagesValue,
});

const mockLlm: GraphNode<typeof State> = (state) => {
  return { messages: [{ role: "ai", content: "hello world" }] };
};

const graph = new StateGraph(State)
  .addNode("mock_llm", mockLlm)
  .addEdge(START, "mock_llm")
  .addEdge("mock_llm", END)
  .compile();

await graph.invoke({ messages: [{ role: "user", content: "hi!" }] });
```
:::

## 核心优势

LangGraph 为 *任何* 长时间运行、有状态的工作流或智能体提供低级支持基础设施。LangGraph 不抽象提示词或架构，并提供以下核心优势：

* **混合确定性和智能体步骤**： 在单个图中结合手写的确定性逻辑与 LLM 驱动的决策。在需要可靠性和可预测性的地方使用确定性步骤，在需要灵活性的地方使用智能体步骤——从而让您对智能体行为的每个部分都有精确的控制。
* [持久化](/langchain/oss/langgraph/persistence): 构建能够在失败中持久化并可以长时间运行、从停止的地方恢复的智能体。
* [人机交互](/langchain/oss/langgraph/interrupts): 通过在任何点检查和修改智能体状态来整合人工监督。
* [综合记忆](/langchain/oss/concepts/memory): 创建具有短期工作记忆（用于持续推理）和长期记忆（跨会话）的有状态智能体。
* [使用 LangSmith 进行调试](https://docs.langchain.com/langsmith/observability): 通过可视化工具深入了解复杂的智能体行为，这些工具跟踪执行路径、捕获状态转换并提供详细的运行时指标。
* [生产就绪部署](https://docs.langchain.com/langsmith/deployment): 使用专为有状态、长时间运行工作流设计的可扩展基础设施，自信地部署复杂的智能体系统。
