---

[当在节点](/langchain/oss/langgraph/use-subgraphs#在节点中调用子图)内多次调用子图且子图以`checkpointer=True`（持续模式）编译时，会出现此错误。

## 排查与修复

根据需求选择以下方案：

:::python
1. **不需要中断？** 使用`checkpointer=False`完全禁用检查点：
   ```python
   subgraph = subgraph_builder.compile(checkpointer=False)
   ```

2. **需要中断但不需要跨调用持久化？** 使用默认继承模式（省略`checkpointer`）：
   ```python
   subgraph = subgraph_builder.compile()
   ```
   每次调用获得唯一命名空间，支持并行执行。子图每次启动时重置但可使用`interrupt()`。

3. **需要跨调用持久化？** 使用`checkpointer=True`。LangGraph为每次调用分配基于位置的命名空间后缀（`calling_node`, `calling_node|1`等）防止冲突。如需稳定的名称化命名空间，可将每个子图包裹在唯一节点名称中——详见[并行子图](/langchain/oss/langgraph/use-subgraphs#子图持久化)。
:::

:::js
1. **不需要中断？** 使用`checkpointer: false`完全禁用检查点：
   ```typescript
   const subgraph = subgraphBuilder.compile({ checkpointer: false });
   ```

2. **需要中断但不需要跨调用持久化？** 使用默认继承模式（省略`checkpointer`）：
   ```typescript
   const subgraph = subgraphBuilder.compile();
   ```
   每次调用获得唯一命名空间，支持并行执行。子图每次启动时重置但可使用`interrupt()`。

3. **需要跨调用持久化？** 使用`checkpointer: true`。LangGraph为每次调用分配基于位置的命名空间后缀（`calling_node`, `calling_node|1`等）防止冲突。如需稳定的名称化命名空间，可将每个子图包裹在唯一节点名称中——详见[并行子图](/langchain/oss/langgraph/use-subgraphs#子图持久化)。
:::
