OpenWiki 是一个开源的命令行工具，用于编写和维护关于您的代码库或个人知识的 Markdown 维基。该维基捕获架构、集成、评估和工作流等详细信息，以便 [编码智能体](/langchain/oss/deepagents/overview)可以将其用作持久的上下文，而不是在每次任务中都重新发现存储库。

这使得智能体在 Token 上的工作更快、更便宜：智能体首先读取经过策划的维基，然后在需要更多细节的地方检查源代码。人类可以浏览相同的 Markdown（以及本地 [可视化器](/langchain/oss/openwiki/visualize)），但主要受众是智能体。

OpenWiki 基于 [深度智能体](/langchain/oss/deepagents/overview) 构建，并支持使用 [LangSmith](https://docs.langchain.com/langsmith/observability-quickstart) 进行跟踪。

## 入门

安装 CLI，然后为当前存储库初始化文档：

```bash
npm install -g openwiki
openwiki --init
```

查看 [快速入门](/langchain/oss/openwiki/quickstart) 以选择模型提供者、生成文档并保持其更新。要在编码智能体内部而不是独立的模型会话中运行 OpenWiki，请参阅 [编码智能体集成](/langchain/oss/openwiki/integrations)。要搜索现有的维基或分组相关存储库，请参阅 [搜索和链接维基](/langchain/oss/openwiki/search-and-link)。

## 模式

OpenWiki 有两种模式：

| 模式 | 命令 | 输出 | 使用场景 |
| --- | --- | --- | --- |
| **代码**（默认） | `openwiki` / `openwiki code` | `openwiki/` 在当前存储库中 | 您需要存储库上下文和编码智能体的文档 |
| **个人** | `openwiki personal` | `~/.openwiki/wiki` | 您需要一个从配置来源生成的本地个人大脑 |

裸 `openwiki --init` 和 `openwiki --update` 运行在代码模式。使用 `openwiki personal --init` 或 `openwiki personal --update` 用于个人维基。
