## 设置

```python

```

```python
from langchain_google_genai import GoogleGenerativeAI
```

```python
from getpass import getpass

```

```python
llm = GoogleGenerativeAI(model="gemini-3.6-flash", google_api_key=api_key)
print(
    llm.invoke(
        "What are some of the pros and cons of Python as a programming language?"
    )
)
```

## 在链中使用

template = """Question: {question}

### 安全设置

Gemini模型具有默认的安全设置，可被覆盖。如果模型频繁发出"安全警告"，可尝试调整 `safety_settings` 属性。例如，要关闭对危险内容的过滤，可通过以下方式构建大语言模型（LLM）：

```python
from langchain_google_genai import GoogleGenerativeAI, HarmBlockThreshold, HarmCategory

llm = GoogleGenerativeAI(
    model="gemini-3.6-flash",
    google_api_key=api_key,
    safety_settings={
        HarmCategory.HARM_CATEGORY_DANGEROUS_CONTENT: HarmBlockThreshold.BLOCK_NONE,
    },
)
```

要查看安全设置分类及阈值的完整列表，请参考Google的[safety settings guide](https://ai.google.dev/gemini-api/docs/safety-settings)。
