>[Google Cloud 文本转语音](https://cloud.google.com/text-to-speech)使开发者能够合成自然流畅的语音，提供100+种声音选择，支持多种语言和变体。该服务应用了DeepMind在WaveNet领域的突破性研究成果，结合Google强大的神经网络技术，实现最高音质输出。
>
>支持的语言包括英语、德语、波兰语、西班牙语、意大利语、法语、葡萄牙语和印地语。

本笔记本演示如何通过`Google Cloud Text-to-Speech API`实现语音合成功能。

首先需要配置Google Cloud项目。请参考[Google Cloud 文本转语音设置指南](https://cloud.google.com/text-to-speech/docs/before-you-begin)。
