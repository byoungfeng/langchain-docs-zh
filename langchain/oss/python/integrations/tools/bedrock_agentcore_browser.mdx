[Amazon Bedrock AgentCore 浏览器](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/browser-tool.html) 使智能体能够通过管理的 Chrome 浏览器与网页交互。智能体可以浏览网站、提取内容、填写表单、点击元素，并在安全、受管理的环境中进行屏幕截图。

## 实例化

工具包使用工厂函数创建。最简单的情况下，只需要 AWS 区域：

```python
from langchain_aws.tools import create_browser_toolkit

# Create toolkit and get tools
toolkit, browser_tools = create_browser_toolkit(region="us-west-2")
```

工厂函数还接受用于 [代理配置](#代理配置)、[浏览器扩展](#浏览器扩展) 和 [浏览器配置文件](#浏览器配置文件) 的可选参数。有关详细信息，请参阅下文。

## 代理配置

使用 `proxy_configuration` 参数将浏览器流量路由到外部代理。这对于地理位置定位、IP 旋转或访问区域限制内容很有用。

```python
from langchain_aws.tools import create_browser_toolkit

toolkit, browser_tools = create_browser_toolkit(
    region="us-west-2",
    proxy_configuration={
        "proxies": [{
            "externalProxy": {
                "server": "proxy.example.com",
                "port": 8080,
                "credentials": {
                    "basicAuth": {
                        "secretArn": "arn:aws:secretsmanager:us-west-2:123456789012:secret:proxy-creds"
                    }
                },
            }
        }],
    },
)
```

`proxy_configuration` 参数接受来自 `bedrock-agentcore` 的 `ProxyConfiguration` 数据类或等效字典，包含 `proxies` 和可选的 `bypass` 键。代理凭证安全地存储在 AWS Secrets Manager 中。

有关更多详细信息，请参阅 [AWS 关于浏览器代理的文档](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/browser-proxies.html)。

## 浏览器扩展

使用 `extensions` 参数将 S3 中的浏览器扩展加载到受管理的浏览器会话中。扩展作为 ZIP 文件打包并托管在 S3 存储桶中。

```python
from langchain_aws.tools import create_browser_toolkit

toolkit, browser_tools = create_browser_toolkit(
    region="us-west-2",
    extensions=[{
        "location": {
            "s3": {"bucket": "my-extensions-bucket", "prefix": "my-extension.zip"}
        }
    }],
)
```

`extensions` 参数接受一组 `BrowserExtension` 数据类或等效字典，每个字典都有一个指定存储桶和前缀的 S3 `location`。

有关更多详细信息，请参阅 [AWS 关于浏览器扩展的文档](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/browser-extensions.html)。

## 浏览器配置文件

使用 `profile_configuration` 参数跨会话持久化浏览器状态（Cookie、本地存储、缓存数据）。这允许智能体在离开的地方继续，而无需重新身份验证或丢失上下文。

使用 AWS CLI 或 Boto3 创建配置文件，然后将返回的配置文件 ID 传递：

```python
from langchain_aws.tools import create_browser_toolkit

toolkit, browser_tools = create_browser_toolkit(
    region="us-west-2",
    profile_configuration={
        "profileIdentifier": "my_profile-AbC1234567"
    },
)
```

`profile_configuration` 参数接受来自 `bedrock-agentcore` 的 `ProfileConfiguration` 数据类或等效字典，包含 `profileIdentifier` 键。配置文件 ID 采用格式 `<name>-<10-char-suffix>`，通过 Bedrock AgentCore 控制平面 API 创建配置文件时返回。

有关更多详细信息，请参阅 [AWS 关于浏览器配置文件的文档](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/browser-profiles.html)。

## 调用

### 直接工具使用

获取特定工具并调用它们：

```python
# Get tools by name
tools_by_name = toolkit.get_tools_by_name()

# Navigate to a URL (requires config with thread_id)
config = {"configurable": {"thread_id": "session-123"}}

result = tools_by_name["navigate_browser"].invoke(
    {"url": "https://example.com"},
    config=config
)
print(result)

# Extract text from the page
text = tools_by_name["extract_text"].invoke({}, config=config)
print(text)
```

### 在智能体中使用

```python
import asyncio
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain_aws.tools import create_browser_toolkit

async def main():
    # Create toolkit
    toolkit, browser_tools = create_browser_toolkit(region="us-west-2")

    # Initialize chat model
    llm = init_chat_model(
        "us.anthropic.claude-sonnet-4-20250514-v1:0",
        model_provider="bedrock_converse",
    )

    # Create agent with browser tools
    agent = create_agent(
        model=llm,
        tools=browser_tools,
    )

    # Create config with thread_id for session isolation
    config = {"configurable": {"thread_id": "research-session"}}

    # Run the agent
    result = await agent.ainvoke(
        {"messages": [{
            "role": "user",
            "content": "Navigate to https://example.com and tell me the main heading"
        }]},
        config=config
    )
    print(result["messages"][-1].content)

    # Clean up when done
    await toolkit.cleanup()

asyncio.run(main())
```

## 基于线程的会话隔离

工具包为每个 `thread_id` 维护单独的浏览器会话。这允许并发使用而不会相互干扰：

```python
# Each thread gets its own browser session
config_user1 = {"configurable": {"thread_id": "user-1"}}
config_user2 = {"configurable": {"thread_id": "user-2"}}

# User 1 navigates to site A
tools_by_name["navigate_browser"].invoke(
    {"url": "https://site-a.com"},
    config=config_user1
)

# User 2 navigates to site B (different browser session)
tools_by_name["navigate_browser"].invoke(
    {"url": "https://site-b.com"},
    config=config_user2
)
```

## 浏览器操作

### 导航

```python
config = {"configurable": {"thread_id": "session-123"}}

# Navigate to URL
tools_by_name["navigate_browser"].invoke({"url": "https://example.com"}, config=config)

# Go back
tools_by_name["navigate_back"].invoke({}, config=config)

# Get current page info
current = tools_by_name["current_webpage"].invoke({}, config=config)
print(current)  # URL and title
```

### 与元素交互

```python
# Click an element
tools_by_name["click_element"].invoke({"selector": "#submit-button"}, config=config)

# Type into an input field
tools_by_name["type_text"].invoke({
    "selector": "input[name='search']",
    "text": "search query"
}, config=config)

# Wait for element to appear
tools_by_name["wait_for_element"].invoke({
    "selector": ".results",
    "timeout": 10000,  # 10 seconds
    "state": "visible"
}, config=config)
```

### 提取内容

```python
# Extract all text
text = tools_by_name["extract_text"].invoke({}, config=config)

# Extract all hyperlinks
links = tools_by_name["extract_hyperlinks"].invoke({}, config=config)

# Get specific elements
elements = tools_by_name["get_elements"].invoke(
    {"selector": "article h2"},
    config=config
)
```

### 屏幕截图和滚动

```python
# Take screenshot of visible viewport (returns base64 image)
screenshot = tools_by_name["take_screenshot"].invoke(
    {"capture_type": "viewport"},
    config=config
)

# Take screenshot of entire scrollable page
full_screenshot = tools_by_name["take_screenshot"].invoke(
    {"capture_type": "full_page"},
    config=config
)

# Scroll the page
tools_by_name["scroll_page"].invoke({
    "direction": "down",
    "amount": 500  # pixels
}, config=config)
```

## 会话清理

完成时始终清理浏览器会话以释放资源：

```python
# Clean up all browser sessions
await toolkit.cleanup()
```

> **注意:** 虽然 `create_browser_toolkit()` 是同步的，但 `cleanup()` 方法是异步的，必须等待。

## 并发保护

工具包包括内置的并发保护。每个浏览器会话都与特定的 `thread_id` 关联，如果尝试在会话正在使用时访问它，将引发 `RuntimeError`。为并发操作使用不同的 `thread_id` 值。

```python
# Good: Different thread IDs for concurrent operations
config_a = {"configurable": {"thread_id": "task-a"}}
config_b = {"configurable": {"thread_id": "task-b"}}

# These can run concurrently without conflicts
await asyncio.gather(
    agent.ainvoke({"messages": [...]}, config=config_a),
    agent.ainvoke({"messages": [...]}, config=config_b),
)
```
