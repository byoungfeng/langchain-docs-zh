>[并行](https://platform.parallel.ai/)是一个为大型语言模型（LLM）和AI应用构建的实时网络搜索和内容提取平台。

`ParallelFindAllTool`调用并行的[FindAll API](https://docs.parallel.ai/findall-api/findall-quickstart)进行实体发现。给定一个自然语言目标和布尔匹配条件列表，它返回满足所有条件的排名候选者。

## 实例化

`generator`是一个工具级设置。使用`"preview"`（免费，限制为10个候选者）进行快速迭代；切换到`"base"`（默认），`"core"`或`"pro"`以获得更高质量的运行。

```python
from langchain_parallel import ParallelFindAllTool

tool = ParallelFindAllTool(generator="preview")
```

## 调用

### 快速发现（预览生成器）

`preview`生成器在几秒钟内返回，并限制为10个候选者。`match_limit`是必需的；对于`preview`，它必须在`[5, 10]`中。

```python
from langchain_parallel import FindAllMatchCondition

result = await tool.ainvoke({
    "objective": "Pure-play public LLM API providers",
    "entity_type": "company",
    "match_conditions": [
        FindAllMatchCondition(
            name="public_us",
            description="Company is publicly traded on a US exchange",
        ),
        FindAllMatchCondition(
            name="llm_api_revenue",
            description="Primary revenue is selling LLM inference via API",
        ),
    ],
    "match_limit": 5,
})

for c in result["candidates"]:
    print(c["name"], "—", c["url"])
```

```text
Anthropic — https://www.anthropic.com
OpenAI — https://www.openai.com
...
```

### 更高质量的运行

切换到`"base"`、`"core"`或`"pro"`以获得高达1000个的`match_limit`。这些需要几分钟；工具会轮询，直到运行达到终端状态（`completed`、`cancelled`或`failed`）。

```python
deep = ParallelFindAllTool(generator="core")

result = await deep.ainvoke({
    "objective": "Independent solar-installer companies based in the EU",
    "entity_type": "company",
    "match_conditions": [
        FindAllMatchCondition(
            name="eu_hq",
            description="Headquartered in an EU country",
        ),
        FindAllMatchCondition(
            name="residential_solar_pv",
            description="Primarily installs residential solar PV",
        ),
    ],
    "match_limit": 50,
})
```

### 排除已处理的候选者

传递`exclude_list=[FindAllExcludeEntry(name=..., url=...)]`以丢弃您已经处理的候选者。`name`和`url`都是必需的。

```python
from langchain_parallel import FindAllExcludeEntry

result = await tool.ainvoke({
    "objective": "Pure-play public LLM API providers",
    "entity_type": "company",
    "match_conditions": [
        FindAllMatchCondition(
            name="llm_api_revenue",
            description="Primary revenue is selling LLM inference via API",
        ),
    ],
    "match_limit": 5,
    "exclude_list": [
        FindAllExcludeEntry(name="OpenAI", url="https://www.openai.com"),
        FindAllExcludeEntry(name="Anthropic", url="https://www.anthropic.com"),
    ],
})
```

### 取消

`cancel()`通过ID中止正在运行的运行。ID返回给启动运行的调用者；如果您使用`tool.ainvoke(...)`在一个长时间运行的任务中启动它，从运行中捕获`findall_id`，然后等待完成。

```python
# from another task / handler:
tool.cancel(findall_id)        # sync
await tool.acancel(findall_id) # async
```

### 参数

#### 必填

- `objective`：要查找的自然语言描述。
- `entity_type`：描述候选者类别的简短名词（`"company"`、`"researcher"`、`"product"`等）。
- `match_conditions`：`FindAllMatchCondition(name=..., description=...)`列表。每个字段都需要这两个字段。
- `match_limit`：`[5, 1000]`中的整数。`preview`生成器进一步将其限制为10。

#### 可选

- `exclude_list`：要跳过的`FindAllExcludeEntry(name=..., url=...)`列表。
- `webhook`：接收运行/候选者事件的`FindAllWebhook(url=..., event_types=[...])`。
- `metadata`：保存在运行上的自由形式元数据。
- `timeout`：秒级轮询超时（默认600）。
