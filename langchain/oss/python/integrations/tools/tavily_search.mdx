## 实例化

这里展示了如何实例化Tavily搜索工具的实例。该工具在实例化期间接受各种参数：

- max_results（可选，int）：返回的最大搜索结果数量。默认为5。
- topic（可选，str）：搜索类别。可以是"general"、"news"或"finance"。默认为"general"。
- include_answer（可选，bool）：在结果中包含对原始查询的答案。默认为False。
- include_raw_content（可选，bool）：包含每个搜索结果的清理和解析的HTML。默认为False。
- include_images（可选，bool）：在响应中包含与查询相关的图片列表。默认为False。
- include_image_descriptions（可选，bool）：包含每张图片的描述性文本。默认为False。
- search_depth（可选，str）：搜索深度，可以是"basic"或"advanced"。默认为"basic"。
- time_range（可选，str）：从当前日期回溯的时间范围以过滤结果 - "day"、"week"、"month"或"year"。默认为None。
- include_domains（可选，List[str]）：要特别包含的域名列表。默认为None。
- exclude_domains（可选，List[str]）：要特别排除的域名列表。默认为None。

有关可用参数的全面概述，请参阅[Tavily搜索API文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)

```python
from langchain_tavily import TavilySearch
```

## 调用

### [使用参数直接调用](/langchain/oss/langchain/tools)

Tavily搜索工具在调用期间接受以下参数：

- `query`（必需）：一个自然语言搜索查询
- 以下参数也可以在调用期间设置：`include_images`、`search_depth`、`time_range`、`include_domains`、`exclude_domains`
- 由于可靠性和性能原因，某些影响响应大小的参数在调用期间不能修改：`include_answer`和`include_raw_content`。这些限制防止意外的上下文窗口问题并确保结果的一致性。

注意：可选参数可用于智能体动态设置，如果您在实例化期间设置了一个参数，然后在调用工具时使用不同的值，工具将使用您在调用期间传递的值。

```python
tool.invoke({"query": "What happened at the last wimbledon"})
```

### [使用ToolCall调用](/langchain/oss/langchain/tools)

我们也可以使用模型生成的ToolCall来调用工具，此时将返回一个ToolMessage：

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "euro 2024 host nation"},
    "id": "1",
    "name": "tavily",
    "type": "tool_call",
}
tool_msg = tool.invoke(model_generated_tool_call)

# The content is a JSON string of results
print(tool_msg.content[:400])
```
