## 安装与配置

要使用此功能，安装`langchain-hana`包：

```python
pip install langchain_hana
```

然后，创建与您的SAP HANA云实例的连接。

```python
import os

from dotenv import load_dotenv
from hdbcli import dbapi

# Load environment variables if needed
load_dotenv()

# Establish connection to SAP HANA Cloud
connection = dbapi.connect(
    address=os.environ.get("HANA_DB_ADDRESS"),
    port=os.environ.get("HANA_DB_PORT"),
    user=os.environ.get("HANA_DB_USER"),
    password=os.environ.get("HANA_DB_PASSWORD")
)
```

`HanaSparqlQAChain`整合了以下功能：

1. **基于模式的SPARQL生成**
2. **对SAP HANA的查询执行**
3. **自然语言答案格式化**

## 初始化

需要：

* 一个用于生成和解析查询的 **LLM**
* 一个包含连接、`graph_uri`和本体论的 `HanaRdfGraph`

按照[HanaRdfGraph](/langchain/oss/python/integrations/graphs/sap_hana_rdf_graph)的步骤获取创建`HanaRdfGraph`实例的详细信息。

导入`HanaSparqlQAChain`

```python
from langchain_hana import HanaSparqlQAChain
```

```python
qa_chain = HanaSparqlQAChain.from_llm(
    llm=llm, graph=graph, allow_dangerous_requests=True, verbose=True
)
```

## 流程概述

1. **SPARQL生成**
   * 使用`SPARQL_GENERATION_SELECT_PROMPT`
   * 输入：
     * `schema`（来自`graph.get_schema`的Turtle格式）
     * `prompt`（用户的问题）
2. **查询后处理**
   * 从LLM响应中提取SPARQL代码
   * 若缺失则注入`FROM <graph_uri>`
   * 确保声明必需的公共前缀（`rdf:`、`rdfs:`、`owl:`、`xsd:`）
3. **执行**
   * 调用`graph.query(generated_sparql)`
4. **答案生成**
   * 使用`SPARQL_QA_PROMPT`
   * 输入：
     * `context`（原始查询结果）
     * `prompt`（原始问题）

## 提示词模板

### "SPARQL生成"提示词

`sparql_generation_prompt`用于指导LLM根据用户问题及提供的模式生成SPARQL查询。

### 答案生成提示词

`qa_prompt`要求LLM仅基于数据库结果生成自然语言回答。

默认提示词可在此找到：[`prompts.py`](https://github.com/SAP/langchain-integration-for-sap-hana-cloud/blob/main/langchain_hana/chains/graph_qa/prompts.py)

## 自定义提示词

初始化时可覆盖默认值：

```python
qa_chain = HanaSparqlQAChain.from_llm(
    llm=llm,
    graph=graph,
    allow_dangerous_requests=True,
    verbose=True,
    sparql_generation_prompt=YOUR_SPARQL_PROMPT,
    qa_prompt=YOUR_QA_PROMPT
)
```

> - `sparql_generation_prompt`必须包含输入变量：`["schema", "prompt"]`
> - `qa_prompt`必须包含输入变量：`["context", "prompt"]`

## 内部机制解析

1. **SPARQL生成**
   链调用LLM，使用`SPARQL_GENERATION_SELECT_PROMPT`处理格式化本体（`graph.get_schema`）和用户问题，生成适配模式的合法`SELECT`查询。
2. **预处理与执行**
   * **提取与清理**：从LLM响应中提取原始SPARQL文本
   * **注入图上下文**：若缺失则添加`FROM <graph_uri>`，确保声明公共前缀（`rdf:`、`rdfs:`、`owl:`、`xsd:`）
   * **执行**：通过`HanaRdfGraph.query()`在命名图中运行优化后的查询
3. **答案生成**
   返回的CSV（或Turtle）结果通过`SPARQL_QA_PROMPT`再次输入LLM，生成严格基于数据且无虚构的简洁回答。
