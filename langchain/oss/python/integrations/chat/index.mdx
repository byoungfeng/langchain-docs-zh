## 路由器与代理

路由器和代理让您通过单一 API 和凭据访问多个提供商的模型。它们可以简化计费、让您在不更换集成的情况下切换模型，并提供自动回退等功能。

| Provider | Integration | Description |
|-|-|-|
| [OpenRouter](https://openrouter.ai/) | [`ChatOpenRouter`](/langchain/oss/python/integrations/chat/openrouter) | 统一访问OpenAI、Anthropic、Google、Meta等模型的接口 |
| [LiteLLM](https://www.litellm.ai/) | [`ChatLiteLLMRouter`](/langchain/oss/python/integrations/chat/litellm) | 提供OpenAI、Anthropic、Azure、Hugging Face等模型的统一接口及路由回退 |

## Chat Completions API

某些模型供应商提供与OpenAI [Chat Completions API](https://platform.openai.com/docs/api-reference/chat)兼容的端点。此时，您可以使用[`ChatOpenAI`](/langchain/oss/python/integrations/chat/openai)配合自定义 `base_url` 连接到这些端点实现基础聊天功能。

<Warning>
    `ChatOpenAI`仅针对[官方OpenAI API规范](https://github.com/openai/openai-openapi)。第三方供应商的非标准响应字段（如 `reasoning_content`、`reasoning`、`reasoning_details`）**不会被提取或保留**。如需访问非标准功能，请使用供应商专用包。

    例如，OpenRouter有专门的LangChain集成。请参考[`ChatOpenRouter`指南](/langchain/oss/python/integrations/chat/openrouter)进行配置和使用。
</Warning>
