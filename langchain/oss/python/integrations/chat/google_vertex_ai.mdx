## 安装

访问Gemini企业智能体平台模型需创建Google Cloud Platform账户、配置凭据并安装 `langchain-google-vertexai` 集成包。

### 凭据

使用集成需满足以下条件之一：

- 环境已配置凭据（gcloud、工作负载身份等）
- 将服务账户JSON文件路径存储为 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量

本代码库使用 `google.auth` 库，优先查找上述应用凭据变量，再查找系统级认证。

更多详情请参考 `google.auth` [API参考](https://googleapis.dev/python/google-auth/latest/reference/google.auth.html#module-google.auth)。

为启用模型调用自动追踪，设置 [LangSmith](https://docs.langchain.com/langsmith/observability) API密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain Gemini企业智能体平台集成位于 `langchain-google-vertexai` 包：

```python
pip install -qU langchain-google-vertexai
```

## 初始化

现在可以实例化模型对象并生成对话补全：

```python
from langchain_google_vertexai import ChatVertexAI

llm = ChatVertexAI(
    model="gemini-3.7-flash",
    temperature=0,
    max_tokens=None,
    max_retries=6,
    stop=None,
    # other params...
)
```

## 内置工具

Gemini支持多种服务器端执行的工具。

### Google搜索

<Info>
    **需 `langchain-google-vertexai>=2.0.11`**
</Info>

Gemini可执行Google搜索并基于结果 [增强响应](https://ai.google.dev/gemini-api/docs/grounding)：

```python
from langchain_google_vertexai import ChatVertexAI

llm = ChatVertexAI(model="gemini-3.7-flash").bind_tools([{"google_search": {}}])

response = llm.invoke("What is today's news?")
```

### 代码执行

<Info>
    **需 `langchain-google-vertexai>=2.0.25`**
</Info>

Gemini可 [生成并执行Python代码](https://ai.google.dev/gemini-api/docs/code-execution)：

```python
from langchain_google_vertexai import ChatVertexAI

llm = ChatVertexAI(model="gemini-3.7-flash").bind_tools([{"code_execution": {}}])

response = llm.invoke("What is 3^3?")
```
