## 配置

要访问 `ChatMistralAI` 模型，您需要创建Mistral账户、获取API密钥并安装 `langchain-mistralai` 集成包。

### 凭据
与API通信需要有效的 [API密钥](https://console.mistral.ai/api-keys/)。配置完成后，请设置 MISTRAL_API_KEY 环境变量：

```python
import getpass
import os

if "MISTRAL_API_KEY" not in os.environ:
    os.environ["MISTRAL_API_KEY"] = getpass.getpass("Enter your Mistral API key: ")
```

要启用模型调用自动追踪功能，请设置您的 [LangSmith](https://docs.langchain.com/langsmith/observability) API密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain Mistral集成包位于 `langchain-mistralai` 包中：

```python
pip install -qU langchain-mistralai
```

## 实例化

现在我们可以实例化模型对象并生成对话补全：

```python
from langchain_mistralai import ChatMistralAI

llm = ChatMistralAI(
    model="mistral-large-latest",
    temperature=0,
    max_retries=2,
    # other params...
)
```

## 调用

```python
messages = [
    (
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ),
    ("human", "I love programming."),
]
ai_msg = llm.invoke(messages)
ai_msg
```
