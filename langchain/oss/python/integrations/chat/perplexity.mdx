## 配置

要访问Perplexity模型，需创建Perplexity账户、获取API密钥并安装 `langchain-perplexity` 集成包。

### 凭据
前往 [此页面](https://www.perplexity.ai/) 注册Perplexity并生成API密钥。完成设置后，配置 `PPLX_API_KEY` 环境变量：

```python
import getpass
import os

if "PPLX_API_KEY" not in os.environ:
    os.environ["PPLX_API_KEY"] = getpass.getpass("Enter your Perplexity API key: ")
```

为启用模型调用自动追踪，设置 [LangSmith](https://docs.langchain.com/langsmith/observability) API密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_perplexity import ChatPerplexity
```

以下代码假设已通过环境变量设置 PPLX_API_KEY。若需手动指定API密钥并选择不同模型，可使用以下代码：

```python
chat = ChatPerplexity(temperature=0, pplx_api_key="YOUR_API_KEY", model="sonar")
```

您可查看 [可用的Perplexity模型列表](https://docs.perplexity.ai/getting-started/models)。在笔记本中可通过输入API密钥动态设置以实现可复现性。

```python
chat = ChatPerplexity(temperature=0, model="sonar")
```

## 智能体 API 支持（`use_responses_api`）

`ChatPerplexity` 可通过设置 `use_responses_api` 路由请求至Perplexity的 [智能体API](https://docs.perplexity.ai/docs/agent-api/quickstart)（Perplexity风格响应API）。其设计理念与 [`ChatOpenAI.use_responses_api`](https://reference.langchain.com/python/langchain-openai/chat_models/ChatOpenAI)一致：单类、双端点、通过单一标志位控制。

| 值 | 端点 | 备注 |
| :--- | :--- | :--- |
| `None` (默认) | 自动检测 | 当请求使用内置Perplexity工具（`web_search`, `fetch_url`, `finance_search`, `people_search`）或包含响应专用字段（`previous_response_id`, `instructions`, `input`, `include`）时，路由至智能体API；否则路由至Chat Completions。 |
| `True` | 智能体API | 总是使用 `client.responses.create()`。 |
| `False` | Chat Completions | 总是使用 `client.chat.completions.create()`。 |

智能体API提供 `ChatPerplexity` 访问内置工具（实时网络搜索、URL获取、金融与人物搜索）及状态感知字段（`previous_response_id`, `instructions`, `include`），这些在Chat Completions中不可用。现有 `ChatPerplexity(model="sonar")` 调用方式不受影响——纯文本请求默认仍走Chat Completions路径。

```python
from langchain_perplexity import ChatPerplexity

chat = ChatPerplexity(
    model="openai/gpt-5.5",
    use_responses_api=True,
)
response = chat.invoke("What did Apple announce at WWDC this week?")
response.content
```

您也可直接传递内置工具，无需设置标志——自动检测即可路由请求：

```python
chat = ChatPerplexity(model="openai/gpt-5.5")

response = chat.invoke(
    "Summarize the latest LangChain release notes.",
    tools=[{"type": "web_search"}],
)
response.content
```

通过智能体API路由后，响应对象包含更丰富的元数据：

- `usage_metadata` 从响应形状的 `usage` 载荷填充（`input_tokens`, `output_tokens`, `total_tokens`）
- `response_metadata` 包含传输层字段：`id`, `model`, `status`, `object`
- `additional_kwargs` 提取Perplexity专用输出：`citations`, `images`, `related_questions`, `search_results`, `videos`, `reasoning_steps`
- 模型返回的工具调用在 `response.tool_calls` 中与 `ChatOpenAI` 保持一致

<Warning>
智能体API不接受Chat-Completions专用采样与控制参数。当 `ChatPerplexity` 路由至智能体API（无论显式或自动检测），以下字段会被 `WARNING` 日志丢弃：`temperature`, `top_p`, `top_k`, `stop`, `metadata`。默认 `temperature` 被 `_default_params` 静默抑制，但用户自定义 `temperature` 仍会警告。

`tool_choice` 不是被静默丢弃——当路由至智能体API时， `ValueError` 会因下游代理循环无法处理缺失的强制工具选择而抛出异常。

</Warning>

请参考 [Perplexity智能体API模型列表](https://docs.perplexity.ai/docs/agent-api/models) 查看完整支持模型列表（例如 `openai/gpt-5.5`, `anthropic/claude-sonnet-4-6`, `google/gemini-3-1-pro`）。

## 通过 `ChatPerplexity` 使用Perplexity专用参数

您也可通过 ChatPerplexity 类使用Perplexity专用参数。例如通过 extra_body 参数设置以下参数：

```python
chat = ChatPerplexity(temperature=0.7, model="sonar")
response = chat.invoke(
    "Tell me a joke about cats", extra_body={"search_recency_filter": "week"}
)
response.content
```

```text
"Sure, here's a cat joke for you:\n\nWhy are cats bad storytellers?\n\nBecause they only have one tale. (Pun alert!)\n\nSource: OneLineFun.com [4]"
```

### 访问搜索结果元数据

Perplexity通常会返回咨询的网页列表（"search_results"）。无需特殊参数——列表会自动存入 `response.additional_kwargs["search_results"]`。

```python
chat = ChatPerplexity(temperature=0, model="sonar")

response = chat.invoke(
    "What is the tallest mountain in South America?",
)

# Main answer
print(response.content)

# First two supporting search results
response.additional_kwargs["search_results"][:2]
```

## `ChatPerplexity` 支持结构化输出（需三级及以上用户）

```python
from pydantic import BaseModel


class AnswerFormat(BaseModel):
    first_name: str
    last_name: str
    year_of_birth: int
    num_seasons_in_nba: int


chat = ChatPerplexity(temperature=0.7, model="sonar-pro")
structured_chat = chat.with_structured_output(AnswerFormat)
response = structured_chat.invoke(
    "Tell me about Michael Jordan. Return your answer "
    "as JSON with keys first_name (str), last_name (str), "
    "year_of_birth (int), and num_seasons_in_nba (int)."
)
response
```

```text
AnswerFormat(first_name='Michael', last_name='Jordan', year_of_birth=1963, num_seasons_in_nba=15)
```
