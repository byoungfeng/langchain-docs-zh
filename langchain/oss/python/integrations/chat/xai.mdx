## 安装

要访问 xAI 模型，需创建 xAI 账户、获取 API 密钥并安装 `langchain-xai` 集成包。

### 凭据
前往 [此页面](https://console.x.ai/) 注册 xAI 并生成 API 密钥。完成此操作后，设置 `XAI_API_KEY` 环境变量：

```python
import getpass
import os

if "XAI_API_KEY" not in os.environ:
    os.environ["XAI_API_KEY"] = getpass.getpass("Enter your xAI API key: ")
```

要启用模型调用自动追踪功能，设置 [LangSmith](https://docs.langchain.com/langsmith/observability) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain xAI 集成位于 `langchain-xai` 包中：

```python
pip install -qU langchain-xai
```

    timeout=None,

## 工具调用

ChatXAI 提供了 [工具调用](https://docs.x.ai/docs#capabilities)（本文使用 "tool calling" 和 "function calling" 互换表述）API，允许定义工具及其参数，并让模型返回包含要调用工具及输入的 JSON 对象。工具调用对构建工具链和智能体非常有用，并能更广泛地获取结构化输出。

### ChatXAI.bind_tools()

通过 `ChatXAI.bind_tools`，可轻松将 Pydantic 类、字典 schema、LangChain 工具或函数作为工具传递给模型。底层会将这些转换为 OpenAI 工具 schema，如下所示：

```
{
    "name": "...",
    "description": "...",
    "parameters": {...}  # JSONSchema
}
```

并在每次模型调用时传递。

```python
from pydantic import BaseModel, Field


class GetWeather(BaseModel):
    """Get the current weather in a given location"""

    location: str = Field(description="The city and state, e.g. San Francisco, CA")


llm_with_tools = llm.bind_tools([GetWeather])
```

```python
ai_msg = llm_with_tools.invoke(
    "what is the weather like in San Francisco",
)
ai_msg
```

## 网络搜索

xAI 的旧版 Live 搜索配置使用 `search_parameters` 构造函数参数，现已弃用。要基于当前网络结果校准 Grok 响应，应绑定 xAI 内置的 `web_search` 工具：

```python
from langchain_xai import ChatXAI

llm = ChatXAI(model="grok-4", temperature=0).bind_tools([{"type": "web_search"}])

response = llm.invoke("Provide me a digest of world news in the last 24 hours.")
response.content
```

参考 [xAI 工具文档](https://docs.x.ai/developers/tools/overview) 获取当前内置工具列表，包括 Web 搜索和 X 搜索。

## 推理强度

[Certain xAI 模型](https://docs.x.ai/docs/models#model-pricing) 支持标准 [`reasoning_effort`](/langchain/oss/langchain/models#推理) 参数，用于控制模型推理程度。该参数可在模型初始化或单次调用时设置：

```python
from langchain_xai import ChatXAI

model = ChatXAI(model="grok-4.3")
response = model.invoke(
    "Analyze the trade-offs between microservices and monolithic architectures",
    reasoning_effort="high",
)
```

<Note>
    `reasoning_effort` 作为标准参数需要 `langchain-xai>=1.3.0`。 `ChatXAI` 将其嵌套在 `extra_body.reasoning_effort` 中。
</Note>

检查模型 [配置](/langchain/oss/langchain/models#模型配置文件) 获取支持的推理强度级别：

```python
model.profile["reasoning_effort_levels"]  # e.g. ['low', 'medium', 'high']
```
