## 设置

要访问 Fireworks 模型，您需要创建一个 Fireworks 账户，获取一个 API 密钥，并安装 `langchain-fireworks` 集成包。

### 凭证

前往 [fireworks.ai](https://app.fireworks.ai/login) 注册 Fireworks 并生成 API 密钥。完成后，设置 FIREWORKS_API_KEY 环境变量：

```python
import getpass
import os

if "FIREWORKS_API_KEY" not in os.environ:
    os.environ["FIREWORKS_API_KEY"] = getpass.getpass("Enter your Fireworks API key: ")
```

要启用模型调用的自动跟踪，设置您的 [LangSmith](https://docs.langchain.com/langsmith/observability) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain Fireworks 集成位于 `langchain-fireworks` 包中：

```bash
pip install -qU langchain-fireworks
```

## 实例化

现在我们可以实例化我们的模型对象并生成对话补全：

```python
from langchain_fireworks import ChatFireworks

llm = ChatFireworks(
    model="accounts/fireworks/models/kimi-k2-instruct-0905",
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2,
    # other params...
)
```

## 推理消耗

一些 Fireworks 托管的模型支持标准的 [`reasoning_effort`](/langchain/oss/langchain/models#推理) 参数，该参数控制模型执行的推理量。`ChatFireworks` 将其原样转发为 `reasoning_effort` 请求字段。支持值因模型而异。可以在模型构建时或每次调用时设置：

```python
from langchain_fireworks import ChatFireworks

model = ChatFireworks(model="accounts/fireworks/models/deepseek-v4-pro")
response = model.invoke(
    "Analyze the trade-offs between microservices and monolithic architectures",
    reasoning_effort="high",
)
```

<Note>
    使用 `reasoning_effort` 作为标准参数需要 `langchain-fireworks>=1.5.2`。
</Note>

检查模型的 [配置文件](/langchain/oss/langchain/models#模型配置文件) 以了解其支持的推理级别：

```python
model.profile["reasoning_effort_levels"]  # e.g. ['low', 'medium', 'high']
```
