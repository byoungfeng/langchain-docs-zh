文档加载器提供了一种**标准接口**，用于从不同来源（如Slack、Notion或Google Drive）将数据转换为LangChain的@[Document]格式。
这确保了数据无论来源如何，都能被一致处理。

所有文档加载器均实现@[`BaseLoader`]接口。

## 接口

每个文档加载器可能定义其 own参数，但共享统一API：

* `load()`：一次性加载所有文档。
* `lazy_load()`：惰性流式加载，适用于大数据集。

```python
from langchain_docling.loader import DoclingLoader

FILE_PATH = "https://arxiv.org/pdf/2408.09869"

loader = DoclingLoader(file_path=FILE_PATH)

# Load all documents
documents = loader.load()

# For large datasets, lazily load documents
for document in loader.lazy_load():
    print(document)
```
