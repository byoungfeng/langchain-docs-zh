## 基础用法

### 保存文档

使用 `MemorystoreDocumentSaver.add_documents(<documents>)` 保存 langchain 文档。初始化 `MemorystoreDocumentSaver` 类需要提供两个参数：

1. `client` - 一个 `redis.Redis` 客户端对象。
1. `key_prefix` - 一个用于 Redis 中存储文档的键前缀。

文档将存储为具有指定前缀 `key_prefix` 的随机生成的键。您也可以通过在 `add_documents` 方法中指定 `ids` 来定义键的后缀。

```python
import redis
from langchain_core.documents import Document
from langchain_google_memorystore_redis import MemorystoreDocumentSaver

test_docs = [
    Document(
        page_content="Apple Granny Smith 150 0.99 1",
        metadata={"fruit_id": 1},
    ),
    Document(
        page_content="Banana Cavendish 200 0.59 0",
        metadata={"fruit_id": 2},
    ),
    Document(
        page_content="Orange Navel 80 1.29 1",
        metadata={"fruit_id": 3},
    ),
]
doc_ids = [f"{i}" for i in range(len(test_docs))]

redis_client = redis.from_url(ENDPOINT)
saver = MemorystoreDocumentSaver(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_field="page_content",
)
saver.add_documents(test_docs, ids=doc_ids)
```

### 加载文档

初始化一个加载器以从 Memorystore for Redis 实例按特定前缀加载数据。

使用 `MemorystoreDocumentLoader.load()` 或 `MemorystoreDocumentLoader.lazy_load()` 加载 langchain 文档。`lazy_load` 返回一个仅在迭代时查询数据库的生成器。初始化 `MemorystoreDocumentLoader` 类需要提供以下参数：

1. `client` - 一个 `redis.Redis` 客户端对象。
1. `key_prefix` - 一个用于 Redis 中存储文档的键前缀。

```python
import redis
from langchain_google_memorystore_redis import MemorystoreDocumentLoader

redis_client = redis.from_url(ENDPOINT)
loader = MemorystoreDocumentLoader(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_fields=set(["page_content"]),
)
for doc in loader.lazy_load():
    print("Loaded documents:", doc)
```

### 删除文档

使用 `MemorystoreDocumentSaver.delete()` 删除 Memorystore for Redis 实例中所有具有指定前缀的键。您也可以指定键的后缀。

```python
docs = loader.load()
print("Documents before delete:", docs)

saver.delete(ids=[0])
print("Documents after delete:", loader.load())

saver.delete()
print("Documents after delete all:", loader.load())
```

## 高级用法

### 自定义文档内容与元数据

当初始化加载器包含超过一个内容字段时，`page_content` 字段将包含一个 JSON 编码的字符串，其顶层字段对应 `content_fields` 中指定的字段。

如果指定了 `metadata_fields`，则 `metadata` 字段将仅包含 `metadata_fields` 中指定的顶层字段。如果元数据字段的值存储为 JSON 编码字符串，将在加载前进行解码。

```python
loader = MemorystoreDocumentLoader(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_fields=set(["content_field_1", "content_field_2"]),
    metadata_fields=set(["title", "author"]),
)
```
