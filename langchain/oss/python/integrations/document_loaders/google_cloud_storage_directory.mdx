>[Google Cloud Storage](https://en.wikipedia.org/wiki/Google_Cloud_Storage) 是一个用于存储非结构化数据的托管服务。

这涵盖了如何从一个 `Google Cloud Storage (GCS) directory (bucket)` 加载文档对象。

```python
pip install -qU  langchain-google-community[gcs]
```

```python
from langchain_google_community import GCSDirectoryLoader
```

```python
loader = GCSDirectoryLoader(project_name="aist", bucket="testing-hwc")
```

```python
loader.load()
```

## 指定前缀

您还可以指定一个前缀，以便对要加载的文件进行更细粒度的控制——包括从特定文件夹加载所有文件。

```python
loader = GCSDirectoryLoader(project_name="aist", bucket="testing-hwc", prefix="fake")
```

```python
loader.load()
```

## 在加载单个文件失败时继续执行

GCS 存储桶中的文件在处理过程中可能会引发错误。启用 `continue_on_failure=True` 参数以允许静默失败。这意味着处理单个文件失败不会中断函数，而是会记录一条警告信息。

```python
loader = GCSDirectoryLoader(
    project_name="aist", bucket="testing-hwc", continue_on_failure=True
)
```

```python
loader.load()
```
