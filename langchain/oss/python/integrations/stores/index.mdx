## 概述

LangChain 提供了键值存储接口用于存储和检索数据。该键值存储接口主要用于缓存 [嵌入](/langchain/oss/python/integrations/embeddings)。

## 接口

所有 [`BaseStores`](https://reference.langchain.com/python/langchain-core/stores/BaseStore) 支持以下接口：

- `mget(key: Sequence[str]) -> List[Optional[bytes]]`: 获取多个键的内容，不存在键时返回 `None`
- `mset(key_value_pairs: Sequence[Tuple[str, bytes]]) -> None`: 设置多个键的内容
- `mdelete(key: Sequence[str]) -> None`: 删除多个键
- `yield_keys(prefix: Optional[str] = None) -> Iterator[str]`: 生成存储中的所有键，可按前缀过滤

<Note>
基座存储设计用于同时处理 **多个** 键值对以提升效率。这减少了网络往返次数，可能允许底层存储进行更高效的批量操作。
</Note>
