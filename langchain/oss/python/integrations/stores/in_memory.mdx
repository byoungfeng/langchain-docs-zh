## 概述

`InMemoryByteStore`是一个非持久的[key-value存储]`ByteStore`实现，它将所有内容存储在Python字典中。它适用于演示和不需要持久化到Python进程生命周期的场景。

### 安装

LangChain `InMemoryByteStore`集成位于`langchain-core`包中：

```python
pip install -qU langchain-core
```

## 实例化

现在你可以实例化你的字节存储：

```python
from langchain_core.stores import InMemoryByteStore

kv_store = InMemoryByteStore()
```

## 使用

你可以使用`mset`方法像这样在键下设置数据：

```python
kv_store.mset(
    [
        ["key1", b"value1"],
        ["key2", b"value2"],
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[b'value1', b'value2']
```

并且你可以使用`mdelete`方法删除数据：

```python
kv_store.mdelete(
    [
        "key1",
        "key2",
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[None, None]
```
