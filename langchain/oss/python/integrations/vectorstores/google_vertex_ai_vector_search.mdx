本页面介绍如何在Gemini企业级智能体平台（Gemini Enterprise Agent Platform）上使用Vector Search作为LangChain的向量存储。

## 概述

[Vector Search on Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search/overview) 是一种完全托管、高扩展、低延迟的解决方案，用于查找相似向量。它支持使用Google的ScaNN（Scalable Nearest Neighbors）技术进行精确和近似最近邻（ANN）搜索。

Vector Search on Gemini Enterprise Agent Platform提供两种版本：

- **[Vector Search 2.0](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search-2/overview)**: 使用Collections存储包含向量、元数据和内容的Data Objects。提供统一的数据模型和更简单快捷的操作。
- **[Vector Search 1.0](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search/overview)**: 部署Indexes到Endpoints，文档存储在Google Cloud Storage或Datastore中。

根据您使用的版本选择对应章节：
- [Vector Search 2.0](#vector-search-2-0) - 如果使用Collections
- [Vector Search 1.0](#vector-search-1-0) - 如果使用Indexes和Endpoints

从Vector Search on Gemini Enterprise Agent Platform 1.0迁移到2.0请参考[迁移指南](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search-2/migration-from-vs-1_0)。

# Vector Search 2.0

Vector Search 2.0使用Collections存储Data Objects。每个Data Object包含统一结构中的向量、元数据和内容。

## 前置条件

- 启用Gemini企业级智能体平台API和Vector Search API的Google Cloud项目
    ```bash
    gcloud services enable vectorsearch.googleapis.com aiplatform.googleapis.com --project "{PROJECT_ID}"
    ```
- 创建Vector Search Collection（参见[创建Collection](#创建collection（v2）)）
- 适当的IAM权限（`Vertex AI User`角色或等效权限）

## 创建Collection（V2）

使用Vector Search 2.0前需创建Collection。以下是兼容LangChain的创建方法：

```python
from google.cloud import vectorsearch_v1beta

# Configuration
PROJECT_ID = "your-project-id"
LOCATION = "us-central1"
COLLECTION_ID = "langchain-test-collection"

# Create the Vector Search service client
vector_search_service_client = vectorsearch_v1beta.VectorSearchServiceClient()

# Create the collection with schema compatible with LangChain
# IMPORTANT: To enable filtering, you must define filterable fields in data_schema.properties
request = vectorsearch_v1beta.CreateCollectionRequest(
    parent=f"projects/{PROJECT_ID}/locations/{LOCATION}",
    collection_id=COLLECTION_ID,
    collection={
        "display_name": "LangChain Test Collection",
        "description": "Collection for testing LangChain VectorSearchVectorStore with filtering",
        "data_schema": {
            "type": "object",
            "properties": {
                # Define fields you want to filter on
                "source": {"type": "string"},
                "category": {"type": "string"},
                "page": {"type": "number"},
                # Add more fields as needed for your specific use case
            },
        },
        "vector_schema": {
            # Vector field must be named "embedding" to match LangChain's default
            "embedding": {
                "dense_vector": {
                    "dimensions": 768  # For text-embedding-005
                }
            },
        },
    },
)

print(f"Creating collection: {COLLECTION_ID}")
operation = vector_search_service_client.create_collection(request=request)
print(f"Operation started: {operation.operation.name}")
print("Waiting for operation to complete...")

result = operation.result()
print(f"Collection created successfully!")
print(f"Resource name: {result.name}")
```

**重要说明：**
- 向量字段必须命名为`"embedding"`以匹配LangChain默认值（或通过`vector_field_name`参数指定）
- V2版本仅支持`data_schema.properties`中定义的字段进行过滤
- 维度应与嵌入模型匹配（768对于text-embedding-005）

## 初始化

```python
from langchain_google_vertexai import VectorSearchVectorStore, VertexAIEmbeddings

# Initialize embeddings
embeddings = VertexAIEmbeddings(model_name="text-embedding-005")

# Create vector store from a Collection
# Use the same PROJECT_ID, LOCATION, and COLLECTION_ID from collection creation
vector_store = VectorSearchVectorStore.from_components(
    project_id=PROJECT_ID,
    region=LOCATION,
    collection_id=COLLECTION_ID,
    embedding=embeddings,
    api_version="v2",
)
```

**关键参数：**
- `collection_id`: Vector Search Collection ID（必填）
- `api_version`: 必须设置为`"v2"`（必填）
- `project_id`: GCP项目ID（必填）
- `region`: Collection所在的GCP区域（必填）
- `vector_field_name`: Collection schema中向量的字段名称（默认`"embedding"`）

## 过滤

Vector Search 2.0使用字典式查询语法进行Data Objects过滤：

```python
# Simple equality filter
results = vector_store.similarity_search(
    "AI features",
    k=5,
    filter={"source": {"$eq": "docs"}}
)

# Comparison operators
results = vector_store.similarity_search(
    "recent pages",
    k=5,
    filter={"page": {"$gte": 10}}
)

# Logical AND
results = vector_store.similarity_search(
    "AI documentation",
    k=5,
    filter={
        "$and": [
            {"source": {"$eq": "docs"}},
            {"category": {"$eq": "AI"}}
        ]
    }
)

# Logical OR
results = vector_store.similarity_search(
    "documentation",
    k=5,
    filter={
        "$or": [
            {"source": {"$eq": "docs"}},
            {"source": {"$eq": "blog"}}
        ]
    }
)

# Less than
results = vector_store.similarity_search(
    "early pages",
    k=5,
    filter={"page": {"$lt": 5}}
)
```

**支持的操作符：**
- `$eq`: 等于
- `$ne`: 不等于
- `$lt`: 小于
- `$lte`: 小于或等于
- `$gt`: 大于
- `$gte`: 大于或等于
- `$and`: 逻辑AND
- `$or`: 逻辑OR
- `$not`: 逻辑NOT

See the [Vector Search 2.0 查询文档](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search-2/query-search/query) for more details.

## 删除操作

### 通过 IDs 删除

```python
# Delete specific documents by ID
ids_to_delete = ["id1", "id2", "id3"]
vector_store.delete(ids=ids_to_delete)
```

### 通过元数据过滤器删除

**注意**: 当前 V2 API 中元数据删除存在限制。推荐方案为：
1. 使用 `similarity_search` 并结合您的过滤器获取文档 IDs
2. 通过 IDs 删除

```python
# Recommended: Search first, then delete by IDs
results = vector_store.similarity_search(
    "query",  # Use a broad query
    k=1000,   # Get more results
    filter={"source": {"$eq": "old_docs"}}
)
ids_to_delete = [doc.metadata.get("id") for doc in results if "id" in doc.metadata]
vector_store.delete(ids=ids_to_delete)
```

 或者，如果您的环境支持直接删除元数据：

```python
# Direct deletion by metadata (may have limitations)
try:
    vector_store.delete(metadata={"source": {"$eq": "old_docs"}})
except Exception as e:
    # Fall back to search-then-delete approach
    print(f"Direct deletion failed: {e}")
```

## 高级功能

Vector Search 2.0 提供了超越传统密集向量搜索的多种高级搜索能力。

### 语义搜索

语义搜索会使用 Gemini 企业智能体平台模型从查询文本自动生成嵌入。您的集合必须配置 `vertex_embedding_config` 在向量方案中。

```python
# Semantic search with auto-generated embeddings
results = vector_store.semantic_search(
    query="Tell me about animals",
    k=5,
    search_field="embedding",  # Vector field with auto-embedding config
    task_type="RETRIEVAL_QUERY",  # Optimizes embeddings for search queries
    filter={"category": {"$eq": "wildlife"}}  # Optional filtering
)

for doc in results:
    print(f"Content: {doc.page_content}")
    print(f"Metadata: {doc.metadata}\n")
```

**任务类型:**
- `RETRIEVAL_QUERY`: 查询搜索（默认）
- `RETRIEVAL_DOCUMENT`: 文档索引
- `SEMANTIC_SIMILARITY`: 语义相似度任务
- `CLASSIFICATION`: 分类任务
- `CLUSTERING`: 聚类任务

### 文本搜索

文本搜索会在数据字段中执行关键词/全文匹配，无需使用嵌入。

```python
# Keyword search on data fields
results = vector_store.text_search(
    query="Python programming",
    k=10,
    data_field_names=["page_content", "title"]  # Fields to search in
)

for doc in results:
    print(f"Content: {doc.page_content}\n")
```

!!! note
    文本搜索不支持过滤器。如需过滤请使用 `semantic_search()` 或 `similarity_search()`

### 混合搜索

混合搜索通过 reciprocity rank fusion（RRF）融合自动生成的语义搜索（基于嵌入）和文本搜索（关键词匹配），生成最优排序结果。

```python
# Hybrid search: semantic understanding + keyword matching
results = vector_store.hybrid_search(
    query="Men's outfit for beach",
    k=10,
    search_field="embedding",  # Vector field with auto-embedding config
    data_field_names=["page_content"],  # Fields for text search
    task_type="RETRIEVAL_QUERY",
    filter={"price": {"$lt": 100}},  # Optional filter for semantic search
    semantic_weight=1.0,  # Weight for semantic results
    text_weight=1.0  # Weight for keyword results
)

for doc in results:
    print(f"Content: {doc.page_content}\n")
```

**权重参数:**
- 更高的 `semantic_weight`: 优先语义理解
- 更高的 `text_weight`: 优先精确关键词匹配
- 相等权重（默认）：平衡结果

在语义和文本搜索结果中排名均靠前的项目，将在合并结果中排名最高。

See the [Vector Search 2.0 文档](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search-2/overview) for more information.

### 自定义向量字段名

# Vector Search 1.0

本笔记本演示如何使用 `Google Cloud Vector Search on Gemini Enterprise Agent Platform` 向量数据库相关功能。

> [Gemini 企业智能体平台上的 Vector Search](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search/overview)，前身为 Vertex AI 匹配引擎，提供业界领先的规模化低延迟向量数据库。这些向量数据库通常被称为向量相似匹配或近似最近邻（ANN）服务。

### 创建空索引

**注意**：创建索引时需指定 "index_update_method" 参数，其取值范围为 "BATCH_UPDATE" 或 "STREAM_UPDATE"
> 批量索引适用于需要按固定周期（如每周或每月）更新索引的场景，例如系统处理周期性存储的数据。流式索引则适用于实时更新场景，例如书店需即时展示新库存信息。选择索引更新方式直接影响系统配置和运行要求。

参考 [官方文档](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search/create-manage-index#create-index-batch) 获取索引配置的详细信息

```python

    dimensions=DIMENSIONS,
    approximate_neighbors_count=150,
    distance_measure_type="DOT_PRODUCT_DISTANCE",
    index_update_method="STREAM_UPDATE",  # allowed values BATCH_UPDATE , STREAM_UPDATE
)
```

## 混合搜索

向量搜索支持混合搜索（Hybrid Search），这是一种在信息检索（IR）中广泛使用的架构模式，结合了语义搜索和关键词搜索（也称为基于令牌的搜索）。通过混合搜索，开发者可以同时利用两种方法的优点，从而提供更高质量的内容检索。

请阅读 [Gemini 企业智能体平台混合搜索文档](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search/about-hybrid-search) 以了解更多信息。

要使用混合搜索，我们需要适配一个稀疏嵌入向量izer，并独立处理嵌入过程（不依赖于Vector Search集成）。

稀疏嵌入向量izer的一个示例是sklearn的TfidfVectorizer，但也可以使用其他技术，例如BM25。

```python
# Define some sample data
texts = [
    "The cat sat on",
    "the mat.",
    "I like to",
    "eat pizza for",
    "dinner.",
    "The sun sets",
    "in the west.",
]

# optional IDs
ids = ["i_" + str(i + 1) for i in range(len(texts))]

# optional metadata
metadatas = [{"my_metadata": i} for i in range(len(texts))]
```

```python
from sklearn.feature_extraction.text import TfidfVectorizer

# Fit the TFIDF Vectorizer (This is usually done on a very large corpus of data to make sure that word statistics generalize well on new data)
vectorizer = TfidfVectorizer()
vectorizer.fit(texts)
```

```python
# Utility function to transform text into a TF-IDF Sparse Vector
def get_sparse_embedding(tfidf_vectorizer, text):
    tfidf_vector = tfidf_vectorizer.transform([text])
    values = []
    dims = []
    for i, tfidf_value in enumerate(tfidf_vector.data):
        values.append(float(tfidf_value))
        dims.append(int(tfidf_vector.indices[i]))
    return {"values": values, "dimensions": dims}
```

```python
# semantic (dense) embeddings
embeddings = embedding_model.embed_documents(texts)
# tfidf (sparse) embeddings
sparse_embeddings = [get_sparse_embedding(vectorizer, x) for x in texts]
```

```python
sparse_embeddings[0]
```

```python
# Add the dense and sparse embeddings in Vector Search

vector_store.add_texts_with_embeddings(
    texts=texts,
    embeddings=embeddings,
    sparse_embeddings=sparse_embeddings,
    ids=ids,
    metadatas=metadatas,
)
```

```python
# Run hybrid search
query = "the cat"
embedding = embedding_model.embed_query(query)
sparse_embedding = get_sparse_embedding(vectorizer, query)

vector_store.similarity_search_by_vector_with_score(
    embedding=embedding,
    sparse_embedding=sparse_embedding,
    k=5,
    rrf_ranking_alpha=0.7,  # 0.7 weight to dense and 0.3 weight to sparse
)
```
