## 基本用法

### 设置云 SQL 数据库值  

在 [Cloud SQL 实例页面](https://console.cloud.google.com/sql?_ga=2.223735448.2062268965.1707700487-2088871159.1707257687) 中查找数据库值。  

**注意：** 仅 MySQL 实例版本 **8.0.36** 或更高支持向量功能。  

对于现有实例，可能需要执行 [自助维护更新](https://cloud.google.com/sql/docs/mysql/self-service-maintenance) 以更新维护版本至 **MYSQL_8_0_36.R20240401.03_00** 或更高。更新后，需 [配置数据库标志](https://cloud.google.com/sql/docs/mysql/flags) 将 **cloudsql_vector** 标志设为 "On"。  

```python
# @title Set Your Values Here { display-mode: "form" }
REGION = "us-central1"  # @param {type: "string"}
INSTANCE = "my-mysql-instance"  # @param {type: "string"}
DATABASE = "my-database"  # @param {type: "string"}
TABLE_NAME = "vector_store"  # @param {type: "string"}
```
  
### MySQLEngine 连接池  

在将 Cloud SQL 配置为向量存储时，需要 `MySQLEngine` 对象。 `MySQLEngine` 用于配置连接池以支持应用程序连接并遵循最佳实践。  

使用 `MySQLEngine.from_instance()` 创建 `MySQLEngine` 需提供以下四项信息：  

1. `project_id` : Google Cloud 项目 ID（Cloud SQL 实例所在项目）  
1. `region` : Cloud SQL 实例所在区域  
1. `instance` : Cloud SQL 实例名称  
1. `database` : 要连接的 Cloud SQL 数据库名称  

默认使用 [IAM 数据库身份验证](https://cloud.google.com/sql/docs/mysql/iam-authentication#iam-db-auth) 作为认证方式。本库使用来自环境的 [应用默认凭据 (ADC)](https://cloud.google.com/docs/authentication/application-default-credentials) 的 IAM 主体的身份。  

更多 IAM 数据库身份验证信息请参考：  

* [为实例配置 IAM 数据库身份验证](https://cloud.google.com/sql/docs/mysql/create-edit-iam-instances)  
* [使用 IAM 数据库身份验证管理用户](https://cloud.google.com/sql/docs/mysql/add-manage-iam-users)  

也可选择 [内置数据库身份验证](https://cloud.google.com/sql/docs/mysql/built-in-authentication)（使用用户名/密码访问 Cloud SQL）。只需提供可选 `user` 和 `password` 参数给 `MySQLEngine.from_instance()`：  

* `user` : 用于内置认证的数据库用户名  
* `password` : 用于内置认证的数据库密码  

```python
from langchain_google_cloud_sql_mysql import MySQLEngine

engine = MySQLEngine.from_instance(
    project_id=PROJECT_ID, region=REGION, instance=INSTANCE, database=DATABASE
)
```

### 初始化默认 MySQLVectorStore  

创建 `MySQLVectorStore` 类实例需提供以下三项：  

1. `engine` : `MySQLEngine` 引擎实例  
1. `embedding_service` : LangChain 嵌入模型实例  
1. `table_name` : 要作为向量存储的 Cloud SQL 数据库表名  

```python
from langchain_google_cloud_sql_mysql import MySQLVectorStore

store = MySQLVectorStore(
    engine=engine,
    embedding_service=embedding,
    table_name=TABLE_NAME,
)
```
  
### 添加文本  

```python
import uuid

all_texts = ["Apples and oranges", "Cars and airplanes", "Pineapple", "Train", "Banana"]
```

## 高级用法

### 使用自定义元数据的 MySQLVectorStore  

向量存储可利用关系数据对相似度搜索进行过滤。  

创建包含自定义元数据列的表和 `MySQLVectorStore` 实例。  

```python
from langchain_google_cloud_sql_mysql import Column

# set table name
CUSTOM_TABLE_NAME = "vector_store_custom"

engine.init_vectorstore_table(
    table_name=CUSTOM_TABLE_NAME,
    vector_size=768,  # Gemini Enterprise Agent Platform model: textembedding-gecko@latest
    metadata_columns=[Column("len", "INTEGER")],
)


# initialize MySQLVectorStore with custom metadata columns
custom_store = MySQLVectorStore(
    engine=engine,
    embedding_service=embedding,
    table_name=CUSTOM_TABLE_NAME,
    metadata_columns=["len"],
    # connect to an existing VectorStore by customizing the table schema:
    # id_column="uuid",
    # content_column="documents",
    # embedding_column="vectors",
)
```
  
### 带元数据过滤的文档搜索  

在处理文档前可先通过元数据缩小范围。  

例如，使用 `filter` 参数对文档进行过滤。  

```python
import uuid

# add texts to the vector store
all_texts = ["Apples and oranges", "Cars and airplanes", "Pineapple", "Train", "Banana"]
metadatas = [{"len": len(t)} for t in all_texts]
ids = [str(uuid.uuid4()) for _ in all_texts]
custom_store.add_texts(all_texts, metadatas=metadatas, ids=ids)

# use filter on search
query_vector = embedding.embed_query("I'd like a fruit.")
docs = custom_store.similarity_search_by_vector(query_vector, filter="len >= 6")

print(docs)
```

```python
[Document(page_content='Pineapple', metadata={'len': 9}), Document(page_content='Banana', metadata={'len': 6}), Document(page_content='Apples and oranges', metadata={'len': 18}), Document(page_content='Cars and airplanes', metadata={'len': 18})]
```
