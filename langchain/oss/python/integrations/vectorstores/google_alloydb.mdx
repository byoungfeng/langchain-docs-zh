> [AlloyDB](https://cloud.google.com/alloydb) 是一个完全托管的关系型数据库服务，提供高性能、无缝集成和令人印象深刻的可扩展性。AlloyDB 与 PostgreSQL 100% 兼容。利用 AlloyDB 的 LangChain 集成扩展您的数据库应用，构建 AI 驱动的体验。

本笔记本介绍如何使用 `AlloyDB for PostgreSQL` 通过 `AlloyDBVectorStore` 类存储向量嵌入。

**AlloyDB AI 功能**：该集成原生支持 `alloydb_ai_nl` 和 `google_ml_integration` 扩展，提供数据库原生的 AI 能力：
* **零调参 ScaNN**：通过 `ScaNNIndex(mode="AUTO")` 实现自动调优、自我管理的向量索引。
* **列式引擎与向量辅助**：通过 `ColumnarEngine` 动态加速向量查询。
* **语义重排序**：使用 `AlloyDBDocumentCompressor`（基于 `google_ml.rank`）在数据库内原生重排序检索文档。
* **自然语言到 SQL**：使用 `AlloyDBToolkit` 构建原生 SQL 智能体。
* **数据库内 AI 工具**：直接在 SQL 中调用 LLM 函数（ `AlloyDBIfTool`、`AlloyDBSummaryTool`、`AlloyDBSentimentTool`）。
* **多模态嵌入**：在数据库内原生生成向量（例如使用 `aembed_image()`）。

更多关于该包的信息请参考 [GitHub](https://github.com/googleapis/langchain-google-alloydb-pg-python/)。

### AlloyDBEngine 连接池

作为向量存储的 AlloyDB 要求提供 `AlloyDBEngine` 对象。 `AlloyDBEngine` 配置连接池以实现应用程序与 AlloyDB 数据库的稳定连接，并遵循行业最佳实践。

使用 `AlloyDBEngine.from_instance()` 创建 `AlloyDBEngine` 需提供以下 5 个参数：

1. `project_id`：Google Cloud 项目 ID（AlloyDB 实例所在项目）
1. `region`：AlloyDB 实例所在区域
1. `cluster`：AlloyDB 集群名称
1. `instance`：AlloyDB 实例名称
1. `database`：要连接的数据库名称

默认使用 [IAM 数据库认证](https://cloud.google.com/alloydb/docs/connect-iam) 作为认证方式。本库会从环境变量中获取 [应用默认凭据 (ADC)](https://cloud.google.com/docs/authentication/application-default-credentials) 的 IAM 主体。

可选地，也可使用 [内置数据库认证](https://cloud.google.com/alloydb/docs/database-users/about)（需提供用户名/密码）。此时需传入 `user` 和 `password` 参数给 `AlloyDBEngine.from_instance()`：

* `user`：内置数据库认证及登录使用的数据库用户
* `password`：内置数据库认证及登录使用的数据库密码

**注意**：本教程演示异步接口。所有异步方法均有对应的同步方法。

```python
from langchain_google_alloydb_pg import AlloyDBEngine

engine = await AlloyDBEngine.afrom_instance(
    project_id=PROJECT_ID,
    region=REGION,
    cluster=CLUSTER,
    instance=INSTANCE,
    database=DATABASE,
)
```

## 创建自定义向量存储

向量存储可利用关系数据对相似度搜索进行过滤。

创建包含自定义元数据列的表。

```python
from langchain_google_alloydb_pg import Column

# Set table name
TABLE_NAME = "vectorstore_custom"

await engine.ainit_vectorstore_table(
    table_name=TABLE_NAME,
    vector_size=768,  # Gemini Enterprise Agent Platform model: textembedding-gecko@latest
    metadata_columns=[Column("len", "INTEGER")],
)


# Initialize AlloyDBVectorStore
custom_store = await AlloyDBVectorStore.create(
    engine=engine,
    table_name=TABLE_NAME,
    embedding_service=embedding,
    metadata_columns=["len"],
    # Connect to an existing VectorStore by customizing the table schema:
    # id_column="uuid",
    # content_column="documents",
    # embedding_column="vectors",
)
```
