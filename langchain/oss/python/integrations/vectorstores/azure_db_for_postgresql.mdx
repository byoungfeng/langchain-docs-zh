[Azure Database for PostgreSQL - Flexible Server](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/service-overview) 是基于开源PostgreSQL数据库引擎构建的关系型数据库服务。它是一个完全受管理的数据库即服务（DBaaS），能够以可预测的性能、安全性和高可用性处理关键业务负载，并支持动态扩展。

本指南展示如何利用集成[向量数据库](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/how-to-use-pgvector)存储文档到集合、创建索引并执行基于余弦距离、欧氏距离（L2）和内积（IP）等近似最近邻算法的向量搜索查询，从而定位与查询向量相近的文档。

## 向量支持

Azure Database for PostgreSQL - Flexible Server 支持高效存储和查询数百万量级的向量嵌入。同时可从概念验证（POC）扩展至生产环境：

* 提供熟悉的SQL接口查询向量嵌入和关系型数据
* 通过[DiskANN索引算法](https://aka.ms/pg-diskann-docs)提升`pgvector`性能，支持在百万级向量（100M+）上实现更快速且更精确的相似性搜索
* 通过单一数据库整合关系元数据、向量嵌入和时间序列数据
* 依托强大的PostgreSQL生态和Azure云服务，实现企业级功能（包括复制和高可用性）

## 认证

Azure Database for PostgreSQL - Flexible Server 支持基于密码和[Microsoft Entra](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/concepts-azure-ad-authentication)（原Azure Active Directory）的认证。

Entra认证允许使用Entra身份验证PostgreSQL服务器。这消除了单独管理数据库用户名和密码的需求，并复用Azure其他服务使用的安全机制。

本指南支持两种认证方式。您可在笔记本中后期配置是否使用Entra认证。

## 配置

Azure Database for PostgreSQL基于开源PostgreSQL。本集成使用专用[`langchain-azure-postgresql`](https://pypi.org/project/langchain-azure-postgresql/)软件包，提供DiskANN索引和Microsoft Entra认证优化支持。

首先下载合作伙伴软件包：

```python
pip install -qU langchain-azure-postgresql langchain-openai azure-identity
```

### 启用pgvector

参考[Azure Database for PostgreSQL的启用说明](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/how-to-use-pgvector)。

### 设置凭据

需要Azure Database for PostgreSQL的[连接详情](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/quickstart-create-server-portal#get-the-connection-information)，并将其作为环境变量运行本笔记本。

将`USE_ENTRA_AUTH`标志设置为`True`以使用Microsoft Entra认证。若使用Entra认证，仅需提供主机和数据库名；若使用密码认证，还需设置用户名和密码。

```python
import getpass
import os

USE_ENTRA_AUTH = True

# Supply the connection details for the database
os.environ["DBHOST"] = "REPLACE_WITH_SERVER_NAME"
os.environ["DBNAME"] = "REPLACE_WITH_DATABASE_NAME"
os.environ["SSLMODE"] = "require"

if not USE_ENTRA_AUTH:
    # If using a username and password, supply them here
    os.environ["DBUSER"] = "REPLACE_WITH_USERNAME"
    os.environ["DBPASSWORD"] = getpass.getpass("Database Password:")
```

## 初始化

### 使用Microsoft Entra认证

以下章节演示如何使用LangChain实现Microsoft Entra认证。LangChain Azure Postgres包中的`AzurePGConnectionPool`类通过`DefaultAzureCredential`库从 `azure.identity` 获取Azure数据库服务令牌。

可将连接配置传入LangChain向量存储的`connection`参数 `AzurePGVectorStore` 中。

#### 登录 Azure

要登录 Azure，请确保已安装 [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli)。您需要在终端中运行以下命令：

```bash
az login
```

登录成功后，以下代码将能够获取令牌。

```python
from langchain_azure_postgresql.common import (
    BasicAuth,
    AzurePGConnectionPool,
    ConnectionInfo,
)
from langchain_azure_postgresql.langchain import AzurePGVectorStore

entra_connection_pool = AzurePGConnectionPool(
    azure_conn_info=ConnectionInfo(
        host=os.environ["DBHOST"], dbname=os.environ["DBNAME"]
    )
)
```

### 密码身份验证

如果未使用 Microsoft Entra 认证，可通过 `BasicAuth` 类使用用户名和密码：

```python
basic_auth_connection_pool = AzurePGConnectionPool(
    azure_conn_info=ConnectionInfo(
        host=os.environ["DBHOST"],
        dbname=os.environ["DBNAME"],
        credentials=BasicAuth(
            username=os.environ["DBUSER"],
            password=os.environ["DBPASSWORD"],
        ),
    )
)
```

### 创建向量存储

```python
from langchain_core.documents import Document
from langchain_azure_postgresql.langchain import AzurePGVectorStore

table_name = "my_docs"

# The connection is either using Entra ID or Basic Auth
connection = entra_connection_pool if USE_ENTRA_AUTH else basic_auth_connection_pool

vector_store = AzurePGVectorStore(
    embedding=embeddings,
    table_name=table_name,
    connection=connection,
)
```

```text

Embedding type is not specified, defaulting to 'vector'.
Embedding dimension is not specified, defaulting to 1536.
Embedding index is not specified, defaulting to 'DiskANN' with 'vector_cosine_ops' opclass.
```

## 配置向量存储参数

在初始化 `AzurePGVectorStore` 时，可覆盖元数据类型、嵌入维度、索引类型等默认参数。这允许您根据具体用例和数据需求定制向量存储。

**关键配置选项：**

- `metadata_column_type`：元数据列类型（默认: `'jsonb'`）。可设置为 `'jsonb'`、`'text'` 等。
- `embedding_column_type`：嵌入列类型（默认: `'vector'`）。
- `embedding_dimension`：嵌入向量维度（默认: `1536`）。
- `embedding_index_type`：向量检索索引类型（默认: `'DiskANN'`）。其他选项包括 `'ivfflat'`、`'hnsw'` 等。
- `embedding_index_opclass`：索引算子类（默认: `'vector_cosine_ops'`）。

**示例：**

```python
vector_store = AzurePGVectorStore(
    embedding=embeddings,
    table_name=table_name,
    connection=connection,
    metadata_column_type="jsonb",           # or "text"
    embedding_column_type="vector",
    embedding_dimension=768,                # set to match your model's output
    embedding_index_type="DiskANN",         # or "ivfflat", "hnsw", etc.
    embedding_index_opclass="vector_cosine_ops",  # or "vector_l2_ops", etc.
)
```

## 初始化 DiskANN 向量索引以实现更高效的向量检索

[DiskANN](https://aka.ms/pg-diskann-blog) 是一种可扩展的近似最近邻搜索算法，适用于任何规模的向量检索。它能实现高召回率、高查询吞吐量、低查询延迟，甚至适用于十亿级数据集。这些特性使其成为处理大规模数据的有力工具。

## 查询向量存储

在创建向量存储并添加相关文档后，您可在链或智能体中查询向量存储。

### 过滤

向量存储支持通过 `FilterCondition`、`OrFilter` 和 `AndFilter`（位于 [LangChain Azure PostgreSQL](https://pypi.org/project/langchain-azure-postgresql/) 包中）对文档元数据字段应用过滤：

| 运算符 | 含义/类别                |
|--------|-------------------------|
| `=`   | 等于                    |
| `!=`   | 不等于                  |
| `<`   | 小于                    |
| `<=`   | 小于或等于              |
| `>`   | 大于                    |
| `>=`   | 大于或等于              |
| `in`   | 特殊处理（在）            |
| `not in`   | 特殊处理（不在）          |
| `is null`   | 特殊处理（为空）          |
| `is not null`   | 特殊处理（非空）          |
| `between`   | 特殊处理（介于）           |
| `not between`   | 特殊处理（不介于）           |
| `like`   | 文本（模糊匹配）           |
| `ilike`   | 文本（不区分大小写模糊匹配） |
| `AND`   | 逻辑（与）                |
| `OR`   | 逻辑（或）                |

### 直接查询

执行简单的相似度搜索可按如下方式：

```python
from langchain_azure_postgresql import FilterCondition, AndFilter

results = vector_store.similarity_search(
    "kitty",
    k=10,
    filter=FilterCondition(
        column="(metadata->>'doc_id')::int",
        operator="in",
        value=[1, 5, 2, 9],
    ),
)

for doc in results:
    print("* " + doc.page_content + " [" + str(doc.metadata) + "]")
```

```text
* there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
* ducks are also found in the pond [{'topic': 'animals', 'doc_id': 2, 'location': 'pond'}]
* the new art exhibit is fascinating [{'topic': 'art', 'doc_id': 5, 'location': 'museum'}]
* the library hosts a weekly story time for kids [{'topic': 'reading', 'doc_id': 9, 'location': 'library'}]
```

若需使用 `AND` 逻辑过滤器，示例如下：

```python
results = vector_store.similarity_search(
    "ducks",
    k=10,
    filter=AndFilter(
        AND=[
            FilterCondition(
                column="(metadata->>'doc_id')::int",
                operator="in",
                value=[1, 5, 2, 9],
            ),
            FilterCondition(
                column="metadata->>'location'",
                operator="in",
                value=["pond", "market"],
            ),
        ]
    ),
)

for doc in results:
    print("* " + doc.page_content + " [" + str(doc.metadata) + "]")
```

```text
* ducks are also found in the pond [{'topic': 'animals', 'doc_id': 2, 'location': 'pond'}]
* there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
```

若需执行相似度搜索并获取对应分数，可运行：

```python
results = vector_store.similarity_search_with_score(query="cats", k=1)
for doc, score in results:
    print(f"* [SIM={score:3f}] {doc.page_content} [{doc.metadata}]")
```

```text
* [SIM=0.528167] there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
```

若需使用最大边际相关性搜索：

