本笔记本介绍如何在LangChain中使用Weaviate向量存储，需通过`langchain-weaviate`包实现。

> [Weaviate](https://weaviate.io/)是开源向量数据库。它允许您存储您喜爱的机器学习模型的数据对象和向量嵌入，并无缝扩展至数十亿级数据对象。

使用此集成需已运行Weaviate数据库实例。

## 最小版本

本模块要求Weaviate `1.23.7`或更高版本。但建议使用最新版Weaviate。

## 连接到weaviate

本笔记本假设您已运行本地Weaviate实例（[`http://localhost:8080`端口50051开放gRPC流量](https://weaviate.io/blog/grpc-performance-improvements)），并通过以下方式连接：

```python
weaviate_client = weaviate.connect_to_local()
```

### 其他部署选项

[Weaviate支持多种部署方式](https://weaviate.io/developers/weaviate/starter-guides/which-weaviate)，如[Weaviate云服务（WCS）](https://console.weaviate.cloud)、[Docker](https://weaviate.io/developers/weaviate/installation/docker-compose)或[Kubernetes](https://weaviate.io/developers/weaviate/installation/kubernetes)。

若采用其他部署方式，可[此处阅读更多](https://weaviate.io/developers/weaviate/client-libraries/python#instantiate-a-client)了解连接方法。您可以使用不同[辅助函数](https://weaviate.io/developers/weaviate/client-libraries/python#python-client-v4-helper-functions)或[创建自定义实例](https://weaviate.io/developers/weaviate/client-libraries/python#python-client-v4-explicit-connection)。

> 注意需要`v4`客户端API，将创建`weaviate.WeaviateClient`对象。

### 认证

部分Weaviate实例（如WCS部署）启用认证机制，如API密钥或用户名+密码认证。

请参考[客户端认证指南](https://weaviate.io/developers/weaviate/client-libraries/python#authentication)及[深度认证配置页面](https://weaviate.io/developers/weaviate/configuration/authentication)获取详细信息。

### 连接到现有集合（复用索引）

若本地Weaviate已创建集合，可直接连接：

```python
from langchain_weaviate import WeaviateVectorStore

store = WeaviateVectorStore(
    client=weaviate_client,
    index_name="Test",
    text_key="text",
)
```

通过添加`alpha=0`可实现纯关键词搜索：

```python
docs = db.similarity_search(query, alpha=0)
```

## 异步使用

`langchain-weaviate`支持Weaviate原生异步客户端。将[`WeaviateAsyncClient`](https://weaviate.io/developers/weaviate/client-libraries/python/async)作为`client_async`参数（与同步的`client`参数一同）时，异步方法（`afrom_texts`、`aadd_texts`、`asimilarity_search`、`asimilarity_search_with_score`、`amax_marginal_relevance_search`及其变体）将直接使用该客户端，而非在线程池中运行同步客户端。

<Note>
原生异步支持需要`langchain-weaviate` `0.0.8`或更高版本。若未传入`client_async`参数，存储将退化为在执行器中运行同步客户端并记录警告（代码仍可运行但无法获得真正的异步I/O）。

</Note>

与同步的`connect_to_local()`辅助函数不同，`use_async_with_*`辅助函数返回尚未连接的客户端——必须先`await client.connect()`再使用。同步的`client`仍需保留，因其用于集合/方案管理。

```python
import weaviate
from langchain_weaviate import WeaviateVectorStore

# Synchronous client (used for schema/collection management)
weaviate_client = weaviate.connect_to_local()

# Asynchronous client — must be connected explicitly
weaviate_client_async = weaviate.use_async_with_local()
await weaviate_client_async.connect()

db = await WeaviateVectorStore.afrom_texts(
    texts,
    embeddings,
    client=weaviate_client,
    client_async=weaviate_client_async,
)

results = await db.asimilarity_search(
    "What did the president say about Ketanji Brown Jackson", k=3
)
for doc in results:
    print(doc.page_content[:100] + "...")
```

完成操作后需关闭两个客户端以释放连接：

```python
weaviate_client.close()
await weaviate_client_async.close()
```

### 检索增强生成

另一个结合大语言模型和向量存储的流行应用是检索增强生成（RAG）。这是一种技术，使用检索器从向量存储中查找相关信息，然后基于检索到的数据和提示词使用大语言模型生成输出。

我们采用类似的初始配置：

```python
with open("state_of_the_union.txt") as f:
    state_of_the_union = f.read()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
texts = text_splitter.split_text(state_of_the_union)
```

```python
docsearch = WeaviateVectorStore.from_texts(
    texts,
    embeddings,
    client=weaviate_client,
    metadatas=[{"source": f"{i}-pl"} for i in range(len(texts))],
)
```
