```python
pip install langchain-hana
```

### 凭证

确保您的SAP HANA实例正在运行。从环境变量加载数据库凭据并创建连接：

```python
import os

from dotenv import load_dotenv
from hdbcli import dbapi

load_dotenv()
# Use connection settings from the environment
connection = dbapi.connect(
    address=os.environ.get("HANA_DB_ADDRESS"),
    port=os.environ.get("HANA_DB_PORT"),
    user=os.environ.get("HANA_DB_USER"),
    password=os.environ.get("HANA_DB_PASSWORD")
)
```

Learn more about SAP HANA in [What is SAP HANA?](https://www.sap.com/products/data-cloud/hana/what-is-sap-hana.html).

## 初始化

初始化 `HanaDB` 向量存储需要数据库连接和嵌入实例。SAP HANA Cloud Vector Engine支持外部和内部嵌入。

- ### 使用外部嵌入

<EmbeddingTabs/>

```python
# | output: false
# | echo: false
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-large")
```

- ### 使用内部嵌入

Alternatively，您可以直接在SAP HANA中通过其原生 `VECTOR_EMBEDDING()` 函数计算嵌入。要启用此功能，创建一个使用 `HanaInternalEmbeddings` 内部模型ID的实例，并将其传递给 `HanaDB`。请注意， `HanaInternalEmbeddings` 实例专门设计用于与 `HanaDB` 配合使用，不适用于其他向量存储实现。如需了解更多关于内部嵌入的信息，请参考[SAP HANA VECTOR_EMBEDDING Function](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-vector-engine-guide/vector-embedding-function-vector)。

> **Caution:** 请确保您的SAP HANA Cloud实例已启用NLP功能。

```python
from langchain_hana import HanaInternalEmbeddings

embeddings = HanaInternalEmbeddings(internal_embedding_model_id="SAP_NEB.20240715")

# optionally, you can specify a remote source to use models from your deployed SAP AI CORE instance

# embeddings = HanaInternalEmbeddings(
#     internal_embedding_model_id="your-embedding-model-id",
#     remote_source_schema="your-remote-source-schema-name",
#     remote_source="your-remote-source-name",
# )
```

在获得连接和嵌入实例后，通过 `HanaDB` 创建向量存储，并传入存储向量的表名：

```python
from langchain_hana import HanaDB

db = HanaDB(
    embedding=embeddings, connection=connection, table_name="MY_TABLE"
)
```

## 管理向量存储

在创建向量存储后，我们可以通过添加和删除不同项目与之交互。

### 向向量存储添加项

我们可通过 `add_documents` 函数向向量存储添加项目。

```python
from langchain_core.documents import Document

docs = [Document(page_content="Some text"), Document(page_content="Other docs")]
db.add_documents(docs)
```

添加带元数据的文档。

```python
docs = [
    Document(
        page_content="foo",
        metadata={"start": 100, "end": 150, "doc_name": "foo.txt", "quality": "bad"},
    ),
    Document(
        page_content="bar",
        metadata={"start": 200, "end": 250, "doc_name": "bar.txt", "quality": "good"},
    ),
]
db.add_documents(docs)
```

添加带map merge插入的文档。

> Note `use_map_merge` 仅作为关键字参数接受，且仅适用于 `HanaInternalEmbeddings` 实例。

```python
# a use_map_merge flag can be supplied for faster insertion
db.add_documents(docs, use_map_merge=True)
```

### 从向量存储删除项

```python
db.delete(filter={"quality": "bad"})
```

## 查询向量存储

### 直接查询

#### 相似度搜索

可通过以下方式执行带元数据过滤的简单相似度搜索：

```python
docs = db.similarity_search("foobar", k=2, filter={"quality": "bad"})
# With filtering on "quality"=="bad", only one document should be returned
for doc in docs:
    print("-" * 80)
    print(doc.page_content)
    print(doc.metadata)
```

```text
--------------------------------------------------------------------------------
foo
{'start': 100, 'end': 150, 'doc_name': 'foo.txt', 'quality': 'bad'}
```

#### MMR 搜索

可通过以下方式执行带元数据过滤的Maximal Marginal Relevance（MMR）搜索：

```python
docs = db.max_marginal_relevance_search("foobar", k=2, fetch_k=5, filter={"quality": "bad"})
for doc in docs:
    print("-" * 80)
    print(doc.page_content)
    print(doc.metadata)
```

```text
--------------------------------------------------------------------------------
foo
{'start': 100, 'end': 150, 'doc_name': 'foo.txt', 'quality': 'bad'}
```

## 距离相似性算法

`HanaDB` 支持以下距离相似性算法：
- 余弦相似度（默认）
- 欧氏距离（L2）

您可以通过使用 `distance_strategy` 参数在初始化 `HanaDB` 实例时指定距离策略。

```python
from langchain_hana.utils import DistanceStrategy
db = HanaDB(
    embedding=embeddings,
    connection=connection,
    distance_strategy=DistanceStrategy.EUCLIDEAN_DISTANCE,
    # distance_strategy=DistanceStrategy.COSINE_SIMILARITY,  # (default)
    table_name="MY_TABLE",
)
```

## 创建 HNSW 索引

向量索引可显著加速向量 top-k 最近邻查询。用户可通过 `create_hnsw_index` 函数创建分层导航小世界（HNSW）向量索引。

对于数据库层面的索引创建说明，请参考 [官方文档](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-vector-engine-guide/create-vector-index-statement-data-definition)。

```python
db = HanaDB(
    embedding=embeddings, connection=connection, table_name="MY_TABLE"
)
db.create_hnsw_index(
    index_name="MY_TABLE_index",
    m=100,  # Max number of neighbors per graph node (valid range: 4 to 1000)
    ef_construction=200,  # Max number of candidates during graph construction (valid range: 1 to 100000)
    ef_search=500,  # Min number of candidates during the search (valid range: 1 to 100000)
)
```

若未指定其他参数，将使用默认值

默认值：m=64, ef_construction=128, ef_search=200

默认索引名称为：\<TABLE_NAME>_idx

## 高级过滤

除基础值过滤功能外，还支持更复杂的过滤操作。
下表列出了可用过滤运算符。

| 运算符 | 语义解释               | 支持的操作数数据类型       |
|--------|-----------------------|---------------------------|
| `$eq`  | 等于（==）             | int, float, str, bool, date 对象, None      |
| `$ne`  | 不等于（!=）          | int, float, str, bool, date 对象, None      |
| `$lt`  | 小于（&lt;）             | int, float, str, date 对象         |
| `$lte`   | 小于等于（&lt;=）        | int, float, str, date 对象         |
| `$gt`  | 大于（>）             | int, float, str, date 对象         |
| `$gte`   | 大于等于（>=）        | int, float, str, date 对象         |
| `$in`  | 包含在给定值集合中（in） | 同类型值列表（int, float, str, bool, date 对象） |
| `$nin`   | 不包含在给定值集合中（not in） | 同类型值列表（int, float, str, bool, date 对象） |
| `$between` | 位于两个边界值范围内   | 两个值列表（int, float, str, date 对象） |
| `$like`  | 基于SQL LIKE语义的文本相等（使用%作为通配符） | str |
| `$contains`  | 过滤包含特定关键词的文档 | 非空str |
| `$and`   | 逻辑"且"（支持多个操作数） | 过滤器列表 |
| `$or`    | 逻辑"或"（支持多个操作数） | 过滤器列表 |

```python
# Prepare some test documents
docs = [
    Document(
        page_content="First",
        metadata={"name": "Adam Smith", "is_active": True, "id": 1, "height": 10.0},
    ),
    Document(
        page_content="Second",
        metadata={"name": "Bob Johnson", "is_active": False, "id": 2, "height": 5.7},
    ),
    Document(
        page_content="Third",
        metadata={"name": "Jane Doe", "is_active": True, "id": 3, "height": 2.4},
    ),
]

db = HanaDB(
    connection=connection,
    embedding=embeddings,
    table_name="LANGCHAIN_DEMO_ADVANCED_FILTER",
)

# Delete already existing documents from the table
db.delete(filter={})
db.add_documents(docs)


# Helper function for printing filter results
def print_filter_result(result):
    if len(result) == 0:
        print("<empty result>")
    for doc in result:
        print(doc.metadata)
```

## 结果重排序

可通过向 `similarity_search` 方法传递 `rerank_config` 字典对相似度搜索结果进行重排序。重排序使用 SAP HANA 的 `CROSS_ENCODE` 函数及跨编码模型实现。

`rerank_config` 字典支持以下字段：

- **`query`** *(str, 必填)* — 用于重排序的查询文本。未提供时使用原始相似度搜索查询。
- **`model_id`** *(str, 必填)* — 跨编码模型ID
- **`top_n`** *(int, 可选)* — 重排序后返回的顶部结果数（默认3）
- **`rank_fields`** *(list[str], 可选)* — 需包含在重排序中的元数据字段列表

> **注意**：确保您的SAP HANA Cloud实例已启用NLP功能以使用重排序功能。更多详情请见 [SAP HANA数据库附加功能](https://help.sap.com/docs/hana-cloud/sap-hana-cloud-administration-guide/sap-hana-database-additional-features?version=hanacloud)。

```python
# Prepare sample documents with metadata
docs = [

    Document(
```

### 基础重排序

使用 `rerank_config` 参数执行相似度搜索并重排序：

```python

    "model_id": os.environ.get("HANA_DB_RERANK_MODEL_ID"),  # e.g., "SAP_CER.20250701"
    "top_n": 2,
}

results = db.similarity_search(
    "AI technology",
    k=3,
    rerank_config=rerank_config
)

print("Reranked results:")
for doc in results:
    print("-" * 80)
    print(f"Content: {doc.page_content}")
    print(f"Metadata: {doc.metadata}")
```

### 独立重排序使用 HanaReranker

若需对重排序过程进行更精细控制，可直接使用 `HanaReranker` 类作为文档压缩器。此方法适用于从任意来源而非仅相似度搜索结果中重排序文档：

```python
from langchain_hana import HanaReranker

# Create a standalone reranker
reranker = HanaReranker(
    connection=connection,
    model_id=os.environ.get("HANA_DB_RERANK_MODEL_ID"),
)

# Documents to rerank (can come from any source)
documents = [
    Document(page_content="Python programming basics"),
    Document(page_content="Advanced machine learning techniques"),
    Document(page_content="Introduction to neural networks"),
    Document(page_content="Deep learning applications"),
    Document(page_content="Reinforcement learning strategies"),
    Document(page_content="Natural language processing techniques"),
]

# Rerank documents based on a query using compress_documents (returns top min(5, len(documents)))
# Reranking scores will be added to the metadata of each document under the key "relevance_score"
reranked_docs = reranker.compress_documents(documents, query="AI and deep learning")

print("Compressed documents:")
for doc in reranked_docs:
    print("-" * 80)
    print(f"Content: {doc.page_content}")
    print(f"Relevance score: {doc.metadata.get('relevance_score'):.4f}")

# Or use the rerank method for more control over top_n
results = reranker.rerank(documents, query="machine learning", top_n=2)
print("\nTop 2 reranked results:")
for idx, score, doc in results:
    print(f"  [{idx}] Score: {score:.4f} - {doc.page_content}")
```

```text

--------------------------------------------------------------------------------
Content: Deep learning applications
Relevance score: 0.2188
--------------------------------------------------------------------------------
Content: Advanced machine learning techniques
Relevance score: 0.0748
--------------------------------------------------------------------------------
```

```python
import struct
# Helper function to parse fvecs format for REAL_VECTOR
def parseFvecs(fvecs):
    dim = struct.unpack_from("<I", fvecs, 0)[0]
    return list(struct.unpack_from("<%sf" % str(dim), fvecs, 4))
```

### 创建 HNSW 向量索引

使用 `create_hnsw_index` 函数创建分层导航小世界（HNSW）向量索引，可显著加速向量查询的 top-k 最近邻搜索。

```python
# HanaDB instance uses cosine similarity as default:
db_cosine = HanaDB(
    embedding=embeddings, connection=connection, table_name="STATE_OF_THE_UNION"
)

# Attempting to create the HNSW index with default parameters
db_cosine.create_hnsw_index()  # If no other parameters are specified, the default values will be used
# Default values: m=64, ef_construction=128, ef_search=200
# The default index name will be: STATE_OF_THE_UNION_COSINE_idx


# Creating a HanaDB instance with L2 distance as the similarity function and defined values
db_l2 = HanaDB(
    embedding=embeddings,
    connection=connection,
    table_name="STATE_OF_THE_UNION",
    distance_strategy=DistanceStrategy.EUCLIDEAN_DISTANCE,  # Specify L2 distance
)

# This will create an index based on L2 distance strategy.
db_l2.create_hnsw_index(
    index_name="STATE_OF_THE_UNION_L2_index",
    m=100,  # Max number of neighbors per graph node (valid range: 4 to 1000)
    ef_construction=200,  # Max number of candidates during graph construction (valid range: 1 to 100000)
    ef_search=500,  # Min number of candidates during the search (valid range: 1 to 100000)
)

# Use L2 index to perform MMR
docs = db_l2.max_marginal_relevance_search(query, k=2, fetch_k=20)
for doc in docs:
    print("-" * 80)
    print(doc.page_content)
```

**关键点**：

- **相似度函数**：索引默认使用余弦相似度。若需使用其他相似度函数（如 `L2` 距离），需在 `HanaDB` 实例初始化时指定。
- **默认参数**：在 `create_hnsw_index` 函数中，若未提供 `m`、`ef_construction` 或 `ef_search` 等参数的定制值，将自动使用 `m=64`、`ef_construction=128`、`ef_search=200` 等默认值。这些值确保索引在合理性能下无需用户干预即可创建。
