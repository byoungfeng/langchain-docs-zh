### 初始化表

 `SpannerVectorStore` 类实例需要一个包含id、content和embeddings字段的数据库表。

可以使用辅助方法 `init_vector_store_table()` 来创建具有正确模式的表。

```python
from langchain_google_spanner import SecondaryIndex, SpannerVectorStore, TableColumn

SpannerVectorStore.init_vector_store_table(
    instance_id=INSTANCE,
    database_id=DATABASE,
    table_name=TABLE_NAME,
    # Customize the table creation
    # id_column="row_id",
    # content_column="content_column",
    # metadata_columns=[
    #     TableColumn(name="metadata", type="JSON", is_null=True),
    #     TableColumn(name="title", type="STRING(MAX)", is_null=False),
    # ],
    # secondary_indexes=[
    #     SecondaryIndex(index_name="row_id_and_title", columns=["row_id", "title"])
    # ],
)
```

embeddings = VertexAIEmbeddings(

)

### SpannerVectorStore

初始化 `SpannerVectorStore` 类需要提供4个必填参数，其他参数为可选且仅在非默认值时需要传递

1. `instance_id` - Spanner实例名称
1. `database_id` - Spanner数据库名称
1. `table_name` - 数据库中存储文档及嵌入的表名称
1. `embedding_service` - 用于生成嵌入的Embeddings实现

```python
db = SpannerVectorStore(
    instance_id=INSTANCE,
    database_id=DATABASE,
    table_name=TABLE_NAME,
    embedding_service=embeddings,
    # Connect to a custom vector store table
    # id_column="row_id",
    # content_column="content",
    # metadata_columns=["metadata", "title"],
)
```

#### 添加文档

向向量存储中添加文档。

```python
import uuid

from langchain_community.document_loaders import HNLoader

loader = HNLoader("https://news.ycombinator.com/item?id=34817881")

documents = loader.load()
ids = [str(uuid.uuid4()) for _ in range(len(documents))]
db.add_documents(documents, ids)
```

#### 搜索文档

使用相似度搜索在向量存储中检索文档。

```python
db.similarity_search(query="Explain me vector store?", k=3)
```

#### 搜索文档

使用最大边际相关性搜索在向量存储中检索文档。

```python
db.max_marginal_relevance_search("Testing the langchain integration with spanner", k=3)
```

#### 删除文档

从向量存储中移除文档，需使用初始化VectorStore时设置的 `row_id` 字段对应的ID。

```python
db.delete(ids=["id1", "id2"])
```

#### 删除文档

可通过文档本身删除向量存储中的文档。VectorStore初始化时提供的content字段和元数据字段将用于查找对应行，所有匹配行将被删除。

```python
db.delete(documents=[documents[0], documents[1]])
```
