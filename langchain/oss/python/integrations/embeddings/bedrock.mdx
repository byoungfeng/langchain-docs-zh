> [Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一个完全托管的服务，提供来自 `AI21 Labs`、`Anthropic`、`Cohere`、`Meta`、`Stability AI` 和 `Amazon` 等领先 AI 公司的高性能基础模型（FMs）的单一 API，并附带构建生成式 AI 应用所需的广泛功能，涵盖安全、隐私和负责任 AI。通过 `Amazon Bedrock`，您可以轻松实验并评估适用于业务场景的顶尖 FMs，利用您的数据进行私有化定制（如通过微调和 `Retrieval Augmented Generation`（`RAG`）），并构建能够执行任务、调用企业系统和数据源的智能体。由于 `Amazon Bedrock` 是无服务架构，您无需管理任何基础设施，并可通过已熟悉的 AWS 服务安全集成和部署生成式 AI 功能到您的应用程序中。

```python
from langchain_aws import BedrockEmbeddings

embeddings = BedrockEmbeddings(
    credentials_profile_name="bedrock-admin", region_name="us-east-1"
)
```

```python
embeddings.embed_query("This is a content of the document")
```

```python
embeddings.embed_documents(
    ["This is a content of the document", "This is another document"]
)
```

```python
# async embed query
await embeddings.aembed_query("This is a content of the document")
```

```python
# async embed documents
await embeddings.aembed_documents(
    ["This is a content of the document", "This is another document"]
)
```
