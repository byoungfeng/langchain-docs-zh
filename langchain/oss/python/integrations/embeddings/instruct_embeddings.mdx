>The `hkunlp/instructor-*` 家族引入了指令调优的句子嵌入。它们已被现代指令感知模型广泛取代，但原始模型仍在Hugging Face上提供，可通过 `HuggingFaceInstructEmbeddings` 类别使用。

对于新项目，建议使用 `HuggingFaceEmbeddings`（参考[`langchain-huggingface`](/langchain/oss/python/integrations/embeddings/sentence_transformers)）配合当前指令感知模型 `intfloat/e5-large-v2`、`Qwen/Qwen3-Embedding-0.6B` 或 `BAAI/bge-m3`。通过 `encode_kwargs` 和 `query_encode_kwargs` 传递查询和文档提示：

```python
from langchain_huggingface import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(
    model_name="intfloat/e5-large-v2",
    encode_kwargs={"prompt": "passage: "},
    query_encode_kwargs={"prompt": "query: "},
)
```
