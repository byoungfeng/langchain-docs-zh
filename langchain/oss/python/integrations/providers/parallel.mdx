本页面涵盖了 LangChain 与 [Parallel](https://platform.parallel.ai/) 的所有集成。

## 安装与配置

 `Parallel` 集成位于独立的 [合作伙伴包](https://pypi.org/project/langchain-parallel/) 中：

 <CodeGroup>
    ```bash pip
    pip install -U langchain-parallel
    ```
    ```bash uv
    uv add langchain-parallel
    ```
 </CodeGroup>

设置 `PARALLEL_API_KEY` 环境变量为你的 Parallel API 密钥。在 [platform.parallel.ai](https://platform.parallel.ai) 上注册以获取密钥。
