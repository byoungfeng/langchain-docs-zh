## 概述

[Graph RAG](https://datastax.github.io/graph-rag/) 提供了一个检索接口，该接口结合了 **非结构化** 向量相似度搜索与 **结构化** 元数据属性遍历。这支持基于图结构的检索，可应用于 **现有** 向量存储。

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-graph-retriever
```

```bash uv
uv add langchain-graph-retriever
```
</CodeGroup>
