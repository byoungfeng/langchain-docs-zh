[Fireworks AI](https://fireworks.ai/) 提供快速推理能力的开放和私有语言模型。`langchain-fireworks` 包实现了 Fireworks API 的 LangChain 聊天和嵌入接口。

## 安装与配置

<CodeGroup>
```bash pip
pip install langchain-fireworks
```

```bash uv
uv add langchain-fireworks
```
</CodeGroup>

从 [fireworks.ai](https://app.fireworks.ai/login) 获取 API 密钥并设置 `FIREWORKS_API_KEY` 环境变量。
