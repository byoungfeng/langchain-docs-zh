LangChain 中的 [MCP 工具箱](https://mcp-toolbox.dev/documentation/introduction/) 允许您为智能体配备一组工具。当智能体接收到查询时，它可以智能地选择并使用 MCP 工具箱提供的最合适的工具来满足请求。

## 它是什么？

MCP 工具箱本质上是一个工具的容器。您可以将其视为智能体的多功能工具；它可以容纳您创建的任何工具。然后，智能体根据用户的输入决定使用哪个特定的工具。

当您有一个需要执行各种任务且这些任务需要不同能力的智能体时，这特别有用。

## 安装

要开始使用，您需要安装必要的包：

<CodeGroup>
```bash pip
pip install toolbox-langchain
```

```bash uv
uv add toolbox-langchain
```
</CodeGroup>
