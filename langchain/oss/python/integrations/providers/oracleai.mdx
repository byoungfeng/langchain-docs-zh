Oracle AI Database 是专为基于 **语义**（而非关键词）查询数据的 AI 工作负载构建。它将 **非结构化内容中的语义搜索** 与 **业务数据中的关系过滤** 整合到一个系统中——从而无需引入独立的向量数据库即可构建 AI 检索工作流（如 RAG），同时避免数据在多个平台间碎片化。

### 为什么重要

- **AI + 业务数据一体化系统**：向量与运营数据共存。
- **减少碎片化**：比独立向量存储少一个组件。
- **数据库级保障**：为同一 AI 工作负载应用安全、事务、扩展性和可用性。

## 前置条件

安装 `langchain-oracledb`。`python-oracledb` 驱动会自动作为依赖安装。

<CodeGroup>
```bash pip
pip install -qU langchain-oracledb
```
```bash uv
uv add langchain-oracledb
```
</CodeGroup>
