>[本地AI](https://localai.io/)是免费的、开源的OpenAI替代品。
> `LocalAI`作为本地推理兼容OpenAI API规范的即插即用式REST API。它允许您使用消费级硬件在本地或本地部署运行LLM、生成图像、音频（以及更多），支持多种模型系列和架构。

<Info>
`langchain-localai`是一个用于LocalAI的第三方集成包。它提供了一种简单的方法，在LangChain中使用LocalAI服务。
源代码可在[Github](https://github.com/mkhludnev/langchain-localai)上获取
</Info>

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-localai
```

```bash uv
uv add langchain-localai
```
</CodeGroup>
