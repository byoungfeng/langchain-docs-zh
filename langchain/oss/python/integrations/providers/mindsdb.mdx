MindsDB 是从企业数据定制 AI 的平台。通过 MindsDB 及其与 [数据源](https://docs.mindsdb.com/integrations/data-overview) 和 [AI/ML 框架](https://docs.mindsdb.com/integrations/ai-overview) 的近 200 个集成，任何开发者都可以更快、更安全地使用其企业数据为企业目的定制 AI。

使用 MindsDB，您可以将任何数据源连接到任何 AI/ML 模型，以实现和自动化 AI 驱动的应用程序。实时部署、服务和微调模型，利用来自数据库、向量存储或应用程序的数据。使用开发者已经熟悉的通用工具完成所有这些操作。

MindsDB 与 LangChain 集成，使用户能够：

- 在 MindsDB 中部署通过 LangChain 可用的模型，使其能够被众多数据源访问。
- 使用实时和动态数据在 MindsDB 中微调通过 LangChain 可用的模型。
- 使用 LangChain 和 MindsDB 自动化 AI 工作流。

请参考 [我们的文档](https://docs.mindsdb.com/integrations/ai-engines/langchain) 了解 MindsDB 与 LangChain 的集成详情，并查看示例。
