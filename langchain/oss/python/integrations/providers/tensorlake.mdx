Tensorlake是AI数据云，可靠地将非结构化数据源的数据转换为AI应用程序可摄入的格式。

The `langchain-tensorlake` package提供了与[Tensorlake](https://tensorlake.ai)和[LangChain](https://langchain.com)的无缝集成，
使您能够使用增强的解析功能构建复杂的文档处理智能体，例如签名检测。

## Tensorlake功能概览

Tensorlake为您提供以下工具：
- Extract：基于模式的结构化数据抽取，从文档中提取特定字段
- Parse：将文档转换为Markdown格式，用于构建RAG/Knowledge Graph系统
- Orchestrate：构建可编程工作流，对文档、文本、音频、视频等数据进行大规模摄入和增强

更多详情请访问[docs.tensorlake.ai](https://docs.tensorlake.ai/introduction)

## 快速开始

### 1. 配置环境

您需要为Tensorlake和OpenAI配置凭据，设置以下环境变量：
```
export TENSORLAKE_API_KEY="your-tensorlake-api-key"
export OPENAI_API_KEY = "your-openai-api-key"
```

从[Tensorlake云控制台](https://cloud.tensorlake.ai/)获取Tensorlake API密钥。新用户可获赠100个免费信用额度。

### 2. 导入必要包

```python
from langchain_tensorlake import document_markdown_tool
from langchain.agents import create_agent
import asyncio
import os
```


### 3. 构建签名检测智能体

```python
async def main(question):
    # Create the agent with the Tensorlake tool
    agent = create_agent(
            model="gpt-5.4-mini",
            tools=[document_markdown_tool],
            prompt=(
                """
                I have a document that needs to be parsed. \n\nPlease parse this document and answer the question about it.
                """
            ),
            name="real-estate-agent",
        )

    # Run the agent
    result = await agent.ainvoke({"messages": [{"role": "user", "content": question}]})

    # Print the result
    print(result["messages"][-1].content)
```

*注意：我们强烈建议使用`openai`作为智能体模型，以确保智能体正确设置解析参数

### 4. 示例用法

```python
# Define the path to the document to be parsed
path = "path/to/your/document.pdf"

# Define the question to be asked and create the agent
question = f"What contextual information can you extract about the signatures in my document found at {path}?"

if __name__ == "__main__":
    asyncio.run(main(question))
```
