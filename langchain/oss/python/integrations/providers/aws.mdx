## 对话模型

### Bedrock Mantle

[AWS Bedrock Mantle API](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-responses-api.html#bedrock-mantle-responses) 通过 OpenAI 和 Anthropic 消息协议暴露模型。`ChatOpenAIMantle` 和 `ChatAnthropicMantle` 是访问这些模型的推荐接口。

这两个类都通过 `bedrock_api_key` 参数或 `AWS_BEARER_TOKEN_BEDROCK` 环境变量接受 Bedrock API 密钥。当两者都不可用时，它们都会从标准 AWS 凭证中派生短期 API 密钥并透明地刷新它们。

`ChatOpenAIMantle` 继承自 `BaseChatOpenAI`。请参阅相应的 [响应 API 文档](/langchain/oss/python/integrations/chat/openai#响应-api) 以获取使用示例和功能。请参阅 [AWS Mantle OpenAI 兼容 API 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-responses-api.html#bedrock-mantle-responses) 以获取支持的模型。

`ChatAnthropicMantle` 继承自 `ChatAnthropic` 并针对 Mantle 上的 Anthropic 消息端点。请参阅 [`ChatAnthropic`](/langchain/oss/python/integrations/chat/anthropic) 文档以获取使用示例和功能。请参阅 [AWS Mantle Anthropic API 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html) 以获取支持的模型。

```python
from langchain_aws import ChatOpenAIMantle, ChatAnthropicMantle

openai_model = ChatOpenAIMantle(
    model="openai.gpt-5.6-luna",
    region_name="us-east-1",
)

anthropic_model = ChatAnthropicMantle(
    model="anthropic.claude-opus-5-5",
    region_name="us-east-1",
)
```

### Bedrock 对话

>[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一个完全托管的服务，提供来自 `AI21 Labs`、`Anthropic`、`Cohere`、`Meta`、`OpenAI`、`Stability AI` 和 `Amazon` 等领先 AI 公司的高性能基础模型 (FMs)，通过单个 API。由于 `Amazon Bedrock` 是无服务器的，因此您无需管理任何基础设施，并且可以使用您已经熟悉的 AWS 服务，将生成式 AI 功能安全地集成并部署到您的应用程序中。

AWS Bedrock 维护一个 [Converse API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html)，该 API 为 Bedrock 模型提供了一个统一的对话接口。您可以在此处查看所有 [支持的模型列表](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html)。

请参阅 [使用示例](/langchain/oss/python/integrations/chat/bedrock)。

```python
from langchain_aws import ChatBedrockConverse
```

## 记忆

### Amazon Bedrock AgentCore 记忆

>[Amazon Bedrock AgentCore Memory](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory.html) 提供
> LangGraph 智能体的托管持久化，能够在会话之间管理对话历史记录和状态，并具有自动扩展和高可用性。

<CodeGroup>
    ```bash pip
    pip install langgraph-checkpoint-aws
    ```

    ```bash uv
    uv add langgraph-checkpoint-aws
    ```
</CodeGroup>

```python
from langgraph_checkpoint_aws import AgentCoreMemorySaver

# Create checkpointer
checkpointer = AgentCoreMemorySaver(
    memory_id="your-memory-id",
    region_name="us-west-2"
)

# Use with LangGraph
graph = workflow.compile(checkpointer=checkpointer)

# Invoke with thread_id and actor_id for conversation persistence
config = {
    "configurable": {
        "thread_id": "user-123",
        "actor_id": "my-agent"  # Required for AgentCore
    }
}
result = graph.invoke({"messages": []}, config)
```

关键特性：
- 托管的 infrastrucure，无需数据库设置
- 自动扩展和高可用性
- 通过 `actor_id` 隔离的多智能体支持
- 静态和传输中的加密

### Amazon Bedrock AgentCore 记忆存储

>[Amazon Bedrock AgentCore Memory Store](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory.html) 提供
> 长期记忆，具有语义搜索功能，用于 LangGraph 智能体，能够在会话之间存储和检索用户偏好、事实和提取的记忆。

```python
from langgraph_checkpoint_aws import AgentCoreMemoryStore

# Initialize store for long-term memories
store = AgentCoreMemoryStore(memory_id="your-memory-id", region_name="us-west-2")

# Use in a pre-model hook to save and retrieve memories
def pre_model_hook(state, config, *, store):
    actor_id = config["configurable"]["actor_id"]
    thread_id = config["configurable"]["thread_id"]
    namespace = (actor_id, thread_id)

    # Save a message
    store.put(namespace, str(uuid.uuid4()), {"message": msg})

    # Search for relevant memories
    results = store.search(("preferences", actor_id), query="user preferences", limit=5)
    return {"model_input_messages": state["messages"]}
```

## 运行时

### Amazon Bedrock AgentCore 运行时

>[Amazon Bedrock AgentCore 运行时](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agents-tools-runtime.html) 提供了
> 管理式、无服务器的 LangGraph 智能体执行，具有内置的可观测性、自动扩展，并能与其他 AgentCore 服务无缝集成。

<CodeGroup>
    ```bash pip
    pip install bedrock-agentcore
    ```

    ```bash uv
    uv add bedrock-agentcore
    ```
</CodeGroup>

```python
from bedrock_agentcore.runtime import BedrockAgentCoreApp

app = BedrockAgentCoreApp()

@app.entrypoint
def agent_invocation(payload, context):
    result = graph.invoke({"messages": [{"role": "user", "content": payload["prompt"]}]})
    return {"result": result["messages"][-1].content}

app.run()
```

使用 AgentCore CLI 进行部署：

```bash
# Configure your agent
agentcore configure

# Deploy to AgentCore Runtime
agentcore launch -e your_agent.py
```
