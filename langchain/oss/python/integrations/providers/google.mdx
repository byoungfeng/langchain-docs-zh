本页面涵盖了与 [Google Gemini](https://ai.google.dev/gemini-api/docs)、[Google Cloud](https://cloud.google.com/) 及其他 Google 产品（如 Google Maps、YouTube 和 [更多](#其他-google-产品)）的 LangChain 集成。

<Note>
    **统一 SDK 与包整合**

    自 `langchain-google-genai` 4.0.0 版本起，此包使用整合的 [`google-genai`](https://googleapis.github.io/python-genai/) SDK，现支持 **Gemini 开发者 API 和 Gemini 企业智能体平台** 后端。

    `langchain-google-vertexai` 包仍受支持，用于 Gemini 企业智能体平台特定功能（模型花园、向量搜索、评估服务等）。

    请参阅 [完整公告和迁移指南](https://github.com/langchain-ai/langchain-google/discussions/1422)。
</Note>

不确定使用哪个包？

<AccordionGroup>
    <Accordion title="Google Generative AI (Gemini API & Gemini Enterprise Agent Platform)">
        通过 **[Gemini 开发者 API](https://ai.google.dev/)** 或 **[Gemini 企业智能体平台](https://cloud.google.com/products/gemini-enterprise-agent-platform)** 访问 Google Gemini 模型。后端会根据您的配置自动选择。

        - **Gemini 开发者 API**：使用 API 密钥快速设置，适合个人开发者和快速原型设计
        - **Gemini 企业智能体平台**：具有 Google Cloud 集成的企业功能（需要 GCP 项目）

        使用 `langchain-google-genai` 包用于对话模型、LLM 和嵌入。

        [查看集成。](#google-生成式-ai)
    </Accordion>
    <Accordion title="Google Cloud (Gemini Enterprise Agent Platform Services)">
        访问 Gemini 企业智能体平台特定服务，超出 Gemini 模型范围：模型花园（Llama、Mistral、Anthropic）、评估服务以及专业视觉模型。

        使用 `langchain-google-vertexai` 包用于平台服务，并使用特定包（例如 `langchain-google-community`、`langchain-google-cloud-sql-pg`）用于其他云服务，如数据库和存储。

        [查看集成。](#google-cloud)
    </Accordion>
</AccordionGroup>

有关差异的更多详细信息，请参阅 Google 的 [从 Gemini API 迁移到 Gemini 企业智能体平台](https://ai.google.dev/gemini-api/docs/migrate-to-cloud) 指南。
