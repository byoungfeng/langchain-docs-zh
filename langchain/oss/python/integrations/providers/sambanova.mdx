专为AI设计的SambaNova RDU采用革命性数据流架构。这种设计使其在处理此类负载时比GPU效率显著更高——通过消除GPU固有的内存冗余调用限制。这种内置的能效优势是RDU相比GPU在更小物理空间实现更高性能的关键特性。

在架构之上，我们开发了若干平台，使企业和开发者能充分利用RDU处理器和开源模型。

## API密钥  
将API密钥设为环境变量：

若您是SambaCloud用户，请申请[API密钥](http://cloud.sambanova.ai/apis?utm_source=langchain&utm_medium=external&utm_campaign=cloud_signup)并设为环境变量：

```bash
export SAMBANOVA_API_KEY="your-sambacloud-api-key-here"
```
  
若您是SambaStack用户，请将基础URL和API密钥设为环境变量：

```bash
export SAMBANOVA_API_BASE="your-sambastack-envirronment-base-url-here"
export SAMBANOVA_API_KEY="your-sambastack-api-key-here"
```
