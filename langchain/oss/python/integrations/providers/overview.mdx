LangChain 提供了一个广泛的生态系统，包含超过 1000 个集成，涵盖对话模型、嵌入模型、工具与工具包、文档加载器、向量存储等。

**提供者** 是指托管 AI 模型并通过 API 暴露它们的公司或平台（例如 OpenAI、Anthropic、Google）。许多提供者都有一个专门的 `langchain-<provider>` 包，该包实现了 LangChain 标准接口中的一个或多个——对话模型、嵌入模型、向量存储等——无论底层提供者如何，都能为您提供一致的 API。安装包、选择模型名称，并在不修改代码的情况下切换提供者。
