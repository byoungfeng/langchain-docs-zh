>[SAP SE(Wikipedia)](https://www.sap.com/about/company.html) 是一家德国跨国
> 软件公司。它开发企业软件来管理业务运营和
> 客户关系。该公司是世界上领先的
> `enterprise resource planning (ERP)` 软件供应商。

## 安装和设置

我们需要安装 `langchain-hana` python 包。

<CodeGroup>
```bash pip
pip install langchain-hana
```

```bash uv
uv add langchain-hana
```
</CodeGroup>

## 向量存储

>[SAP HANA Cloud Vector Engine](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-vector-engine-guide/sap-hana-cloud-sap-hana-database-vector-engine-guide) 是
> 一个完全集成到 `SAP HANA Cloud` 数据库中的向量存储。

查看一个 [使用示例](/langchain/oss/python/integrations/vectorstores/sap_hanavector)。

```python
from langchain_hana import HanaDB
```

## 自查询检索器
>[SAP HANA Cloud Vector Engine](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-vector-engine-guide/sap-hana-cloud-sap-hana-database-vector-engine-guide)
> 还提供了一个使用 `HanaTranslator` 类的自查询检索器实现。

查看一个 [使用示例](https://pypi.org/project/langchain-hana/)。

```python
from langchain_hana import HanaTranslator
```

## 图
>[SAP HANA Cloud Knowledge Graph Engine](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/sap-hana-cloud-sap-hana-database-knowledge-graph-engine-guide)
> 通过 `HanaRdfGraph` 类提供对知识图的支持。

查看一个 [使用示例](/langchain/oss/python/integrations/graphs/sap_hana_rdf_graph)。

```python
from langchain_hana import HanaRdfGraph
```

## 链
一个 `SparqlQAChain` 也可以使用，它可用于 `HanaRdfGraph` 进行 SPARQL-QA 任务。

查看一个 [使用示例](/langchain/oss/python/integrations/chains/sap_hana_sparql_qa_chain)。

```python
from langchain_hana import HanaSparqlQAChain
```

## 智能体
一个 `HanaSparqlQAAgent` 可以在 `HanaRdfGraph` 上迭代生成和执行 SPARQL 查询，包括本体检索和自我纠正。

查看一个 [使用示例](/langchain/oss/python/integrations/agents/sap_hana_sparql_qa_agent)。

```python
from langchain_hana import HanaSparqlQAAgent
```
