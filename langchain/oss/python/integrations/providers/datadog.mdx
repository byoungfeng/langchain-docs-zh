> [ddtrace](https://github.com/DataDog/dd-trace-py) 是一个 Datadog 应用性能监控（APM）库，提供 LangChain 应用的集成监控。  

关键特性：  
- 跟踪：捕获 LangChain 请求、参数、提示词生成结果，并可视化 LangChain 操作。  
- 指标：捕获 LangChain 请求延迟、错误及 Token/成本使用情况（适用于 OpenAI LLM 和对话模型）。  
- 日志：存储每个 LangChain 操作的提示词生成数据。  
- 控制台：将指标、日志和跟踪数据整合至单一平面，监控 LangChain 请求。  
- 监控：对 LangChain 请求延迟激增或错误率突增触发告警。  

注意：当前 ddtrace LangChain 集成支持 LLM、对话模型、文本嵌入模型、链（Chain）和向量存储（Vector Store）的跟踪。  

## 安装与配置  

1. 在 Datadog Agent 中启用 APM 和 StatsD，并设置 Datadog API Key。例如，在 Docker 中：  
```
docker run -d --cgroupns host \
              --pid host \
              -v /var/run/docker.sock:/var/run/docker.sock:ro \
              -v /proc/:/host/proc/:ro \
              -v /sys/fs/cgroup/:/host/sys/fs/cgroup:ro \
              -e DD_API_KEY=<DATADOG_API_KEY> \
              -p 127.0.0.1:8126:8126/tcp \
              -p 127.0.0.1:8125:8125/udp \
              -e DD_DOGSTATSD_NON_LOCAL_TRAFFIC=true \
              -e DD_APM_ENABLED=true \
              gcr.io/datadoghq/agent:latest
```
  
2. 安装 Datadog APM Python 库。  
<CodeGroup>  
```shell pip
pip install "ddtrace>=1.17"
```
  
```shell uv
uv add "ddtrace>=1.17"
```
</CodeGroup>  

3. 通过在 LangChain Python 应用命令前添加 `ddtrace-run` 可自动启用集成：  
```
DD_SERVICE="my-service" DD_ENV="staging" DD_API_KEY=<DATADOG_API_KEY> ddtrace-run python <your-app>.py
```
  
**注意**：若 Agent 使用非默认主机名或端口，需同时设置 `DD_AGENT_HOST`、`DD_TRACE_AGENT_PORT` 或 `DD_DOGSTATSD_PORT`。  

此外，可通过在应用首次导入 `langchain` 之前添加 `patch_all()` 或 `patch(langchain=True)` 手动启用集成。  

注意：使用 `ddtrace-run` 或 `patch_all()` 将同时启用 `requests` 和 `aiohttp` 集成（跟踪 LLM 提供商 HTTP 请求），并启用 `openai` 集成（跟踪 OpenAI 库请求）。  
```python
from ddtrace import config, patch

# Note: be sure to configure the integration before calling `patch()`!
# e.g. config.langchain["logs_enabled"] = True

patch(langchain=True)

# to trace synchronous HTTP requests
# patch(langchain=True, requests=True)

# to trace asynchronous HTTP requests (to the OpenAI library)
# patch(langchain=True, aiohttp=True)

# to include underlying OpenAI spans from the OpenAI integration
# patch(langchain=True, openai=True)
# patch_all()
```
  
更多高级用法请参考 [APM Python 库文档](https://ddtrace.readthedocs.io/en/stable/installation_quickstart.html)。  

## 配置  

所有可用配置选项请参考 [APM Python 库文档](https://ddtrace.readthedocs.io/en/stable/integrations.html#langchain)。  

### 日志提示与完成采样  

启用日志提示与完成采样功能，需设置 `DD_LANGCHAIN_LOGS_ENABLED=1` 环境变量。默认情况下，10% 的跟踪请求会生成包含提示词和生成的日志。  

调整日志采样率请参考 [APM 库文档](https://ddtrace.readthedocs.io/en/stable/integrations.html#langchain)。  

**注意**：提交日志需在运行 `ddtrace-run` 时指定 `DD_API_KEY`。
