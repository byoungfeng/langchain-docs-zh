>[Chroma](https://docs.trychroma.com/docs/overview/getting-started) 是一个用于构建 AI 应用的嵌入数据库。

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-chroma
```

```bash uv
uv add langchain-chroma
```
</CodeGroup>

## 向量存储

存在一个围绕 Chroma 向量数据库的包装器，允许你将其用作向量存储，
无论是用于语义搜索还是示例选择。

```python
from langchain_chroma import Chroma
```

有关 Chroma 包装器的更详细说明，请参阅 [此笔记本](/langchain/oss/python/integrations/vectorstores/chroma)。
