>Memgraph 是一款高性能的内存图数据库，专为实时查询和分析而优化。
>通过访问 [他们的网站](https://memgraph.com/) 开始使用 Memgraph。

## 安装和设置

- 使用 `pip install langchain-memgraph` 安装 Python SDK

## MemgraphQAChain

Memgraph 数据库存在一个包装器，允许您根据用户输入生成 Cypher 语句，并使用它们从数据库中检索相关信息。

```python
from langchain_memgraph.chains.graph_qa import MemgraphQAChain
from langchain_memgraph.graphs.memgraph import MemgraphLangChain
```

查看一个 [使用示例](/langchain/oss/python/integrations/graphs/memgraph)

## 从非结构化数据构建知识图谱

您可以使用集成从非结构化数据构建知识图谱。

from langchain_memgraph.graphs.memgraph import MemgraphLangChain

## Memgraph 工具和工具包

Memgraph 还提供了一个工具包，允许您与 Memgraph 数据库交互。
