> [Elasticsearch](https://www.elastic.co/elasticsearch/) 是一个分布式、RESTful 搜索和分析引擎。
> 它提供了一种分布式、多租户支持的全文本搜索引擎，具有 HTTP 网页界面和 schema-free
> JSON 文档。

## 安装与配置

### Elasticsearch 安装

有两种方式开始使用 Elasticsearch：

#### 在本地机器上安装 Elasticsearch

本地开发测试最便捷的方式是使用 [start-local](https://github.com/elastic/start-local) 脚本。该脚本通过 Docker 用一行简单命令配置 Elasticsearch。

```bash
curl -fsSL https://elastic.co/start-local | sh
```

这会创建一个 `elastic-start-local` 文件夹。要启动 Elasticsearch：

```bash
cd elastic-start-local
./start.sh
```

Elasticsearch 将在 `http://localhost:9200` 可用。`elastic` 用户和 API 密钥的自动生成密码将保存在 `.env` 文件中，位于 `elastic-start-local` 文件夹。

如果只需要 Elasticsearch 而不需要 Kibana，可以使用 `--esonly` 选项：

```bash
curl -fsSL https://elastic.co/start-local | sh -s -- --esonly
```

<Note>
本地测试专用的 start-local 配置不应用于生产环境。生产环境安装请参考官方 [Elasticsearch 文档](https://www.elastic.co/guide/en/elasticsearch/reference/current/install-elasticsearch.html)。
</Note>

#### 在弹性云上部署 Elasticsearch

`Elastic Cloud` 是一个托管 Elasticsearch 服务。注册 [免费试用](https://cloud.elastic.co/registration?utm_source=langchain&utm_content=documentation) 账户。
