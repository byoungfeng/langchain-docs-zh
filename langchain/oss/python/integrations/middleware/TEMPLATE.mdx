## 与智能体一起使用

按顺序将中间件传递给 @[`create_agent`] 或 @[`create_deep_agent`]。你可以将提供者中间件与 [内置中间件](/langchain/oss/langchain/middleware/built-in) 结合使用。

```python Agent with middleware icon="robot"
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[...],
    middleware=[middleware],
)

agent.invoke({"messages": [{"role": "user", "content": "INSERT QUERY"}]})
```

<Tip>
    中间件在 [智能体循环](/langchain/oss/langchain/middleware/overview#智能体循环) 中运行。如需自定义行为，请参阅 [自定义中间件](/langchain/oss/langchain/middleware/custom)。
