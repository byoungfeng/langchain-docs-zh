文档加载器提供了一个**标准接口**，用于从不同来源（如 Slack、Notion 或 Google Drive）读取数据到 LangChain 的 @[Document] 格式。
这确保了无论数据来源如何，都能一致地处理数据。

所有文档加载器都实现了 @[BaseLoader] 接口。

<Warning>
社区文档加载器是用户贡献的且未经验证。LangChain 不审核或认可这些集成；请自行承担使用风险。
</Warning>

## 接口

每个文档加载器可以定义自己的参数，但它们共享一个共同的 API：

- `load()`: 一次性加载所有文档。
- `loadAndSplit()`: 一次性加载所有文档并将它们分割成更小的文档。

```typescript
import { OracleDocLoader } from "@oracle/langchain-oracledb";

const loader = new OracleDocLoader(,
  ...  // <-- Integration specific parameters here
);
const data = await loader.load();
```

## 按类别分类

LangChain.js 以两种不同的方式对文档加载器进行分类：

- [文件加载器](/langchain/oss/javascript/integrations/document_loaders/file_loaders/)，它们从您的本地文件系统加载数据到 LangChain 格式。
- [网络加载器](/langchain/oss/javascript/integrations/document_loaders/web_loaders/)，它们从远程来源加载数据。
