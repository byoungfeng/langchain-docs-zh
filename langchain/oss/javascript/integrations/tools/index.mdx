[工具](/langchain/oss/langchain/tools) 是设计为被模型调用的实用程序：它们的输入设计为由模型生成，输出设计为传递回模型。

一个 [工具包](/langchain/oss/langchain/tools#预构建工具) 是一组旨在一起使用的工具。
