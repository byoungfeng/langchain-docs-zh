### 凭证

在 [Tavily 控制台](https://app.tavily.com) 上设置 API 密钥，并将其作为名为 `TAVILY_API_KEY` 的环境变量。

```typescript
process.env.TAVILY_API_KEY = "YOUR_API_KEY";
```

## 实例化

您可以像这样导入和实例化 `TavilyResearch`：

```ts
import { TavilyResearch } from "@langchain/tavily";

const tool = new TavilyResearch({
  // model: "mini",
  // citationFormat: "apa",
  // stream: false,
});
```

- `model`（可选）：研究智能体模型。`"mini"`、`"pro"` 或 `"auto"`（默认）。
- `citationFormat`（可选）：来源的引用格式。`"numbered"`、`"mla"`、`"apa"` 或 `"chicago"`（默认 `"numbered"`）。
- `outputSchema`（可选）：定义研究输出的 JSON Schema。
- `stream`（可选）：是否流式输出研究结果。默认为 `false`。

## 调用

### [直接使用参数调用](/langchain/oss/langchain/tools)

Tavily 研究工具在调用时接受以下参数：

- `input`（必需）：要调查的研究任务或问题
- 可选覆盖：`model`、`outputSchema`、`stream`、`citationFormat`

```ts
await tool.invoke({
  input: "What are the latest developments in AI?",
});
```

### [使用 ToolCall 调用](/langchain/oss/langchain/tools)

您也可以使用模型生成的 `ToolCall` 调用该工具，此时会返回一个 @[`ToolMessage`]：

```ts
// This is usually generated by a model, but we'll create a tool call directly for demo purposes.
const modelGeneratedToolCall = {
  args: {
    input: "What are the latest developments in AI?",
  },
  id: "1",
  name: tool.name,
  type: "tool_call",
};

await tool.invoke(modelGeneratedToolCall);
```

## 在智能体中使用

将研究工具传递给 `createAgent`，以便智能体可以使用研究任务调用它：

```ts
import { ChatOpenAI } from "@langchain/openai";
import { TavilyResearch } from "@langchain/tavily";
import { createAgent } from "langchain";

const llm = new ChatOpenAI({
  model: "gpt-5.5",
});

const tavilyResearchTool = new TavilyResearch({
  model: "mini",
});

const agent = createAgent({
  model: llm,
  tools: [tavilyResearchTool],
});

const userInput =
  "Research the latest developments in AI agents and summarize key trends.";

const stream = await agent.streamEvents(
  { messages: [{ role: "user", content: userInput }] },
  { version: "v3" },
);

await Promise.all([
  (async () => {
    for await (const message of stream.messages) {
      for await (const token of message.text) {
        process.stdout.write(token);
      }
    }
  })(),
  (async () => {
    for await (const call of stream.toolCalls) {
      console.dir({ name: call.name, input: call.input }, { depth: null });
      await call.output;
    }
  })(),
]);

await stream.output;
```
