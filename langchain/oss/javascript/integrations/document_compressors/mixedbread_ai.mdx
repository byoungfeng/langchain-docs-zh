## 概述

本指南将帮助您集成和使用 [Mixedbread AI](https://mixedbread.ai/) 重新排序 API。重新排序 API 允许您根据给定的查询对文档列表进行排序，从而提高搜索结果或任何排序列表的相关性。

## 安装

开始使用前，请安装 `@langchain/mixedbread-ai` 包：

<Tip>
请参阅 [有关安装 LangChain 包的通用说明部分](/langchain/oss/langchain/install)。
</Tip>

```bash
npm install @langchain/mixedbread-ai
```

## 认证

通过在 [Mixedbread AI](https://mixedbread.ai/) 注册来获取您的 API 密钥。然后，您可以将 `MXBAI_API_KEY` 环境变量设置为您的 Mixedbread AI API 密钥，或在构建类时直接将其作为 `apiKey` 选项传递。

## 使用重新排序

`MixedbreadAIReranker` 类提供了对重新排序 API 的访问。以下是使用方法：

1. **导入类**：首先，从包中导入 `MixedbreadAIReranker` 类。

```typescript
import { MixedbreadAIReranker } from "@langchain/mixedbread-ai";
```

2. **实例化类**：使用您的 API 密钥创建 `MixedbreadAIReranker` 的实例。

```typescript
const reranker = new MixedbreadAIReranker({ apiKey: "your-api-key" });
```

3. **重新排序文档**：使用 `rerankDocuments` 方法根据查询对文档进行排序。

```typescript
const documents = [
  { pageContent: "To bake bread you need flour" },
  { pageContent: "To bake bread you need yeast" },
  { pageContent: "To eat bread you need nothing but good taste" },
];
const query = "What do you need to bake bread?";
const result = await reranker.compressDocuments(documents, query);
console.log(result);
```
