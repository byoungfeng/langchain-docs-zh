## 概述

[Amazon Kendra](https://aws.amazon.com/kendra/) 是由亚马逊云服务（AWS）提供的一项智能搜索服务。
它利用先进的自然语言处理（NLP）和机器学习算法，能够在组织内的各种数据源中实现强大的搜索功能。
Kendra 的设计目的是帮助用户快速准确地找到所需信息，提高生产力和决策能力。

使用 Kendra，用户可以搜索多种内容类型，包括文档、常见问题解答（FAQ）、知识库、手册和网站。
它支持多种语言，并能够理解复杂查询、同义词和上下文含义，以提供高度相关的搜索结果。

这将帮助您开始使用 `AWSKendraRetriever` [检索](/langchain/oss/deepagents/retrieval)。有关所有 `AWSKendraRetriever` 功能和配置的详细文档，请访问 [API 参考](https://reference.langchain.com/javascript/langchain-aws/AmazonKendraRetriever)。

## 设置

您需要有一个 AWS 账户和一个 Amazon Kendra 实例才能开始。有关更多信息，请参阅 AWS 的此 [教程](https://docs.aws.amazon.com/kendra/latest/dg/getting-started.html)。

如果您想从单个查询中获得自动跟踪，您也可以通过取消注释以下内容来设置您的 [LangSmith](https://docs.langchain.com/langsmith/observability) API 密钥：

```typescript
// process.env.LANGSMITH_TRACING = "true";
```

## 实例化

现在我们可以实例化我们的检索器：

```typescript
import { AmazonKendraRetriever } from "@langchain/aws";

const retriever = new AmazonKendraRetriever({
  topK: 10,
  indexId: "YOUR_INDEX_ID",
  region: "us-east-2", // Your region
  clientOptions: {
    credentials: {
      accessKeyId: "YOUR_ACCESS_KEY_ID",
      secretAccessKey: "YOUR_SECRET_ACCESS_KEY",
    },
  },
});
```

## 使用

```typescript
const query = "..."

await retriever.invoke(query);
```
