## 提示词最佳实践

与 OpenAI 模型相比，Anthropic 模型在提示词方面有几个最佳实践。

**系统消息只能是第一条消息**

Anthropic 模型要求任何系统消息必须是提示词中的第一条。

## `ChatAnthropic`

`ChatAnthropic` 是 LangChain 的 `ChatModel` 的子类，这意味着它与 `ChatPromptTemplate` 配合最佳。
您可以使用以下代码导入此包装器：

<Tip>
请参阅 [有关安装 LangChain 包的一般说明的此部分](/langchain/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/anthropic @langchain/core
```
```typescript
import { ChatAnthropic } from "@langchain/anthropic";
const model = new ChatAnthropic({});
```

在使用 ChatModels 时，建议您将提示词设计为 `ChatPromptTemplate`。
以下是一个使用该设计的示例：

```typescript
import { ChatPromptTemplate } from "@langchain/classic/prompts";

const prompt = ChatPromptTemplate.fromMessages([
  ["system", "You are a helpful chatbot"],
  ["human", "Tell me a joke about {topic}"],
]);
```

然后您可以在链中使用它，如下所示：

```typescript
const chain = prompt.pipe(model);
await chain.invoke({ topic: "bears" });
```

请参阅 [对话模型集成页面](/langchain/oss/python/integrations/chat/anthropic/) 获取更多示例，包括多模态输入。
