[OpenRouter](https://openrouter.ai/) 是一个统一 API，通过单个端点提供对来自多个提供者（OpenAI、Anthropic、Google、Meta 等）的模型的访问，具有提供商路由和多模型回退等功能。

## 安装

```bash
npm install @langchain/openrouter @langchain/core
```

设置 `OPENROUTER_API_KEY` 在您的环境。有关详细信息，请参阅 [ChatOpenRouter](/langchain/oss/python/integrations/chat/openrouter) 页面。
