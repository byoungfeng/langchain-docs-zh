## 设置

要访问 `ChatTogetherAI` 模型，请创建一个 Together 账户，[获取 API 密钥](https://api.together.xyz/)，并安装 `@langchain/together-ai` 集成包。

### 凭证

前往 [api.together.ai](https://api.together.ai/) 注册 Together AI 并生成 API 密钥。设置 `TOGETHER_AI_API_KEY` 环境变量：

```bash
export TOGETHER_AI_API_KEY="your-api-key"
```

如果你希望自动跟踪你的模型调用，你也可以通过取消注释以下内容来设置你的 [LangSmith](https://docs.langchain.com/langsmith/observability) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain ChatTogetherAI 集成位于 `@langchain/together-ai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/together-ai @langchain/core
```
```bash yarn
yarn add @langchain/together-ai @langchain/core
```
```bash pnpm
pnpm add @langchain/together-ai @langchain/core
```
</CodeGroup>

## 实例化

现在我们可以实例化我们的模型对象并生成对话补全：

```typescript
import { ChatTogetherAI } from "@langchain/together-ai";

const llm = new ChatTogetherAI({
    model: "meta-llama/Meta-Llama-3.1-70B-Instruct-Turbo",
    temperature: 0,
    // other params...
})
```
