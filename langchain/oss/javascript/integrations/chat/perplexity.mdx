## 设置

要访问 Perplexity 模型，你需要创建一个 Perplexity 账户，获取一个 API 密钥，并安装 `@langchain/perplexity` 集成包。

### 凭证

前往 [Perplexity API 密钥控制面板](https://www.perplexity.ai/account/api/keys) 注册并生成一个 API 密钥。完成此操作后，设置 `PERPLEXITY_API_KEY` 环境变量：

```bash
export PERPLEXITY_API_KEY="your-api-key"
```

如果你希望自动跟踪你的模型调用，你也可以通过取消注释以下内容来设置你的 [LangSmith](https://docs.langchain.com/langsmith/observability) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

现在你可以实例化模型：

```typescript
import { ChatPerplexity } from "@langchain/perplexity";

const llm = new ChatPerplexity({
  model: "openai/gpt-5.5",
  temperature: 0,
  maxTokens: undefined,
  timeout: undefined,
  maxRetries: 2,
  // other params...
});
```

## 智能体 API 支持 (`useResponsesApi`)

`ChatPerplexity` 也可以通过设置 `useResponsesApi` 将请求路由到 Perplexity 的 [智能体 API](https://docs.perplexity.ai/docs/agent-api/quickstart)（Perplexity 风格的响应 API）。这类似于 [`ChatOpenAI` 的响应模式](https://reference.langchain.com/javascript/langchain-openai/)：一个类，两个端点，由一个选项控制。

| 值 | 端点 | 备注 |
| :--- | :--- | :--- |
| `undefined` (默认) | 自动检测 | 当请求使用内置的 Perplexity 工具 (`web_search`, `fetch_url`, `finance_search`, `people_search`) 或包含仅限响应的字段 (`previousResponseId`, `instructions`, `input`, `include`) 时，路由到智能体 API。否则路由到 Chat Completions。 |
| `true` | 智能体 API | 总是使用 `client.responses.create()`。 |
| `false` | Chat Completions | 总是使用 `client.chat.completions.create()`。 |

智能体 API 为 `ChatPerplexity` 提供对 Perplexity 内置工具（实时网络搜索、URL 获取、金融和人名搜索）和有状态智能体字段（`previousResponseId`, `instructions`, `include`）的访问权限，这些在 Chat Completions 上不可用。现有的 `new ChatPerplexity({ model: "sonar" })` 调用者不会看到行为变化——对于纯文本请求，Chat Completions 路径仍然是默认的。

```typescript
import { ChatPerplexity } from "@langchain/perplexity";

const chat = new ChatPerplexity({
  model: "openai/gpt-5.5",
  useResponsesApi: true,
});

const response = await chat.invoke("What did Apple announce at WWDC this week?");
console.log(response.content);
```

你也可以绑定一个内置工具，并让自动检测路由请求——无需选项：

```typescript
import { ChatPerplexity } from "@langchain/perplexity";

const chat = new ChatPerplexity({ model: "openai/gpt-5.5" });

const response = await chat.invoke(
  "Summarize the latest LangChain release notes.",
  { tools: [{ type: "web_search" }] },
);
console.log(response.content);
```

当通过智能体 API 路由时，响应对象包含更丰富的元数据：

- `usage_metadata` 从 Responses 形状的 `usage` 负载中填充（`input_tokens`, `output_tokens`, `total_tokens`）。
- `response_metadata` 包含传输级字段（`id`, `model`, `status`, `object`），并在存在时包含 Perplexity 特定的搜索输出：`citations`, `images`, `related_questions`, 和 `search_results`。
- `additional_kwargs.responses_output` 存储原始智能体 API 输出项。
- 模型返回的工具调用在 `response.tool_calls` 上与 `ChatOpenAI` 完全相同。

<Note>
    `_toResponsesPayload` 翻译将 `temperature`, `topP`, 和 `toolChoice` 直接传递给智能体 API。仅限 Chat-Completions 的旋钮（例如 `topK`, `stop`, `metadata`）在 `extra_body` 下转发。
</Note>

请参阅 [Perplexity 智能体 API 模型列表](https://docs.perplexity.ai/docs/agent-api/models)，了解通过此端点可用的完整模型集（例如 `openai/gpt-5.5`, `anthropic/claude-sonnet-4-6`, `google/gemini-3-1-pro`）。
