## 路由器和代理

路由器和代理通过单个 API 和凭证提供对来自多个提供者的模型的访问。它们可以简化计费，让您在不更改集成的情况下切换模型，并提供自动回退等特性。

| 提供者 | 集成 | 描述 |
|-|-|-|
| [OpenRouter](https://openrouter.ai/) | [`ChatOpenRouter`](/langchain/oss/javascript/integrations/chat/openrouter) | 统一访问 OpenAI、Anthropic、Google、Meta 等模型的接口 |

## 对话完成 API

某些模型提供者提供与 OpenAI 的（旧版）[对话完成 API](https://platform.openai.com/docs/guides/completions)兼容的端点。在这种情况下，您可以使用 [`ChatOpenAI`](/langchain/oss/javascript/integrations/chat/openai) 并通过自定义`base_url`连接到这些端点。请注意，基于对话完成 API 构建的功能可能无法完全由`ChatOpenAI`支持；在这种情况下，如果可用，请考虑使用提供者特定的类。
