## 设置

要访问遗留 `TogetherAI` 完成类，请创建一个 Together 账户，[获取 API 密钥](https://api.together.xyz/)，并安装 `@langchain/together-ai` 集成包。对于对话和指令模型，请优先使用 [`ChatTogetherAI`](/langchain/oss/javascript/integrations/chat/togetherai)。

### 凭证

前往 [api.together.ai](https://api.together.ai/) 注册 Together AI 并生成 API 密钥。设置 `TOGETHER_AI_API_KEY` 环境变量：

```bash
export TOGETHER_AI_API_KEY="your-api-key"
```

如果您希望自动跟踪您的模型调用，您还可以通过取消注释以下内容来设置您的 [LangSmith](https://docs.langchain.com/langsmith/observability) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain TogetherAI 集成位于 `@langchain/together-ai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/together-ai @langchain/core
```
```bash yarn
yarn add @langchain/together-ai @langchain/core
```
```bash pnpm
pnpm add @langchain/together-ai @langchain/core
```
</CodeGroup>

## 实例化

实例化完成模型：

```typescript
import { TogetherAI } from "@langchain/together-ai";

const llm = new TogetherAI({
  model: "meta-llama/Meta-Llama-3.1-8B-Instruct-Turbo",
  maxTokens: 256,
});
```
