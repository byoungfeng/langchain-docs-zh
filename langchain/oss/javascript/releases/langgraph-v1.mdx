**LangGraph v1 是一个以稳定性为重点发布的智能体运行时。** 它保持了核心图 API 和执行模型不变，同时改进了类型安全、文档和开发者易用性。

它设计为与 [LangChain v1](/langchain/oss/python/releases/langchain-v1)（其 `createAgent` 基于 LangGraph）协同工作，让您可以从高级别开始，在需要时进行粒度控制。

## `createReactAgent` 的弃用

LangGraph 的 `createReactAgent` 预构建已被弃用，改为使用 LangChain 的 `createAgent`。它提供了一个更简单的接口，并通过引入中间件提供了更大的自定义潜力。

* 有关新的 `createAgent` API 的信息，请参阅 [LangChain v1 发布说明](/langchain/oss/python/releases/langchain-v1#create_agent)。
* 有关从 `createReactAgent` 迁移到 `createAgent` 的信息，请参阅 [LangChain v1 迁移指南](/langchain/oss/python/migrate/langchain-v1#迁移到-create_agent)。

## 带有类型中断

@[`StateGraph`] 现在在构造函数中接受中断类型的映射，以更紧密地限制图中可以使用的中断类型。

```typescript expandable
import { StateGraph, MemorySaver, interrupt } from "@langchain/langgraph";
import * as z from "zod";

const stateSchema = z.object({
  foo: z.string(),
})

const graphConfig = {
  interrupts: {
    // Define a simple interrupt that accepts a reason and returns messages
    simple: interrupt<{ reason: string }, { messages: string[] }>, // [!code highlight]
    // Define a complex interrupt with the same signature
    complex: interrupt<{ reason: string }, { messages: string[] }>, // [!code highlight]
  }
}

const checkpointer = new MemorySaver();

const graph = new StateGraph(stateSchema, graphConfig)
  .addNode("node", async (state, runtime) => {
    // Trigger the simple interrupt with a reason
    const response = runtime.interrupt.simple({ reason: "test" });
    // Return the interrupt response as the new state
    return { foo: response };
  })
  // Compile the graph with the checkpointer
  .compile({ checkpointer });

// Invoke the graph with initial state
const result = await graph.invoke({ foo: "test" });

// Access the interrupt data
if (graph.isInterrupted(result)) {
  console.log(result.__interrupt__.messages);
}
```

有关中断的更多信息，请参阅 [中断](/langchain/oss/langgraph/interrupts) 文档。

## 前端 SDK 增强

与前端交互时，LangGraph v1 提供了一些增强功能。

### 事件流编码

低级 `toLangGraphEventStream` 辅助工具已被移除。流式响应现在由 SDK 本地处理，您可以通过将 `encoding` 格式传递给 `graph.stream` 选择线格式。这使得在 SSE 和普通 JSON 响应之间切换变得简单，而无需更改 UI 逻辑。

有关更多信息，请参阅 [迁移指南](/langchain/oss/javascript/migrate/langgraph-v1#事件流编码)。

### `useStream` 中的自定义传输

React 的 `useStream` 钩子现在支持可插拔的传输，因此您可以在不更改 UI 代码的情况下对网络层拥有更多控制权。

```typescript
const stream = useStream({
  transport: new FetchStreamTransport({
    apiUrl: "http://localhost:2024",
  }),
});
```

学习如何集成和自定义钩子：[将 LangGraph 集成到您的 React 应用程序中](/langchain/oss/langgraph/ui)。
