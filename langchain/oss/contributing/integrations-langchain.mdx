**集成是 LangChain 的核心组件。**

LangChain 为多种关键组件（语言模型、向量存储等）提供了标准接口，这些组件在构建 LLM 应用时至关重要。实现新的集成有助于扩展 LangChain 生态系统，并使您的服务对数百万开发者可见。

<Warning>
    新的集成**不被接受为**任何 `langchain-ai` 仓库的 PR。所有新的集成都必须作为独立的包发布到 PyPI（例如，`langchain-yourprovider`）。您应该向 `langchain-ai` 仓库打开的唯一的 PR 是在文档中列出您的已发布包：要么为下载表添加一个 YAML 行，要么如果您符合 [资格标准](/langchain/oss/contributing/publish-langchain#主机指南的资格)，则提供一个托管指南。
</Warning>

## 为什么实现 LangChain 集成？

<Card title="Discoverability" icon="search">
    LangChain 是构建 LLM 应用的最常用框架，每月下载量超过 2 亿。
</Card>

<Card title="Interoperability" icon="refresh">
    LangChain 组件公开了标准接口，允许开发者轻松地相互替换它们。如果您实现了一个 LangChain 集成，任何使用不同组件的开发者将能够轻松地将其替换为您。
</Card>

<Card title="Best Practices" icon="star">
    通过它们的标准接口，LangChain 组件鼓励并促进最佳实践（流式输出、异步等），这些实践提高了开发者体验和应用程序性能。
</Card>

## 要集成的组件

虽然任何组件都可以集成到 LangChain 中，但我们鼓励更多特定类型的集成：

**集成这些 ✅**：

- [**对话模型**](/langchain/oss/python/integrations/chat)：最活跃使用的组件类型
- [**工具/工具包**](/langchain/oss/python/integrations/tools)：启用智能体功能
- [**检索器**](/langchain/oss/python/integrations/retrievers)：RAG 应用程序的核心
- [**嵌入模型**](/langchain/oss/python/integrations/embeddings)：向量操作的基础
- [**向量存储**](/langchain/oss/python/integrations/vectorstores)：语义搜索的必要组件
- [**中间件**](/langchain/oss/python/integrations/middleware)：通过钩子扩展智能体行为
- [**沙盒**](/langchain/oss/deepagents/sandboxes)：使用 Deep Agents 安全运行代码

**不集成这些 ❌**：

- **LLM（文本完成模型）**：已弃用，改为使用 [对话模型](/langchain/oss/python/integrations/chat)
- [**文档加载器**](/langchain/oss/python/integrations/document_loaders)：维护负担高
- [**键值存储**](/langchain/oss/python/integrations/stores)：使用有限
- **文档转换器**：小众用例
- **模型缓存**：基础设施问题
- **图**：复杂的抽象
- **消息历史记录**：存储抽象
- **回调**：系统级组件
- **对话加载器**：需求有限
- **适配器**：边缘案例工具

## 如何贡献一个集成

<Steps>
    <Step title="Implement your package">
        <Card title="How to implement a LangChain integration" icon="link" href="/langchain/oss/contributing/implement-langchain" arrow />
    </Step>

    <Step title="Pass standard tests">
        如适用，为您的集成实现 LangChain 的 [标准测试](/langchain/oss/contributing/standard-tests-langchain) 套件的支持，并成功运行它们。
    </Step>

    <Step title="Publish integration">
        <Card title="How to publish an integration" icon="upload" href="/langchain/oss/contributing/publish-langchain" arrow />
    </Step>

    <Step title="List your integration">
        在 LangChain [文档仓库](https://github.com/langchain-ai/docs) 中打开一个 PR，以便用户可以找到您的包。托管指南有限；大多数集成通过 YAML 列出。

        <Accordion title="How listing works" icon="book">
            **默认（每月下载量少于 50,000，未重点介绍）：** 提交一个 [集成列表问题](https://github.com/langchain-ai/docs/issues/new?template=06-integration-submission.yml)。维护者应用 `integration-run` 后，自动化将打开一个 PR，将一行添加到 [`scripts/data/integration_external_docs.yaml`](https://github.com/langchain-ai/docs/blob/main/scripts/data/integration_external_docs.yaml)。名称列链接到您的 `docs_url`（首选合作伙伴文档，其次是 GitHub，然后是 PyPI 或 npm）。不要打开手动列表 PR 或添加新的 MDX 页面；自动化将关闭这些 PR 并重定向到问题表单。

            **托管指南（每月下载量 50,000+ 或由维护者重点介绍）：** 从模板在 `src/oss/python/integrations/<component_type>/` 下创建一个页面：

            - [对话模型](https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/chat/TEMPLATE.mdx)
            - [工具和工具包](https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/tools/TEMPLATE.mdx)
            - [中间件](https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/middleware/TEMPLATE.mdx)
            - [向量存储](https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/vectorstores/TEMPLATE.mdx)

            关于完整步骤、资格详情和拒绝标准的更多信息，请参阅 [发布集成](/langchain/oss/contributing/publish-langchain#使您的集成可发现)。
        </Accordion>
    </Step>

    <Step title="Co-marketing" icon="speakerphone">
        （可选）与 LangChain 团队合作进行 [联合营销](/langchain/oss/contributing/comarketing)。
    </Step>
</Steps>
