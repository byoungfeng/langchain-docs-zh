## 步骤1：阅读指南

检测项目使用的编程语言（Python或TypeScript/JavaScript），获取并遵循对应页面；将其视为包名、模型字符串和代码的权威来源：

- Python: https://docs.langchain.com/oss/python/langchain/quickstart.md
- TypeScript: https://docs.langchain.com/oss/javascript/langchain/quickstart.md

## 步骤2：安装依赖项

使用项目已使用的包管理器（`uv`, `pip`, `npm`, `pnpm`, `yarn`, 或 `bun`）安装指南中的包。当项目已固定版本时，优先使用当前稳定版本而非浮动`latest`标签。

## 步骤3：配置模型凭据

检查是否已设置受支持的提供商API密钥（例如 `OPENAI_API_KEY`, `GOOGLE_API_KEY`, 或 `ANTHROPIC_API_KEY`）。若未设置，请用户选择提供商并暂停等待其创建密钥并设置到shell或 `.env` 文件中。不要编造、硬编码或提交API密钥。

## 步骤4：实现基础智能体

根据指南创建"构建基础智能体"示例： `create_agent`, 一个简单的工具（如 `get_weather`）、简短的系统提示，以及 `invoke` 调用。使用用户选择的提供商对应的模型字符串。输出最终消息内容（Python: `.content_blocks`）供用户验证运行。

## 步骤5：可选LangSmith追踪

询问用户是否需要追踪。若需要，请其自行设置 `LANGSMITH_TRACING=true` 和 `LANGSMITH_API_KEY` 后重新运行。不要编造LangSmith密钥。

## 规则

- 仅限本快速开始范围。不要添加无关框架、eval或生产部署。
- 如指南所示，优先使用来自 `langchain.agents` / `langchain` 的 `create_agent`。
- 对未明确的密钥、提供商选择或项目约定，应询问而非猜测。

## 构建基础智能体

首先创建一个能够回答问题和调用工具的简单智能体。本例中的智能体使用选定语言模型、基础天气函数作为工具，并通过简单提示词指导其行为：

    ```python OpenAI
    from langchain.agents import create_agent

    def get_weather(city: str) -> str:
        """Get weather for a given city."""
        return f"It's always sunny in {city}!"

    agent = create_agent(
        model="openai:gpt-5.5",
        tools=[get_weather],
        system_prompt="You are a helpful assistant",
    )

    result = agent.invoke(
        {"messages": [{"role": "user", "content": "What's the weather in San Francisco?"}]}
    )
    print(result["messages"][-1].content_blocks)
    ```

## 构建真实世界智能体

本示例将构建一个能回答文本文件问题的研究智能体。过程中您将探索以下概念：

1. **详细的系统提示词**以优化智能体行为
1. **创建工具**以集成外部数据
1. **模型配置**以确保响应一致性
1. **会话式记忆**以实现聊天式交互
1. **深度智能体**内置高级功能
1. **测试智能体**

<Steps>
    <Step title="Define the system prompt">
        系统提示词定义智能体的角色与行为。需具体且可操作：

        :::python
        ```python wrap
        SYSTEM_PROMPT = """You are a literary data assistant.

        ## Capabilities

        - `fetch_text_from_url`: loads document text from a URL into the conversation.
        Do not guess line counts or positions—ground them in tool results from the saved file."""
        ```
        :::

        :::js
        ```ts wrap
        const SYSTEM_PROMPT = `You are a literary data assistant.

        ## Capabilities

        - \`fetch_text_from_url\`: loads document text from a URL into the conversation.
        Do not guess line counts or positions—ground them in tool results from the saved file.`;
        ```

    </Step>
    <Step title="Create tools">
        [工具](/langchain/oss/langchain/tools)使模型能与外部系统交互，调用您定义的函数。
        工具可依赖[运行时上下文](/langchain/oss/langchain/runtime)并与[智能体记忆](/langchain/oss/langchain/short-term-memory)交互。

        本例使用工具从指定URL加载文档：

        :::python
        ```python
        import urllib.error
        import urllib.request

        from langchain.tools import tool


        @tool
        def fetch_text_from_url(url: str) -> str:
            """Fetch the document from a URL.
            """
            req = urllib.request.Request(
                url,
                headers={"User-Agent": "Mozilla/5.0 (compatible; quickstart-research/1.0)"},
            )
            try:
                with urllib.request.urlopen(req, timeout=120) as resp:
                    raw = resp.read()
            except urllib.error.URLError as e:
                return f"Fetch failed: {e}"
            text = raw.decode("utf-8", errors="replace")
            return text
        ```

        <Tip>
            工具需完善文档：名称、描述和参数会成为模型提示词的一部分。
            LangChain的@[`@tool`装饰器][@tool]会添加元数据并支持通过`ToolRuntime`参数注入运行时。
           详见[工具指南](/langchain/oss/langchain/tools)。
        </Tip>
        :::


另一方面，深度智能体可以：

        1. **根据需要生成子智能体**，将复杂的子任务委托给专业的子智能体。

对于 LangChain 智能体，您必须实现更多功能才能获得类似的服务水平，并且可以根据需要随时进行定制。

    </Step>
</Steps>

## 追踪智能体调用

<AgentTracingPrerequisite />

你使用 LangChain 构建的许多有趣应用都需要频繁调用 LLM。随着这些应用变得越来越复杂，了解智能体内部究竟发生了什么变得至关重要。要做到这一点，最佳方式是使用 [LangSmith](https://smith.langchain.com)。

注册一个 [LangSmith](https://smith.langchain.com) 账户，并设置这些以开始记录跟踪：

```shell
export LANGSMITH_AGENT_ID="<your-agent-id>"
export LANGSMITH_AGENT_ENVIRONMENT="production"
export LANGSMITH_TRACING="true"
export LANGSMITH_API_KEY="..."
```

设置完成后，再次运行您的脚本，然后检查 [LangSmith](https://smith.langchain.com) 期间智能体的调用情况。

<Tip>
要详细了解如何使用 LangSmith 追踪智能体，请参阅 [LangSmith 文档](https://docs.langchain.com/langsmith/trace-with-langchain)。

我们建议您还设置 [LangSmith Engine](https://docs.langchain.com/langsmith/engine)，它监控您的跟踪记录、检测问题并建议解决方案。
</Tip>
