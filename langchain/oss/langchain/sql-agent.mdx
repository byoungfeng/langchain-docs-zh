## 概述

在本教程中，您将学习如何使用 LangChain [智能体](/langchain/oss/langchain/agents)构建一个能够回答有关 SQL 数据库问题的智能体。

从宏观角度来看，该智能体将执行以下操作：

1. 从数据库中获取可用的表和模式
1. 判断哪些表与问题相关
1. 获取相关表的模式
1. 根据问题和模式信息生成查询
1. 使用大型语言模型（LLM）检查查询是否存在常见错误
1. 执行查询并返回结果
1. 修正数据库引擎暴露的错误，直到查询成功
1. 根据结果制定响应

<Warning>
构建 SQL 数据库的问答系统需要执行模型生成的 SQL 查询。这样做存在固有风险。确保您的数据库连接权限始终尽可能狭窄地限制在智能体的需求范围内。这将减轻，尽管不能消除，构建模型驱动系统的风险。
</Warning>
