**智能体 = 模型 + 托管。** LangChain 提供 `create_agent`：一个极简、高度可配置的托管。托管是模型循环周围的一切：提示词、工具以及任何塑造行为的中间件。从基础元素开始，组合您用例所需的内容。支持 [OpenAI, Anthropic, Google, 和更多](/langchain/oss/python/integrations/providers/overview)。

<Tip>
**LangChain vs. LangGraph vs. 深度智能体**

从 [Managed Deep Agents](https://docs.langchain.com/langsmith/managed-deep-agents-overview) 开始，用于一个包含电池（上下文压缩、虚拟文件系统、子智能体）的托管，当您想在不管理基础设施的情况下运行生产智能体时。或者，为了在使用相同的深度智能体托管时获得最大灵活性，使用 [Deep Agents SDK](/langchain/oss/deepagents/overview#使用-sdk-自托管) 自己托管智能体，或运行一个自定义的 [LangSmith Deployment](https://docs.langchain.com/langsmith/deployment)。深度智能体基于 LangChain [agents](/langchain/oss/langchain/agents/)，您也可以直接使用它们。

使用 [LangChain](/langchain/oss/langchain/agents) (`create_agent`) 用于一个高度可定制的托管，可以轻松地根据您的用例和数据进行调整。

使用 [LangGraph](/langchain/oss/langgraph/overview)，我们的低级编排框架，用于结合确定性和智能体工作流的高级需求。

使用 [LangSmith](https://docs.langchain.com/langsmith/observability) 来跟踪、调试和评估使用这些框架构建的智能体。遵循 [tracing quickstart](https://docs.langchain.com/langsmith/trace-with-langchain) 来设置。我们建议您还设置 [LangSmith Engine](https://docs.langchain.com/langsmith/engine)，它监控您的跟踪、检测问题并建议修复。
</Tip>

    ```python OpenAI
    # pip install -qU langchain "langchain[openai]"
    from langchain.agents import create_agent

    def get_weather(city: str) -> str:
        """Get weather for a given city."""
        return f"It's always sunny in {city}!"

    agent = create_agent(
        model="openai:gpt-5.5",
        tools=[get_weather],
        system_prompt="You are a helpful assistant",
    )

    result = agent.invoke(
        {"messages": [{"role": "user", "content": "What's the weather in San Francisco?"}]}
    )
    print(result["messages"][-1].content_blocks)
    ```

    ```ts OpenAI
    // First install: npm install langchain zod @langchain/openai
    import { createAgent, tool } from "langchain";
    import * as z from "zod";

    const getWeather = tool(
      (input) => `It's always sunny in ${input.city}!`,
      {
        name: "get_weather",
        description: "Get the weather for a given city",
        schema: z.object({
          city: z.string().describe("The city to get the weather for"),
        }),
      }
    );

    const agent = createAgent({
      model: "gpt-5.5",
      tools: [getWeather],
    });

    console.log(
      await agent.invoke({
        messages: [{ role: "user", content: "What's the weather in San Francisco?" }],
    ```
