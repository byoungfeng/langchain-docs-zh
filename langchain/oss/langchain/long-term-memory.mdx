长期记忆允许您的智能体在不同对话和会话中存储和回忆信息。
与[短期记忆](/langchain/oss/langchain/short-term-memory)不同（短期记忆限定于单个线程），长期记忆跨线程持久化，并且可以随时被回忆。

长期记忆基于[LangGraph 存储系统](/langchain/oss/langgraph/stores)构建，该系统将数据保存为按命名空间和键组织的 JSON 文档。

## 记忆存储

LangGraph 将长期记忆作为 JSON 文档存储在[存储系统](/langchain/oss/langgraph/stores)中。

每条记忆都组织在自定义的`namespace`（类似于文件夹）和唯一的`key`（类似于文件名）下。命名空间通常包含用户或组织 ID 或其他标签，以便更容易地组织信息。

这种结构支持记忆的分层组织。通过内容过滤器支持跨命名空间搜索。
