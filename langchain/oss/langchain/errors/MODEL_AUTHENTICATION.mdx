您的模型提供方拒绝您访问其服务。

此错误通常发生在您的认证凭证或 API 密钥存在问题时。

## 故障排除

* 确认您的 API 密钥或认证凭证准确且有效。
* 如果使用基于环境变量的认证，请验证：
    - 变量名拼写正确
    - 变量包含已分配的值
    - 第三方包如 `dotenv` 未干扰加载过程
* 如果使用代理或非标准端点，确保您的自定义提供方不期望替代的认证方案。
* 通过显式传递凭证绕过环境变量问题：

:::python
```python
from langchain_openai import ChatOpenAI

model = ChatOpenAI(api_key="YOUR_KEY_HERE")
```
:::
:::js
```typescript
import { ChatOpenAI } from "@langchain/openai";

const model = new ChatOpenAI({
  apiKey: "YOUR_KEY_HERE",
});
```
:::
