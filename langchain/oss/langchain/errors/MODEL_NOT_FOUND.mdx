## 故障排除

要解决此错误：

1. **验证模型标识符**：仔细检查您传递的模型字符串。确保拼写和格式正确。
2. **检查代理/包装器配置**：如果您使用带有模型包装器的代理或其他替代主机，请确认允许的模型名称没有被限制或更改。

此错误通常源于模型名称字符串本身存在拼写错误，或是由您代码与提供者 API 之间的代理服务或模型包装器施加的限制。
