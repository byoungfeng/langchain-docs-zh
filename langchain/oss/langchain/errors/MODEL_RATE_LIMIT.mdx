您已超出模型提供者在特定时间段内允许的最大请求数量，因此被暂时阻止。

当您在特定时间内超过了模型提供者允许的最大请求数量时，就会发生此错误，导致暂时阻止。这种限制通常是临时的，在限制重置后会解除。

## 故障排除

要解决此错误，您可以：

1. **实现速率限制**：部署一个速率限制器来调节发送到模型的请求频率。
    :::python
    参考 [速率限制](/langchain/oss/langchain/models#速率限制) 文档。
    :::
2. **实现响应缓存**：使用模型响应缓存来减少当传入查询重复时的冗余请求。
3. **使用多个提供者**：如果您的应用程序架构支持，将请求分配到多个提供者。
4. **联系您的提供者**：联系您的模型提供者，请求提高您的速率限制。
