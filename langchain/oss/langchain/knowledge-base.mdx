## 概述

使用 LangChain [嵌入](/langchain/oss/python/integrations/embeddings) 和 [向量存储](/langchain/oss/python/integrations/vectorstores) 在 PDF 上构建语义搜索引擎。使用它检索与查询相似的段落，然后将检索器插入 [检索增强生成（RAG）](/langchain/oss/deepagents/retrieval) 或其他 LLM 工作流程。

本教程涵盖：

1. 从 PDF 创建 `Document` 对象。
2. 生成嵌入。
3. 加载和分割 PDF。
4. 在向量存储中索引片段并通过相似性查询。
5. 将存储包装为检索器。

本指南还包含基于搜索引擎的最小 RAG 实现。

### 概念

本教程专注于文本检索，涵盖以下概念：

- @[`Document`]
- [文本分割器](/langchain/oss/integrations/splitters)
- [嵌入](/langchain/oss/python/integrations/embeddings)
- [向量存储](/langchain/oss/python/integrations/vectorstores) 和 [检索器](/langchain/oss/python/integrations/retrievers)

## 创建文档

LangChain 为文本单元及其相关元数据实现了 @[`Document`] 抽象。它具有三个属性：

:::python
- `page_content`: 表示内容的字符串。
- `metadata`: 包含任意元数据的字典。
- `id`: （可选）文档的字符串标识符。
:::
:::js
- `pageContent`: 表示内容的字符串。
- `metadata`: 包含任意元数据的字典。
- `id`: （可选）文档的字符串标识符。
:::

`metadata` 可以捕获文档的来源、与其他文档的关系以及其他信息。单个 @[`Document`] 通常表示较大文档的一部分。

以下代码创建示例文档：

:::python
```python
from langchain_core.documents import Document

documents = [
    Document(
        page_content="Dogs are great companions, known for their loyalty and friendliness.",
        metadata={"source": "mammal-pets-doc"},
    ),
    Document(
        page_content="Cats are independent pets that often enjoy their own space.",
        metadata={"source": "mammal-pets-doc"},
    ),
]
```
:::
:::js
```typescript
import { Document } from "@langchain/core/documents";

const documents = [
  new Document({
```

## 选择向量存储

LangChain @[`VectorStore`] 对象将文本和 @[`Document`] 对象添加到存储中，并使用相似性度量查询它们。它们通常使用 [嵌入](/langchain/oss/python/integrations/embeddings) 模型初始化，这些模型将文本转换为数值向量。

## 加载和分割 PDF

从 PDF 加载内容，然后在其分割成更小的片段之前进行索引。本例使用 [2023 年 Nike 的示例 10-K 文件](https://github.com/langchain-ai/langchain/blob/v0.3/docs/docs/example_data/nke-10k-2023.pdf)。

:::python
对于专用的 PDF 文档加载器（包括 `PyPDFLoader` 和合作伙伴包），请参阅 [PDF 文档加载器](/langchain/oss/python/integrations/document_loaders#pdfs)。

```python
import pypdf
from langchain_core.documents import Document


# Below is a minimal helper for demonstration purposes.
def load_pdf_pages(file_path: str) -> list[Document]:
    reader = pypdf.PdfReader(file_path)
    return [
        Document(
            page_content=page.extract_text() or "",
            metadata={"source": file_path, "page": i},
        )
        for i, page in enumerate(reader.pages)
    ]


file_path = "../example_data/nke-10k-2023.pdf"
docs = load_pdf_pages(file_path)
print(len(docs))
```
:::
:::js
```typescript
import { readFileSync } from "node:fs";
import { Document } from "@langchain/core/documents";
import { PDFParse } from "pdf-parse";

// Below is a minimal helper for demonstration purposes.
async function loadPdfPages(filePath: string): Promise<Document[]> {
  const parser = new PDFParse({
    data: new Uint8Array(readFileSync(filePath)),
  });
  try {
    const { pages } = await parser.getText();
    return pages.map(
      (page) =>
        new Document({
          pageContent: page.text,
          metadata: { source: filePath, page: page.num - 1 },
        })
    );
  } finally {
    await parser.destroy();
  }
}

const filePath = "../../data/nke-10k-2023.pdf";
const docs = await loadPdfPages(filePath);
console.log(docs.length);
```
:::

```text
107
```

页面对于检索来说往往过于粗略。进一步分割页面，以便相关段落不会被周围文本稀释。@[`RecursiveCharacterTextSplitter`] 递归地在常见分隔符（如换行符）上分割，直到每个片段达到目标大小。这是通用文本用例的推荐文本分割器。

:::python
设置 `add_start_index=True`，以便每个分割片段保留 `start_index` 元数据字段，用于其在原始文档中的字符偏移量。

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000, chunk_overlap=200, add_start_index=True
)
all_splits = text_splitter.split_documents(docs)

print(len(all_splits))
```
:::
:::js
```typescript
import { RecursiveCharacterTextSplitter } from "@langchain/textsplitters";

const textSplitter = new RecursiveCharacterTextSplitter({
  chunkSize: 1000,
  chunkOverlap: 200,
});

const allSplits = await textSplitter.splitDocuments(docs);

console.log(allSplits.length);
```
:::

## 使用检索器

LangChain @[`VectorStore`] 对象不继承 @[`Runnable`]。 @[检索器] 是 Runnable，因此它们支持标准方法，如同步和异步 `invoke` 和 `batch`。

您还可以从向量存储构建检索器，检索器也可以封装非向量源（例如外部 API）。

:::python
在这种情况下，通过封装 `similarity_search` 而不继承 `Retriever` 创建一个简单的检索器：

```python
from typing import List

from langchain_core.documents import Document
from langchain_core.runnables import chain


@chain
def retriever(query: str) -> List[Document]:
    return vector_store.similarity_search(query, k=1)


retriever.batch(
    [
        "How many distribution centers does Nike have in the US?",
        "When was Nike incorporated?",
    ],
)
```
