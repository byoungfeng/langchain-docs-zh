## LangSmith Cloud

本节将指导你从 GitHub 仓库将智能体部署到 LangSmith Cloud。LangSmith 处理基础设施、扩展和运维问题。

### 前置条件

开始之前，请确保你拥有以下内容：

- 一个 [GitHub 账户](https://github.com/)
- 一个 [LangSmith 账户](https://smith.langchain.com)（免费注册）
