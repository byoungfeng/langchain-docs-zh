**链**配置允许您针对特定模型或**智能体**自定义Deep Agents的**链**。您可以调整系统**提示词**和工具描述，排除工具或中间件，添加中间件，并配置通用子**智能体**。Deep Agents在您选择匹配的模型时应用这些设置，而无需更改您的**智能体**创建代码。

:::python
**提供者**配置定义创建模型的默认设置，例如温度和超时。这些设置不会影响**链**。大多数调用者不需要提供者配置。当打包需要共享默认值、凭证检查或运行时计算的集成时，它们很有用。
:::

<Note>
  提供**者**配置（用于控制用于创建模型的设置）和插件注册系统是仅限Python的功能。TypeScript SDK仅支持**链**配置。
</Note>
:::

## 注册键

配置文件注册使用这些键：

- **提供者级**—一个不带提供者名称的 `"openai"`（例如 `"openai"`）适用于该提供者提供的所有模型。
- **模型级**—一个完全限定 `provider:model` 键（例如 `"openai:gpt-6-astra"`）仅适用于该特定模型。

当存在提供者级和模型级配置文件时，它们在解析时合并。未设置的模型级字段继承自提供者级配置文件；显式的模型级值会覆盖它们。

:::python
仅第一个冒号分隔提供者和模型标识符。对于假设的键 `my_provider:my-model:tag`，提供者是 `my_provider`，完整的模型标识符是 `my-model:tag`。任何额外的冒号都是模型标识符的一部分。
::>

:::js
TypeScript 中的配置文件注册不支持包含冒号的模型标识符。使用一个键，例如 `my_provider:my-model`，其中只有一个冒号分隔提供者和模型标识符。
::>

## 合并语义

:::python
| 字段 | 合并行为 |
| --- | --- |
| `base_system_prompt`, `system_prompt_suffix` | 设置时新值优先；否则继承 |
| `tool_description_overrides` | 映射按键合并；共享键上新值优先 |
| `excluded_tools`, `excluded_middleware` | 设置的并集 |
| `extra_middleware` | 按具体类型合并：新实例替换其位置的现有实例，新类型追加 |
| `general_purpose_subagent` | 按字段合并（未设置字段继承） |
| `init_kwargs` (提供者) | 字典按键合并；共享键上新值优先 |
| `pre_init` (提供者) | 可调用链：现有实例先执行，然后执行新的 |
| `init_kwargs_factory` (提供者) | 工厂链：在每次模型构建时合并它们的输出 |
:::

## 将配置作为插件发送

:::python
可分发配置可以通过 `importlib.metadata` 入口点注册，而不是要求调用者手动运行 `register_*_profile`。加载顺序是 **内置组件优先，然后是入口点插件，然后是用户代码中的任何直接 `register_*_profile` 调用**；所有三个路径都通过相同的附加注册流程，因此较晚的注册在相同键下叠加在较早的注册之上。

在分发的 `pyproject.toml` 下声明入口点，在适当的组中：

```toml
[project.entry-points."deepagents.harness_profiles"]
my_provider = "my_pkg.profiles:register_harness"

[project.entry-points."deepagents.provider_profiles"]
my_provider = "my_pkg.profiles:register_provider"
```

每个目标解析为在 `deepagents.profiles` 导入时执行注册的零参数可调用对象：

:::

:::js
