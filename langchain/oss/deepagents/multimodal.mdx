## 上下文压缩和多模态内容

内置的卸载和摘要针对文本和消息历史进行了优化：

- **卸载** 仅测量文本 Token。非文本块（包括图像）在替换消息中保留，而不是被压缩。仅包含图像的消息不会根据图像大小单独卸载。
- **摘要** 将较旧的消息压缩为纯文本摘要。在该范围内的图像、音频、视频和文件块不会被传递——模型只看到摘要器写的内容。低于保留阈值的最近消息保持不变。

    当摘要运行时，较旧回合中的媒体块会从活动上下文中删除：

    <MultimodalSummarizationPy />

    :::

    :::js

    <MultimodalSummarizationJs />

    :::

    原始对话仍然作为文本写入文件系统。有关触发器、保留阈值和完整流程，请参阅 [摘要](/langchain/oss/deepagents/context-engineering#摘要)。

对于多模态密集型工作负载：

- 将图像、截图和图表存储在文件系统后端或外部对象存储中，然后通过消息传递文件路径或 URL。
- 在长时间运行的对话中，优先使用引用而不是 base64 编码的图像块。
- 使用 [子智能体](/langchain/oss/deepagents/subagents) 进行图像密集型检查，以便主智能体接收紧凑的文本结果。
- 调整摘要阈值或在你的提供程序为图像收费许多 Token 时提供自定义 Token 计数器。

有关卸载阈值、摘要触发器和自定义选项，请参阅 [上下文压缩](/langchain/oss/deepagents/context-engineering#上下文压缩)。
