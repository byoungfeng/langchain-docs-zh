### OpenAI 和响应 API

当您将 `openai:...` 字符串作为模型传递时，Deep Agents 使用内置的 OpenAI [提供者配置文件](/langchain/oss/deepagents/profiles#提供者配置文件) 默认启用 [响应 API](/langchain/oss/python/integrations/chat/openai#响应-api)。该路径支持 OpenAI 会话状态和相关功能；有关当前 API 选项，请参阅 [OpenAI 提供者](/langchain/oss/python/integrations/providers/openai) 和 [对话模型](/langchain/oss/python/integrations/chat/openai) 文档。

<Note>
    内置的 OpenAI 提供者配置文件仅适用于模型字符串。要设置 kwargs，如 `use_responses_api`、`store` 或 `include`，请传递配置好的模型实例，或在 Python 中，通过 [提供者配置文件](/langchain/oss/deepagents/profiles#提供者配置文件) `init_kwargs` 层叠它们。使用 @[`init_chat_model`]（Python）或 `initChatModel` / `ChatOpenAI`（TypeScript）构建实例。
</Note>

:::python
要使用 [聊天补全](https://platform.openai.com/docs/guides/responses-vs-chat-completions) 而不是响应 API，请传递预初始化的模型，使用 `use_responses_api=False`：

```python
from langchain.chat_models import init_chat_model
from deepagents import create_deep_agent

model = init_chat_model("openai:gpt-5.5", use_responses_api=False)
agent = create_deep_agent(model=model)
```

要保持响应 API 但禁用数据保留（`store=False`），同时仍然接收加密的推理输出，请设置 `include`，以便推理作为加密内容返回：

```python
from langchain.chat_models import init_chat_model
from deepagents import create_deep_agent

model = init_chat_model(
    "openai:gpt-5.5",
    use_responses_api=True,
    store=False,
    include=["reasoning.encrypted_content"],
)
agent = create_deep_agent(model=model)
```
:::

:::js
使用 [OpenAI 聊天集成](/langchain/oss/python/integrations/chat/openai#响应-api) 来选择响应 API 与聊天补全（`useResponsesApi`、模型 kwargs 以及您的版本公开的任何存储或输出选项）。将生成的模型实例传递给 `createDeepAgent({ model })`，以保留这些设置。
:::
