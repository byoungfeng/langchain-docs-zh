深度智能体代码（`dcode`）是一个基于 [深度智能体 SDK](/langchain/oss/deepagents/quickstart) 开发的开源编码智能体。
它可与任何大型语言模型配合使用，并支持切换提供商或模型。
持久化记忆在对话中传递上下文，可定制的技能塑造行为，而审批控制则管理代码执行。

## 入门指南

运行以下命令以安装深度智能体代码并启动交互式会话：

```bash
curl -LsSf https://langch.in/dcode | bash
dcode
```

查看 [快速入门](/langchain/oss/deepagents/code/quickstart) 以添加提供商凭证、运行第一个任务并学习交互模式。
