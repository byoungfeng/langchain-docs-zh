## 命名空间

当 `subgraphs` 启用时，每个流式传输事件都包含一个 **命名空间**，用于标识哪个智能体生成了它。命名空间是节点名称和任务 ID 的路径，表示智能体层次结构。

| 命名空间 | 源 |
| --------- | ------ |
| `()` (空) | 主智能体 |
| `("tools:abc123",)` | 主智能体通过 `task` 工具调用 `abc123` 生成的子智能体 |
| `("tools:abc123", "model_request:def456")` | 子智能体内部的模型请求节点 |

### 处理人机交互中断

当 [`interrupt_on`](/langchain/oss/deepagents/human-in-the-loop) 配置时，`updates` 流中可能包含 `__interrupt__` 条目，用于暂停执行以供人工批准。通过检查更新块中的 `__interrupt__` 键来检测它们。使用与 `.invoke()` 相同的扁平 `{"decisions": [...]}` 负载继续：

:::python
```python
from langchain_core.utils.uuid import uuid7

config = {"configurable": {"thread_id": str(uuid7())}}

for mode, data in agent.stream(
    {"messages": [{"role": "user", "content": "Delete temp.txt"}]},
    stream_mode=["messages", "updates"],
    config=config,
):
    if mode == "updates" and isinstance(data, dict):
        if "__interrupt__" in data:  # [!code highlight]
            for interrupt_obj in data["__interrupt__"]:
                print(f"Approval needed: {interrupt_obj.value}")
```
:::

:::js
```typescript
import { v7 as uuid7 } from "uuid";

const config = { configurable: { thread_id: uuid7() } };

for await (const [mode, data] of await agent.stream(
  { messages: [{ role: "user", content: "Delete temp.txt" }] },
  { streamMode: ["messages", "updates"], ...config }
)) {
  if (mode === "updates" && data?.__interrupt__) {  // [!code highlight]
    for (const interruptObj of data.__interrupt__) {
      console.log("Approval needed:", interruptObj.value);
    }
  }
}
```
:::

参见 [人机交互：使用流式传输处理中断](/langchain/oss/deepagents/human-in-the-loop#使用流式输出处理中断)，了解完整的流式恢复循环模式。

## 流式传输块形状

使用 `subgraphs=True` 时，块形状取决于您是否传递了一个流式传输模式或多个：

| `stream_mode` | 块形状 |
| ------------- | ----------- |
| 单一模式（例如 `"updates"`） | `(namespace, data)` |
| 多种模式（例如 `["messages", "updates"]`） | `(namespace, mode, data)` |

没有 `subgraphs`，单一模式直接生成 `data`，多种模式生成 `(mode, data)`。

```python
# Single mode + subgraphs
for namespace, data in agent.stream(
    {"messages": [{"role": "user", "content": "Research quantum computing"}]},
    stream_mode="updates",
    subgraphs=True,
):
    print(namespace)  # () for main agent, ("tools:<id>",) for subagent
    print(data)

# Multiple modes + subgraphs
for namespace, mode, data in agent.stream(
    {"messages": [{"role": "user", "content": "Research quantum computing"}]},
    stream_mode=["updates", "messages", "custom"],
    subgraphs=True,
):
    print(mode)       # "updates", "messages", or "custom"
    print(namespace)  # () for main agent, ("tools:<id>",) for subagent
    print(data)
```

:::python
LangGraph 1.1 及更高版本还支持统一的 `version="v2"` `StreamPart` 字典格式。参见 [流式输出格式 (v2)](/langchain/oss/langgraph/streaming#流式输出格式-v2)。本页上的深度智能体示例使用元组格式，该格式与深度智能体当前依赖的 LangGraph 版本匹配。
