## 概述

本指南展示了如何使用 [Deep Agents](/langchain/oss/deepagents) 构建多步骤网页研究智能体。该智能体将研究问题分解为聚焦的任务，委托给专用子智能体处理，并将最终发现整合为综合报告。

您构建的智能体将实现以下功能：

1. 使用可选待办事项中间件规划研究
1. 将聚焦型研究任务委托给具有独立上下文隔离的子智能体
1. 随着信息收集评估搜索结果并规划下一步行动
1. 将带有规范引用的发现整合为最终报告

生成的子智能体使用 Tavily 进行网页搜索，获取完整网页内容进行分析。

### 核心概念

本教程涵盖以下内容：

- [子智能体](/langchain/oss/deepagents/subagents) 实现并行、上下文隔离的研究
- 自定义 [工具](/langchain/oss/langchain/tools) 进行网页搜索
- 使用可选 [规划工具](/langchain/oss/deepagents/overview#任务规划) 实现多步骤规划

## 先决条件

需要以下 API 密钥：

- Anthropic（Claude）或 Google（Gemini）
- [Tavily](https://www.tavily.com/)（用于网页搜索，可选；免费套餐足够）
- [LangSmith](https://smith.langchain.com)（用于追踪，若使用 SDK 可选；使用 Managed Deep Agents 时必需）

## 选择路径

本指南展示了如何使用 [Managed Deep Agents](https://docs.langchain.com/langsmith/managed-deep-agents-overview) 和 Deep Agents SDK 构建该智能体。Managed Deep Agents 允许您无需管理基础设施即可部署智能体。Deep Agents SDK 提供最大灵活性，您既可使用相同的 Deep Agents harness 部署，也可通过自定义 [LangSmith 部署](https://docs.langchain.com/langsmith/deployment) 自行托管。
