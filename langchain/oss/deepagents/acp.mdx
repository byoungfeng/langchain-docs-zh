[智能体客户端协议（ACP）](https://agentclientprotocol.com/get-started/introduction) 标准化了编码智能体与代码编辑器或 IDE 之间的通信。
通过 ACP 协议，您可以使用自定义的深度智能体与任何 ACP 兼容的客户端，使您的代码编辑器能够提供项目上下文并接收丰富的更新。

<Note>
    ACP 是为智能体-编辑器集成设计的。如果您希望您的智能体调用外部服务器托管的工具，请参阅 [模型上下文协议（MCP）](/langchain/oss/langchain/mcp/)。
</Note>

## 客户端

深度智能体可以在您能运行 ACP 智能体服务器的任何地方工作。一些值得注意的 ACP 客户端包括：

- [Zed](https://zed.dev/docs/ai/external-agents)
- [JetBrains IDEs](https://www.jetbrains.com/help/ai-assistant/acp.html)
- Visual Studio Code (通过 [vscode-acp](https://github.com/formulahendry/vscode-acp))
- Neovim (通过 ACP 兼容插件)

### Zed

:::python

The `deepagents` 仓库包含 [一个示例 ACP 入口点](https://github.com/langchain-ai/deepagents/blob/main/libs/acp/run_demo_agent.sh)，您可以将其注册到 [Zed](https://zed.dev/docs/ai/external-agents)：

1. 克隆 `deepagents` 仓库并安装依赖：

```bash
git clone https://github.com/langchain-ai/deepagents.git
cd deepagents/libs/acp
uv sync --all-groups
chmod +x run_demo_agent.sh
```

2. 为演示智能体配置凭证：

```bash
cp .env.example .env
```

然后设置 `ANTHROPIC_API_KEY` 在 `.env` 中。

3. 在 Zed 的 `settings.json` 中配置您的 ACP 智能体服务器命令：

```json
{
  "agent_servers": {
    "DeepAgents": {
      "type": "custom",
      "command": "/your/absolute/path/to/deepagents/libs/acp/run_demo_agent.sh"
    }
  }
}
```

4. 打开 Zed 的智能体面板并启动一个深度智能体线程。

:::

:::js

通过将您的深度智能体添加到您的 Zed 设置（Linux 上的 `~/.config/zed/settings.json`，macOS 上的 `~/Library/Application Support/Zed/settings.json`）来向 [Zed](https://zed.dev/docs/ai/external-agents) 注册您的深度智能体：

**简单设置（无需代码）：**

```json
{
  "agent": {
    "profiles": {
      "deepagents": {
        "name": "DeepAgents",
        "command": "npx",
        "args": ["deepagents-acp"],
        "env": {
          "ANTHROPIC_API_KEY": "sk-ant-..."
        }
      }
    }
  }
}
```

**使用 CLI 选项：**

```json
{
  "agent": {
    "profiles": {
      "deepagents": {
        "name": "DeepAgents",
        "command": "npx",
        "args": [
          "deepagents-acp",
          "--name", "my-assistant",
          "--skills", "./skills",
          "--debug"
        ],
        "env": {
          "ANTHROPIC_API_KEY": "sk-ant-..."
        }
      }
    }
  }
}
```

**自定义服务器脚本：**

对于更多控制，创建一个 TypeScript 服务器脚本：

```ts
// server.ts
import { startServer } from "deepagents-acp";

await startServer({
  agents: {
    name: "my-agent",
    description: "My custom coding agent",
    skills: ["./skills/"],
  },
});
```

然后指向 Zed：

```json
{
  "agent": {
    "profiles": {
      "my-agent": {
        "name": "My Agent",
        "command": "npx",
        "args": ["tsx", "./server.ts"]
      }
    }
  }
}
```

打开 Zed 的智能体面板并启动一个深度智能体线程。

## CLI 参考

CLI 是启动 ACP 服务器的最快方式。它无需代码——只需运行 `npx deepagents-acp` 并连接您的编辑器。

```bash
npx deepagents-acp [options]
```

| 选项                 | 简写 | 描述                                       |
| -------------------- | ----- | ------------------------------------------------- |
| `--name <name>`        | `-n`  | 智能体名称（默认： `"deepagents"`）              |
| `--description <desc>` | `-d`  | 智能体描述                                 |
| `--model <model>`      | `-m`  | LLM 模型（默认： `"claude-sonnet-4-5-20250929"`） |
| `--workspace <path>`   | `-w`  | 工作区根目录（默认：当前工作目录）           |
| `--skills <paths>`     | `-s`  | 以逗号分隔的技能路径                       |
| `--memory <paths>`     |       | 以逗号分隔的 AGENTS.md 路径                   |
| `--debug`              |       | 启用将调试日志写入 stderr                  |
| `--help`               | `-h`  | 显示帮助信息                                 |
| `--version`            | `-v`  | 显示版本                                      |

### 环境变量

| 变量            | 描述                                    |
| ------------------- | ---------------------------------------------- |
| `ANTHROPIC_API_KEY` | Anthropic/Claude 模型的 API 密钥（必需） |
| `OPENAI_API_KEY`    | OpenAI 模型的 API 密钥                      |
| `DEBUG`             | 设置为 `"true"` 以启用调试日志        |
| `WORKSPACE_ROOT`    | `--workspace` 标志的替代方案              |

#### 服务器选项

| 选项          | 类型                                   | 默认              | 描述                          |
| --------------- | -------------------------------------- | -------------------- | ------------------------------------ |
| `agents`        | `DeepAgentConfig \| DeepAgentConfig[]` | required             | 智能体配置(s)               |
| `serverName`    | `string`                               | `"deepagents-acp"`   | ACP 的服务器名称                  |
| `serverVersion` | `string`                               | `"0.0.1"`            | 服务器版本                       |
| `workspaceRoot` | `string`                               | `process.cwd()`      | 工作区根目录             |
| `debug`         | `boolean`                              | `false`              | 启用调试日志                 |

#### 智能体配置

| 选项         | 类型                                           | 描述                                       |
| -------------- | ---------------------------------------------- | ------------------------------------------------- |
| `name`         | `string`                                       | 唯一智能体名称（必填）                      |
| `description`  | `string`                                       | 智能体描述                                 |
| `model`        | `string`                                       | LLM 模型（默认：`"claude-sonnet-4-5-20250929"`） |
| `tools`        | `StructuredTool[]`                             | 自定义 LangChain 工具                            |
| `systemPrompt` | `string`                                       | 自定义系统提示词                              |
| `middleware`    | `AgentMiddleware[]`                            | 添加到 [Deep Agents 堆栈](/langchain/oss/deepagents/customization#deep-agents-堆栈) 的自定义中间件 |
| `backend`      | `AnyBackendProtocol`                           | 文件系统后端                                |
| `skills`       | `string[]`                                     | 技能源路径                                |
| `memory`       | `string[]`                                     | 记忆源路径 (AGENTS.md)                   |
| `interruptOn`  | `Record<string, boolean \| InterruptOnConfig>` | 需要用户批准的工具 (HITL)              |
| `commands`     | `Array<{ name, description, input? }>`         | 自定义斜杠命令                             |
