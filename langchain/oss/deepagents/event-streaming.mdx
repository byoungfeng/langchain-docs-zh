## 流式处理子智能体

Deep Agents 在 LangGraph 流式处理的基础上添加了子智能体投影。当你希望每个委托的 `task` 调用都有一个流式处理句柄时，请使用 `stream.subagents`。该投影非常轻量级：它首先发现子智能体任务，并且只有在你在子智能体句柄上访问消息、工具调用和值流时才会打开这些流。

每个句柄的 `name` 是子智能体的配置名称：协调器在调用 `task` 工具时传递的 `subagent_type`。Deep Agents 将该名称绑定到委托的运行，因此你在子智能体规范中定义的相同标签就是你流式处理中过滤和路由的标签。

每个子智能体流式处理暴露与父运行相同的投影类型，例如消息、工具调用、嵌套子智能体和最终输出。有关通用的父运行流式处理模型，请参阅 [LangChain 流式处理](/langchain/oss/langchain/event-streaming)。

:::python
Python 使用 snake_case 投影名称，例如 `tool_calls`。每个子智能体流式处理可以暴露 `.messages`、`.tool_calls`、`.values`、`.subagents` 和 `.output`。
:::

:::js

| 字段 | 描述 |

| `messages` | 子智能体发出的消息。 |
| `subagents` | 嵌套子智能体调用。 |
| `output` | 最终子智能体状态，或委托任务的完成信号。 |
:::python
| `path` | 子智能体流式处理的命名空间路径。 |
| `status` | 生命周期状态，例如 `started`、`completed`、`failed` 或 `interrupted`。 |
| `tool_calls` | 限定在子智能体范围内的工具调用。 |
::::::js
| `taskInput` | 传递给任务工具的提示词的 Promise。 |
| `toolCalls` | 限定在子智能体范围内的工具调用。 |

## 并发消费

协调器和子智能体的输出经常交错。当你需要实时 UI 更新时，请并发消费投影。

:::python
在异步代码中进行并发消费，请使用 `astream_events` 与 `asyncio.gather`：

```py
import asyncio

stream = await agent.astream_events(input, version="v3")

async def consume_coordinator():
    async for message in stream.messages:
        print("[coordinator]", await message.text)

async def consume_subagents():
    async for subagent in stream.subagents:
        async for message in subagent.messages:
            print(f"[{subagent.name}]", await message.text)

await asyncio.gather(consume_coordinator(), consume_subagents())
```

## 子智能体与子图

`stream.subgraphs` 显示图执行结构。`stream.subagents` 显示产品级别的 Deep Agents 任务委托。使用 `stream.subagents` 用于用户界面的 UI，因为它隐藏了内部图节点并直接暴露了子智能体概念。
